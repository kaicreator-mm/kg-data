## 广度计划：不被四系统试点锁死

- 第一组可并行的 `STR-ENG-LUBE / STR-AT / STR-BRK / STR-HV` 仅验证首轮不同系统独立写集。
- 同一计划审阅通过后，`STR-ENG-AIRFUEL / STR-DRIVELINE / STR-STEER-SUSP / STR-LOWV / STR-THERMAL / STR-BODY-SAFETY` 可以作为结构广度 READY 候选并行认领，必须由当前资料可见范围、优先级和写集核查来激活，**不需要前面四系统的全部知识正文完成**。
- 任何真实系统、总成、零部件和交互在生成过程中被发现遗漏，新增稳定 ID 节点及 Markdown 写集，不强行卡在这个表的“种子数量”；不为每个系统强制生成相同几篇。
- 同一机理跨系统出现时生成一次并引用；由 Integrator 对共有接口与不一致地方做归纳，不能让多 Writer 争用同一共享文件。
- **真实性限定**：此处结构只是“应研究的候选”，目前对具体车辆实物、部件目录及故障数据**没有独立专业事实核验**。
