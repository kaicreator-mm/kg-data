## 1. 把“驾驶者转弯”拆成四个不同物理过程

车辆转向不能简化为“方向盘转了，车轮便必然沿期望轨迹转弯”。必须区分：

1. **转向输入**：驾驶者施加方向盘角度/力矩，经过转向柱、转向器、拉杆和转向节，产生前轮（或适用转向轮）实际转角；机械比率、几何与弹性变形因车辆构型而不同。
2. **助力贡献**：HPS、EHPS、EPS 等在许可条件下提供附加作用，改变驾驶者所需操纵力，但**不会自动创造可用轮胎附着**，更不等于车轮角度传感器所读数值必然真实。
3. **悬架/车身响应**：车身质量、弹簧、阻尼、连杆、衬套以及载荷转移改变轮胎与道路接触时的载荷/姿态；这会影响驾驶反馈、方向稳定与舒适性。
4. **轮胎–路面力**：轮胎有侧偏角、侧向力与附着限制；极限依轮胎/路面、垂向载荷、温度及驾驶状态。驾驶指令只能在系统可用力的范围内形成有效横向加速度。

概念因果链：

```text
驾驶员方向输入
    ├── 机械转向柱 → 转向器 → 横拉杆/转向节 → 轮端转角
    └── (车型具助力时) EPS/HPS/EHPS 请求与可用助力 → 转向执行力
轮端转角 + 车速 + 实际轮胎/道路条件 + 悬架运动/载荷
    → 前/后轮侧向力及车辆横摆运动
    → 驾驶员感觉 / ESC 传感与控制（如果装备）
```

以上描述的是输入、正常机理和输出，不是车辆 OEM 操纵稳定性模型；**实际横摆率不是方向盘转角的固定函数**。

## 2. HPS、EHPS、EPS 正常助力：能量来源与执行形式不可混同

| 助力型式 | 输入与能源 | 正常机理 | 适用条件及反例 |
|---|---|---|---|
| HPS 液压助力 | 方向盘/转向阀请求、由发动机或其它机械源驱动的液压泵、储液/压力调节 | 液压回路按相应转向器和阀的设计产生可减轻驾驶者输入力矩的辅助作用 | 发动机转速、油温、供压/阀体/执行器与机械阻力共同决定实际感觉，未装备 HPS 的 EPS 车没有同一液压泵 |
| EHPS 电液助力 | 低压/其它供电、电机泵控制、液压齿条/阀体 | **电机驱动液压泵**提供液压能，转向器内仍由液压执行助力 | “电动泵”不等于纯 EPS 无液压油；电机电源与液压问题可以分别影响功能 |
| EPS 纯电动助力 | 驾驶转向力矩/角度、ECU、适用车速/状态、电力和电机 | 控制器在指定车型许可范围驱动电机，经柱式/齿轮式/齿条式机构增加辅助力矩 | 电机位置并非固定在齿条；失去电动助力也不能在没有 OEM 失效分析时许诺车辆仍可安全操控 |
| 手动转向或特殊架构 | 驾驶者直接机械输入、结构许可 | 无专门助力电机/泵时仍存在机械几何传递 | 不能把“没有 EPS 电机”当异常，也不意味着助力类别明确的车型全采用同一转向比 |

Bosch 对 EPS 多种实现形式的原始资料支持电机与控制器存在不同机械耦合方式；ZF/TRW 的 EHPS 原始材料支持“电驱液压泵＋液压执行”的技术结构。二者只是*技术家族存在*的来源，不证明特定 Probox/Fit 实装哪一种。

### 2.1 EPS 控制输入、输出与反馈不是同一量

`T_driver` 是驾驶者输入；`T_assist_command` 是控制器请求；`T_motor_actual` 是电机真实输出；转向器/路面机械阻力决定最终轮端响应。可用概念关系 `T_steering_effective ≈ T_driver + T_assist - T_loss` 解释辅助作用，但**并非可用于工程标定的车型扭矩方程**，也不适用于所有机构/测点的直接相加。

典型辅助目标可能随车速、方向盘扭矩、温度/低压状态、转向角和车辆行驶模式变化；某 EPS 车型低速时提供更明显操纵力减轻，不表示所有车辆的助力曲线或传感器、软件均相同。

**反例**：驾驶者感觉转向沉重，可能由助力不可用、轮胎接地载荷/气压、机械连接、悬架/轴承影响；单独的 EPS 警告或一个车速信号不能直接确诊助力电机损坏。

## 3. 车轮转角与转弯几何：理想运动学不等于真实路面路径

在低速、近似无侧滑的几何简化模型中，转向轮角度、轴距与路径曲率可以关联：`R ≈ L / tan(δ)`（理想单轨/bicycle model；`R` 为近似转弯半径，`L` 轴距，`δ` 等效转向轮角）。这不是用于实际 Probox/Fit 的转向半径计算式：真实轮胎侧偏、前后轮转向几何、Ackermann 条件、悬架弹性和车速等会偏离简化模型。

两侧转向轮在低速转弯时通常承担不同半径，几何可能为不同转角；“方向盘角度”还需通过转向器传动比、可能的可变比率、机械游隙及控制装置才能关联具体车轮角度。高速极限时，轮胎侧向力及车辆动态主导路径，不能据此推算安全转弯速度或操作策略。

## 4. 弹簧、减振器与导向机构：储能、耗能、约束三件不同的事

| 悬架组 | 输入 | 正常作用 | 不应推出的结论 |
|---|---|---|---|
| 弹簧/弹性元件 | 车身垂向载荷、轮端相对位移 | 提供弹性支撑与恢复力，暂时储存/释放机械能 | 车身每次弹跳都等于弹簧损坏；弹簧能取代阻尼器 |
| 减振器 | 悬架相对位移速度、内部液压/阀体条件（按结构） | 将部分相对运动能量耗散，抑制车身持续振荡 | 阻尼器“越硬越安全”，或减振器承担所有承重 |
| 支柱 strut（若装） | 车身与轮端运动/载荷、导向约束 | 一部分构型中同时参与减振和结构/导向承载 | 所有 Shock 与 Strut 可以不区分互换 |
| 控制臂、连杆、衬套、球节 | 轮端垂向/横向与转向运动 | 约束运动轨迹并传递载荷，随几何影响车轮外倾/前束变化 | 没有 OEM 车型结构便能推导四轮定位数值 |
| 稳定杆（若装） | 左右轮悬架运动差 | 通过扭转弹性对侧倾/左右轮运动差提供约束 | 所有车型都装有稳定杆，或装后可忽略独立轮胎附着限制 |

简化的质量–弹簧–阻尼模型 `m x¨ + c x˙ + kx = F(t)` 可以说明**弹性储能** `kx` 与**速度相关阻尼** `c x˙` 的职责差异，但车辆悬架有非线性几何、载荷与轮胎特性；本式不用于计算某车弹簧常数、减振器阻尼值、承载上限、定位或维修选择。

Monroe 的公开说明区分 Shock、Strut、弹簧与支柱在结构定位中的作用；单靠零件图示不能推断某缅甸车辆安装方案。

## 5. 载荷转移、转向、制动和轮胎的耦合

车辆转弯、加速、制动时，轮端垂向负荷和轮胎纵/横向力可发生变化。**轮胎附着不是两个互不影响的无限力源**：制动纵向力、驱动纵向力与转向侧向力均受轮胎–路面接地条件共同限制；ABS/ESC 的功能可以在约束内调节请求，不能改变道路摩擦极限。

| 工况 | 合理的正常变化 | 重要反例 |
|---|---|---|
| 低速泊车 | EPS/EHPS 可通过助力减少方向输入所需力，轮胎与地面仍产生阻力 | 驻车转向较重不自动证明助力电机损坏；不应据此开具维修任务 |
| 直线通过起伏路 | 弹簧与阻尼器吸收/耗散不同部分的能量，悬架导向影响车轮位置 | 车身波动不等于“只有减振器负责” |
| 车辆入弯 | 方向输入改变轮端角度，轮胎侧向力产生横摆/向心运动，悬架承担载荷和姿态变化 | 侧向力受附着、载荷与动态约束，轮端角度不保证横摆符合指令 |
| 制动入弯 | 制动产生纵向力请求、转向产生侧向力请求，可用附着有限；载荷和姿态同时变化 | ABS 可以调制滑移但不保证总能缩短所有路面制动距离 |
| 低附着或轮胎异常 | 轮胎–地面力限制路径跟随与稳定，EPS 可以仍然正常助力 | “EPS 没报码”不等于轮胎附着足够或悬架几何正常 |

已审 [制动正常功能](../braking/function.md) 和 [制动失效链](../braking/failure.md) 为跨系统知识复用，不把制动下游错误引入当前转向功能 Task DAG。真实驾驶/制动安全需要匹配 OEM 数据和专业人员判断。

## 6. 助力、机械游隙和轮胎条件的竞争解释

| 观察 | 可同时成立的机制假说 | 能反驳“单个零件直接致故障”的信息类别（非作业指令） |
|---|---|---|
| 方向盘转动费力 | HPS/EHPS 液压/电源，EPS 电力/状态，机械连接阻力与轮胎接地 | 车辆实际助力类型、低压/控制状态、机械运动与轮胎状态 |
| 方向盘偏斜或车跑偏 | 轮胎不对称、道路坡度、制动拖滞、转向几何、悬架衬套/变形等 | 是否确实由制动产生不等力、同工况轮胎和几何证据 |
| 颠簸后异响 | 连杆/衬套、支柱/减振器、弹簧、轮胎、轮毂轴承或路面激励 | 来源定位/实际配置与运动条件；DTC 不一定覆盖所有机械运动 |
| 操纵感随速度变化 | 助力策略、轮胎侧偏特性、车身/载荷和悬架动态 | 没有厂家 EPS 曲线与轮胎/运动证据，不能由主观手感作唯一结论 |
| 制动时车身点头/偏航 | 正常载荷转移、左右附着/制动力、悬架阻尼/导向 | 没有实车制动/轮胎/悬架证据，不把正常载荷转移当损坏 |

这里的研究目标是保持因果可证伪性，不是现场“试车检查”；**危险路试、拆装带储能弹簧、轮端悬挂作业、转向角标定等全部不在本阶段内**。

## 7. 缅甸车型系列适用边界

- **Probox/Succeed**：其具体底盘、装配年份与市场进口版次可能改变助力型式、悬架前后结构和轮胎规格。当前没有能把某一辆 VIN 映射到助力泵、EPS ECU、轴承、定位角和零件号的 OEM 完整证据；`OEM_STEER_VARIANT=UNKNOWN`、`ALIGNMENT_LIMIT=UNKNOWN`。
- **Honda Fit/Jazz GD/GE 等**：车型代际可能使用不同机械/电子助力、悬架配件、轮胎与制动系统；“Fit”不是唯一底盘，IMA/i-DCD/e:HEV 不宜无证据合并配套部件。
- **其它 ICE/HEV/BEV**：仅可共享力学和架构级助力/悬架机理，不能把某供应商的列车式 EPS/控制系统或电动汽车的高压供能形式直接套到缅甸传统汽油车。
- 对 VIN、车型完整底盘/出厂版本、市场配置、助力驱动/ECU 及匹配 OEM 参数未被证实的，`PART_FITMENT`、`STEERING_TORQUE`、`TIRE_PRESSURE`、`SPRING_SPEC`、`DAMPER_FORCE`、`REPAIR_PROCEDURE` 全部 `UNKNOWN`。
