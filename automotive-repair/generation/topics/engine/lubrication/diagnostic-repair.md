## 1. 维修判断的目标不是“油压灯亮就换泵”

同样的油压报警、热态敲击、油温升高、VVT 反应异常或启动时异响，可能跨越四种不同证据对象：

1. **真实润滑能力**：储油/吸入是否足以持续为泵供油；泵的可供流量、泄放、滤清、支路流动与回油是否符合对应设计。
2. **测点压力**：指定油路位置在指定温度、转速、负载、泵控制工况下的物理量；不能与某轴承局部动压油膜画等号。
3. **信号与控制**：压力开关/连续传感器、供电/接地/线束、ECU 条件判断和仪表提示；显示/报码可以与实体量不一致。
4. **损伤结果**：运动副表面、轴承间隙、局部热损失、滤材/油液污染等可能已受影响的对象；即使信号恢复正常，既有损伤也可能没有消失。

**安全停用条件**：行驶中出现持续或明确的低机油压力警告、严重机械敲击、明显润滑失效或过热嫌疑时，应安全停止使用并交由具备资格的维修人员按对应车型手册处理。**不得**依据“再开一会儿看是否复现”、人为升高转速、在故障状态下路试、绕开油压报警或用本文提供的概念判断继续运行安全。本文不给机油测压接口、设备连接、拆装、液体加注、转速/温度测试程序或合格数值。

## 2. 从现象到竞争假设：证据需要什么区分力

| 观察 / 研究问题 | 重要竞争解释（仅为候选） | 有区分力的证据类别 | 误判与反例 |
|---|---|---|---|
| 启动后油压警告或响应迟滞 | 储油/入口供油、滤清器防回流、油温黏度、泵/调压、压力开关或仪表逻辑 | 真实机型、状态/持续时间、油路结构、物理量与信号一致性、维护历史 | 灯点亮不等于油泵实体坏；信号恢复不证明此前无缺油 |
| 热态低转速报警 | 温度/黏度、正常可变泵压力目标、间隙漏流、泵效率、提前泄放、传感偏差 | OEM 规定温度/转速/负载与阈值、实际泵策略、测点信号可信性 | “热态压力较冷态低”不自动为故障；不能借用另一车型阈值 |
| 高转速或负载变化时异常 | 入口受限/吸气、实际泵能力、调压阀控制、过高流路阻力、传感延迟 | 事件时间关系、真实转速/负载/油温、来源明确的压力变化 | 压力不随转速线性上涨可能是设计调压，不足以定泵损坏 |
| 压力看似正常但机械局部噪声 | 局部油道或喷嘴供油不足、轴承间隙/表面损伤、噪声来自非润滑部件 | 实装油路拓扑、损伤部位与声源证据、滤材/介质污染证据 | 主油道压力合格也不能保证每个运动副足量供油 |
| 低压且油温异常升高 | 热负荷、冷却器/散热路径、油品劣化或稀释、泵/轴承间隙、传感链 | 温度与压力先后次序、相应冷却回路状态、油液真实性 | “温度高→泵坏”与“泵弱→油温高”均不可从静态截图唯一确定 |
| VVT 执行偏差与油压问题并存 | VVT 控制阀/相位器支路、总供油、线束/控制请求、机械卡滞 | 该机型是否具有 VVT、请求/允许/实际位置区别及油路结构 | 单独 VVT DTC 不是总油泵或相位器必坏的证据 |
| 机油或滤材发现颗粒 | 运行磨耗、局部轴承损伤、污染、过滤失效、此前维修残留 | 材料/尺寸/时间演化与实际发动机部位的可信关联 | 油液深色不等于报废；颗粒不单独指向某轴承或油泵 |
| 没有任何报警但疑似润滑不足 | 传感器类型、测点覆盖不足、局部堵塞、信号或警告逻辑缺陷 | 警告系统监测范围、原厂控制逻辑、部件损伤/供流独立证据 | “没报码＝所有部位油膜安全”不成立 |

真正的鉴别不是增加候选数量，而是找到**能让不同解释产生不同预期结果的证据**。上述证据维度供具资质的人员按相应 OEM 程序获取和解释，不代表本文授予任何危险测试方案。

## 3. 对主要竞争原因建立可证伪条件

| 机理候选 | 若成立应解释哪些证据 | 哪些观察会削弱此假设 | 仍不能推断 |
|---|---|---|---|
| `LUB-F01/F02` 储油与吸入连续性问题 | 供油能力可能随油量、姿态、入口阻力和气体混入而变化 | 与吸入问题无关的实体信号错误，或更局部/独立的支路证据 | 不能仅凭一次油位显示断言吸入网、油底壳形状正常 |
| `LUB-F03` 泵内部/驱动或可变泵控制能力下降 | 在允许工况下可能有供流余量不足，与下游压力/分配变化相符 | 明确的单测点传感/电路错误，或者已知允许的正常压力调节状态 | 不能仅凭“低压”决定更换泵 |
| `LUB-F04` 主压力调节异常 | 可能表现为过早泄流、供压不足或过压，随调节状态变化 | 仅滤芯压差异常、单个分支局部堵塞而主压符合预期 | **主调压阀≠全流滤清器的差压旁通阀** |
| `LUB-F05` 滤材/旁通问题 | 滤前后阻力变化、旁通路径对未过滤油和供流的不同影响 | 主压异常没有滤清器相关证据、传感信号归属不一致 | 不能把旁通开启视作“完全没油”，也不能当长期正常 |
| `LUB-F06` 局部油道受限 | 局部供流/温度/损伤信号可能不同于上游主压 | 实际损伤或温度更符合某独立机械源、油路图无对应支路 | 没有同机型油路不能臆测堵塞位置 |
| `LUB-F07` 轴承间隙/泄漏增大 | 热态、低速及负载影响可能与局部漏流及油膜情况相容 | 完全独立的线束假警、明确不相关的机械噪声 | 温机压力偏低不构成轴承已磨坏证据 |
| `LUB-F08/F09` 油品热态/污染及换热异常 | 油液性能、热负荷、冷却回路或回油变化与时序相符 | 所谓升温仅源于温度信号偏差，或相关冷却结构根本未装备 | 不能凭某油色、品牌、季节擅自制定油品与处理方式 |
| `LUB-F10/F11` VVT/涡轮/活塞冷却等选配支路 | 该车确实装该部件；局部功能症状与真实支路关联 | 车型无该总成或正常控制并不请求该功能 | 不能把涡轮故障树套给自然吸气车型 |
| `LUB-F12` 传感器或通讯链 | 报警/显示与独立实体证据或逻辑状态不匹配 | 多独立物理部位同时存在缺油损伤，不能仅靠信号异常解释 | 发现传感器问题也不证明并存实体问题已经排除 |

**因果方向需验证**：机油温度变化、主路压力、局部油膜破坏、噪声与控制保护之间可相互反馈。没有时间序列、测点定义和原厂许可状态时，先后关系记为 `UNKNOWN`，不将相关性包装为唯一原因。

## 4. 概念决策树：证明/排除，而非现场步骤

`症状 / 报警 / 实际风险`  
→ 首先判断是否触发安全停用与专业移交（严重低压警告、敲击、过热等优先停用）  
→ 明确实体车辆身份：架构、发动机/油泵、过滤与冷却、传感器类型、实际 OEM 文档  
→ 将**可观察信号**、**被证明的真实油路状态**与**潜在既有机械损伤**分别记账  
→ 比较可同时解释当前证据的候选：入口、泵、主调压、滤材旁通、支路、间隙、黏度/热、液压执行、传感电气  
→ 仅当具可靠来源的证据能排除重要竞争解释，才由专业人员决定组件级维修方案  
→ 修复后应有与原症状/实体损伤一致的**独立完成验证**；控制信号恢复、灯熄灭或清除 DTC 不能代替实体供流/机械状态已恢复的判断。

这个决策树的箭头是知识层推理顺序，**不是拆检、测压、路试或施工顺序**；任何接触旋转/高温/油液或拆卸车辆需以该车型认可程序和相应职业安全措施执行。

## 5. 维修选项的合理性与误修代价

| 候选处理方向 | 必须先具备的因果依据 | 不能接受的“快速修复”推断 | 完成资格的证据需求 |
|---|---|---|---|
| 信号或仪表电气相关修复 | 已分离物理油路与压力信号/控制异常，并找到实际电气部位依据 | 换油压开关就意味着发动机润滑正常 | 物理风险被独立排除、信号在适用条件下恢复 |
| 供油/吸入回路修复 | 与该油底壳、吸口或油量保持相关的实际证据，排除单纯传感假信号 | 有油压灯就先换油泵，忽略入口空气/堵塞 | 重新成立持续供油及其对应风险闭环 |
| 泵与压力调节组件修复 | 供流/泵驱动/阀控异常且关键竞争原因受证据排除 | 更换油泵万能解决热态低压 | 与同机型运行条件匹配的压力/供流与保护状态证据 |
| 滤清器/旁通相关修复 | 对应型号、流路及滤材/旁通异常被确认 | 用更大流量或随意改变旁通设计代替 OEM 规格 | 正确供流/过滤功能并存，且污染后果得到考虑 |
| 运动副或机械损伤修复 | 可信的间隙、表面、污染或机械损伤证据；包括上游供油根因追查 | 只更换损坏轴承，不解决持续缺油根因 | 根因与后续损伤均得到独立验证 |
| 热管理或油品状态修复 | 实际装有相关换热件，油品与机型匹配，热/污染链与观察一致 | 根据颜色或网上推荐随意改机油规格 | 原厂允许的介质与热态、润滑风险判断 |
| VVT/涡轮等局部支路修复 | 证明相关总成存在、真实局部支路与其指令/状态不一致 | “VVT 报码＝换总油泵” | 局部执行问题及公共供油问题分别有完成证据 |

**风险与成本排序**：安全风险与不可逆机械损伤先于低成本替换便利性；在没有可靠故障频率、车型适用性、损伤范围和当地工时/零件来源时，`REPAIR_COST`、`FAILURE_PROBABILITY`、`PART_INTERCHANGEABILITY` 均是 `UNKNOWN`。不使用泛化“高发通病”与未经证实的诊断概率指导替换。

## 6. 三个容易造成误修的跨系统接口

- **低压电气与控制**：[FUN-LOWV](../../electrical-low-voltage/function.md) 已解释供电、唤醒、信号与实体输出分账。油压相关 DTC/灯可能受到供电、接地、信号或控制策略影响；这不能替代物理润滑风险排查。
- **发动机热管理**：[FUN-THERMAL](../../thermal/function.md) 描述机油、冷却液及环境散热之间的条件换热。高温与压力异常相伴不证明二者同一根因；油/水换热器两种介质原则上隔壁传热，不从“有油冷器”推断互相混流。
- **通用诊断证据**：[DISC-METHOD](../../common/diagnostic-methods.md) 区分 DTC、冻结帧、测量可靠性、证据来源与故障原因；这些链接是知识网络，不增加本 REP Task 的硬 DAG 前置。
