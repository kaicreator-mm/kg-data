## 1. 核心问题：泵送流量、主油道压力、轴承油膜不是同一个物理量

润滑系统的目标不只是让仪表显示一个数值，而是在运动副、热负载和液压执行器需要时提供适合的油量、流动、清洁度和润滑状态。把系统拆成四个层次：

1. **泵的供给能力**：泵的排量、转速、容积效率以及入口是否持续供油，决定可用体积流率。齿轮泵、转子泵等典型正排量泵的概念关系为 `Q_theoretical ≈ V_per_rev × n`；真实流量 `Q_actual` 受到内部泄漏、吸入条件、温度、控制排量和泄压分流影响。此式**不是**任何车辆的实测泵曲线，更不能由机油泵额定流量直接算出主油道压力。
2. **油道网络中的压力与流量分配**：主油道压力是供给、回流阻力、各支路泄漏/消耗和调压分流形成的结果。可用守恒理解为 `Q_pump = Q_bearing + Q_valvetrain + Q_actuators + Q_aux + Q_relief + Q_other`（忽略瞬态蓄积、具体测点与架构差别时的概念账本）。每条支路的压力、温度和通畅情况都可能不同；油道网络并不是一根零阻力管。
3. **轴承的油膜**：在适当的间隙、载荷、相对运动和油液性质下，旋转轴承可形成流体动压油楔承载载荷。**主油道表压不是轴承油膜内部产生的局部动压**。启动/停机、低速高载、局部缺油和高温条件可能处于混合或边界润滑状态。
4. **信号与控制**：油压开关可能只报低于某门槛的二值状态，传感器可能在某测点提供连续读数；某些可变泵有 ECU 控制目标。仪表警告、ECU 指令、测点压力、不同支路实际流动和金属接触状态并不互相等价。

以上四者必须在后续失效/诊断任务中分开，不能将“油压低=油泵坏”“油压正常=所有油膜安全”当作结论。来源：MAHLE 的油压调节技术说明和集成油管理实例，Donaldson 的主压调节及滤清策略，Castrol 的动压润滑技术解释（§9）。

## 2. 从储油到负载：正常运行条件链

以常见**湿式油底壳、机械驱动泵、全流式滤清**的典型概念为例（并非所有车型同样布置）：

| 环节 | 条件输入 | 正常机理 | 输出、限制或反例 |
|---|---|---|---|
| 储油和吸入 | 足够且在工作状态可用的储油、吸油口浸没、相对通畅的入口 | 油液由储油腔通过吸油滤网与吸入通道进入泵；泵入口与油底壳内流态相关 | 吸入气泡/入口受限会降低可实现的持续供给；“油底壳里有油”不等于瞬时吸入充足 |
| 增压与供流 | 泵转速、有效排量、容积效率、介质性质 | 正排量泵输送油液，克服油路阻力 | 空转无负载不代表真实压力；泄漏/空化/泵调节可改变供流 |
| 调压与分流 | 出口/主油道压力、控制阀设定、控制策略 | 当适用的调压元件满足开启条件，部分油液绕行/返回，从而限制过高压力或实现需求调节 | 主调压阀**不是**滤清器旁通阀；开启位置/返回位置依 OEM 设计 |
| 全流过滤 | 滤材压差、油温、流量需求及滤芯状态 | 正常情况下油液通过滤材捕获污染颗粒；适用时滤芯的差压旁通允许减少流动阻力 | 旁通可能让油绕过滤材，但不等于绕过全部轴承；不应据此宣称“不需要过滤” |
| 温度调节 | 发动机热状态、油温、换热器与温控/旁通结构 | 机油与金属、冷却液、空气（按架构）进行换热，影响黏度与热负载 | 不带独立油冷器不必然异常；油水换热器通常不使两个回路直接混合 |
| 主油道分流 | 主油道压差、支路阻力、轴承间隙、VVT 等负载 | 各负载在压力差驱动下获得机油；部分油被作为 VVT/液压挺柱工作介质，部分用来润滑和带走热 | 测点主压正常仍可能存在局部堵塞；液压执行机构并非所有汽油机都有 |
| 回流和再供给 | 重力、回油通道与曲轴箱环境 | 油液从运动副或受控排油口返回储油腔，再经吸入端进入循环 | 停机、过度倾斜及干式油底壳必须改用对应结构分析 |

该表是 **输入→机理→输出/反例** 的知识链，不是维修步骤、测量点指定或 OEM 油路顺序。

## 3. 黏度、温度、供流阻力与油膜：为什么压力不能脱离工况

### 3.1 冷油与热油

- **冷起动**：机油常较黏稠，流道与滤材的压降可能较大；泵出口或某测点压力可较快升高，甚至触发调压或滤芯差压旁通，但这不证明所有狭窄支路已经同步达到足够流量，也不证明局部油膜立即处于稳定动压状态。
- **温机**：温度升高通常使同一机油在相应工况下黏度下降；支路流量分配、泄漏及泵调压状态可能随之改变。某测点压力比冷车低**不自动说明故障**；是否异常需要 OEM 指定温度、转速、负载、测点及限值。
- **持续高负载**：轴承载荷/速度、涡轮/活塞冷却等负载热量可上升；需要同时考虑油液供给、换热与膜稳定性。压力高不等于油温合理、油品没有污染或局部油膜足够。
- **频繁启停或混动**：机械泵在发动机停转时的行为不同于运行中；是否配置辅助泵、止回、预供油或控制策略须由对应引擎与混动架构证明，不能用一般湿式汽油机推定 IMA、i-DCD、e:HEV 的实际做法。

**定性关系**：在理想、稳定、层流、恒定几何的圆管中，泊肃叶模型 `Q = π r⁴ Δp / (8 μ L)` 可说明在相同压差下，黏度 `μ` 越高、有效半径 `r` 越小，流量越受限；但发动机复杂轴承间隙/回路、不同温度油液、泵泄压与流态、分支及瞬态并不满足这个简单模型，**不得拿它直接算车型油压、油膜厚度或滤芯压差**。

### 3.2 油膜的物理分类

| 状态 | 可解释的物理机制 | 不能推出的结论 |
|---|---|---|
| 流体动压润滑 | 相对运动与收敛油隙形成承载油楔，油液黏度和表面几何影响膜形成 | “主油道压力高就是油膜承载高” |
| 混合润滑 | 部分区域保持流体膜，部分微凸体发生接触；常与速度、载荷、温度和边界条件变化有关 | “一旦混合接触便能确定某个零件损坏” |
| 边界润滑 | 微凸体接触占比增大，表面层与添加剂化学作用可能参与降低磨损 | “所有停机或启停的发动机都有同样的失效趋势” |
| 局部喷射/飞溅与冷却 | 喷嘴、油滴或甩油对特定部位带来润滑与带走热量 | “有油压传感器就能监测喷嘴喷油量” |

此处为一般润滑学概念；具体轴承安全系数、临界油膜厚度、发动机的允许油品黏度与压力工况须 OEM 指定。

## 4. 两种旁通、两个压力信号：防混淆的因果规则

| 名称 | 受什么影响、目的是什么 | 如果误解会造成什么诊断偏差 |
|---|---|---|
| **机油泵/主油压调节或泄压通路** | 依泵/主油路压力、弹簧和部分电控策略，对供流/压力进行限制和分配 | 看到高压力就当“泵越健康”；把调压堵塞误解为滤清器滤芯堵塞 |
| **全流滤清器差压旁通** | 主要受滤材上游与下游**压差**、设计阈值及油液流动条件影响，在某些设计中允许绕过滤材以避免供油严重受阻 | 把旁通开启说成“所有油路无流量”；或把冷启动压差误当滤清器已损坏 |
| **滤清器防回流装置** | 某些设计在停机时降低油液反向排空，影响再启动时滤清器/上游充油状态 | 把防回流阀当成压力调节阀，或假设每个滤清器都有相同结构 |
| **ECU 目标压力 / 泵排量指令** | 某些可控泵在工况控制下改变供给目标 | 把控制命令当成实测压力，忽略传感器类型和闭环/开环差异 |
| **仪表油压警告/测点压力** | 只有传感点与判定条件所在的信息，不是全油路的实体真值 | 用“无报警”断言所有运动副无缺油或润滑异常 |

另需区分**全流滤清器自身的旁通阀**与某些重型发动机独立的 **secondary by-pass fine filtration**：后者可能将小部分油单独过滤后回油底壳，不是“全流滤芯堵住后打开的通道”。Donaldson 的原始资料特别区分这两种架构，不能把某重型柴油机的双滤示意当成 Probox/Fit 汽油机图纸。

## 5. 固定排量与可调油泵：控制目标不同于实现效果

| 泵/控制构型 | 可预期的正常变化（定性） | 明确未知 |
|---|---|---|
| 固定排量机械泵 | 理论供流能力随泵轴转速提高；达到调压区间后，额外供流可能被泄放；吸入与泄漏改变实际供给 | 精确泵/曲轴传动比、调压特性、某负载实际支路流量 |
| 可变排量机械泵 | 可在允许范围内改变每转排量，以随需求和工况调节供给与驱动功耗 | 调压是液压控制还是电控、目标压力区间、执行器失败保护 |
| 温度/工况响应型系统 | 在转速、温度、负荷等条件变化时协调油泵、温控或其它支路 | 是否存在 ECU 压力闭环、传感器位置、油冷器/旁通路径 |
| 具有专门辅助油泵/预供油的特定架构 | 可能支持特殊启停、动力总成或其它需求 | **不能**根据“混动”三个字推断就一定有电动机油泵 |

MAHLE 的可控油泵与油管理模块是**供应商技术案例**，可以证实这些技术方案存在，但并不等于所有汽油发动机、全部缅甸在用车型均装备。

## 6. 跨系统功能接口：电控、热管理与配气的相互影响

1. **油压/油温信号 ↔ ECU/仪表**：二值开关不能给出油压变化曲线；连续传感器也只能报告相应测点及采样工况，ECU 处理和故障报码还依车型逻辑。
2. **机油 ↔ VVT 与液压张紧/挺柱**：适用发动机中，同一介质可同时承担润滑与液压执行功能；某类正时响应问题也可能受控制阀、电磁驱动、机械相位器或实际油路的不同条件影响，不能单归因于机油泵。
3. **机油 ↔ 发动机冷却/热管理**：温度影响黏度与回路阻力，机油冷却/油水换热可相互影响热负荷。参见已审 [STR-THERMAL](../../thermal/structure.md)；不能将“冷却液温度正常”当成“油温正常”的全部证明。
4. **机油 ↔ 涡轮轴承/活塞冷却喷嘴**：仅对装备相关部件的架构成立；供油、回油、热负荷的功能与发动机整体循环相关，局部干扰未必首先出现在主压测点。
5. **机油 ↔ HEV 发动机运行状态**：不同代际的发动机启停、再启动及电机参与工作不同，不能由一般汽油机结论推断 Honda Fit 的 IMA/i-DCD/e:HEV 实际油泵或油液许可条件。

## 7. 正常现象、反例与未来失效分类的边界

| 观察或条件 | 可兼容的多种正常解释/异常假说 | 本篇不许直接下的结论 |
|---|---|---|
| 冷车时油压较热车高 | 同油品黏度变化、泵转速、调压/旁通工况、测点变化；也可能存在不适用油品 | “冷压高说明泵和滤芯均无问题” |
| 热怠速油压低于冷怠速 | 温度/黏度、实际怠速转速与泵控制、间隙漏流；若低于 OEM 限值则可能涉及故障 | “热车压力低必然需要更换机油泵” |
| 仪表没有油压警告 | 监测阈值未触发、监测点局部状态、传感系统与判定策略 | “所有轴承/涡轮/VVT 分支均已得到充分润滑” |
| 机械噪声与油压波动同时出现 | 油路供给、轴承负载、可变机构、传感误报、温度和其它外部因素 | “更换滤清器必定解决异响” |
| 高速或负荷升高时油压未线性提高 | 调压泄放、可变排量泵、油温变化或真实异常均可能 | “泵轴转速翻倍主压必须翻倍” |
| 滤清器差压旁通打开 | 冷油高黏度或滤材阻力等条件，依实际阀位置与设计 | “这是主油泵压力调节回路” |

**安全与诊断界面**：发动机若真实存在严重油压不足、机械敲击或高温等危险信号，应停止将本研究稿当作运行许可或操作指南，由具备相应条件的维修人员按正确车型 OEM 文档评估。本文不规定车型允许继续驾驶的条件、不提供压力数值、不建议现场测量口/拆卸动作。
