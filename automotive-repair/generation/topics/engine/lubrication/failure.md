## 1. 先明确“失效”不是症状名称

润滑相关的实际失效可以发生在**储油和吸入、泵送能力、调压与分流、过滤与冷却、局部油道、运动副、液压附件以及信号链**中。它们通过同一网络相互影响，因此一个仪表信号不能唯一定位根因。

将因果区分为四层：

1. **根本条件（Root condition）**：例如吸油口失去稳定浸没、入口受阻、泵内泄漏增加、调压阀卡滞、轴承间隙增大、滤芯压差升高、局部油道堵塞、传感器/线束异常。
2. **直接物理变化（Mechanism）**：实际进入泵的连续液流降低、主路流量分流变化、压力控制无法按要求调节、局部油流不足、油温/黏度变化、测量信号与物理状态脱节。
3. **受影响对象（Effect）**：某运动副油膜/散热条件变化、VVT 等液压执行响应受影响、整体油道测点压力异常或报警。
4. **可见现象（Symptom/Evidence）**：油压警告、某工况下传感器曲线、机械噪声、可变气门相位响应、油温变化、特定部位磨损迹象。**现象和根因之间不是一一映射**；并非每个失效都会立即报码或异响。

后续 `REP-ENG-LUBE` 才负责具体证据的鉴别价值与专业移交；本篇描述什么机制可能发生、什么条件下成立、哪些反例能够推翻单一解释。

## 2. 失效机制矩阵：同一油压异常的竞争原因

| ID / 可能部位 | 触发条件或候选根因（不是实车断言） | 直接机理及可能后果 | 可能观察与重要反例 |
|---|---|---|---|
| `LUB-F01` 储油不足或吸入中断 | 油量不足、工况下油液远离吸口、油底壳/吸口不匹配等 | 入口液相连续性不足，泵可能吸入空气/出现供给波动，下游实际供流下降 | 可出现压力不稳或机械润滑异常；**油量表面看似足够也不直接证明动态吸入持续充分** |
| `LUB-F02` 吸油网或入口阻力过大 | 入口污染/沉积、吸油管问题或高黏度极端工况 | 入口可供流量下降；泵潜在气穴/气体混入，供给能力波动 | 热/冷表现可依介质、入口位置而不同；**读到泵出口压力不等于所有入口状态已排除** |
| `LUB-F03` 泵能力降低 | 泵齿/转子磨损、驱动损伤、内部泄漏，或者可变泵控制未按需求工作 | 相同转速下实际供给能力下降，支路压差与流量可能减小 | 低压是候选而非特异征象；**同样低压可由 F01/F04/F06 或油温/间隙解释** |
| `LUB-F04` 主压调节失效 | 泄压阀或控制阀卡滞在过多泄放/不足泄放状态 | 提前泄流可能降低有效供油；无法泄放则压力峰值与负载增加 | 高压力并非必然健康；**主调压失效不可与滤芯旁通开闭直接等同** |
| `LUB-F05` 滤清与旁通异常 | 滤芯阻力上升、冷机高黏度、旁通卡滞或过滤介质失效 | 滤前后压差增大；若设计有差压旁通则可能减少过滤路径阻力同时让未过滤油绕过滤材 | **滤清器差压高不等于主压必须低**；旁通开启不一定意味着下游完全无油 |
| `LUB-F06` 主油道或支路受限 | 局部沉积、异物、管孔局部堵塞、分支热/机械问题 | 测点上游压力可维持甚至升高，但局部流量与散热不足 | **主压正常不能排除局部缺油**；没有对应油路图不能推出堵塞位置 |
| `LUB-F07` 轴承间隙/漏流增加 | 运动副磨损或不适配几何导致漏流路径加大 | 同供给条件下局部漏流增加，相关压力与油膜条件改变；某些工况更明显 | 可能在热机低转速工况反映；**热怠速压力低本身不是轴承损坏的直接证明** |
| `LUB-F08` 油温/黏度与污染异常 | 过热、燃油稀释、水分/颗粒污染、使用条件与油液适用性不匹配 | 黏度/膜形成能力、腐蚀磨粒及过滤负荷改变；多系统同时受影响 | 未有油品与发动机资料时不能把某商业机油牌号或季节气温当根因 |
| `LUB-F09` 冷却与回油不足 | 冷却器换热不足、回油通道受阻，或特定涡轮回油条件改变 | 高温、局部积油/回油不畅、分支润滑与散热受影响 | 主油道压力可未明显异常，**油温/回油问题不能只由主压判定** |
| `LUB-F10` VVT/液压执行支路异常 | 机油控制阀/相位器或专用通道堵塞、控制命令错误 | 执行器未达到要求位置/动态，可能产生机理相关的报码或性能异常 | **VVT 响应异常不等于总泵压力异常**；机械、电控与测量竞争原因需分开 |
| `LUB-F11` 涡轮或活塞冷却等附加支路 | 仅在相关组件真实装备时，局部供油/冷却/回油受阻 | 局部轴承过热、润滑/冷却降低而主回路其它对象可能仍供油 | **涡轮相关机制不能推广到自然吸气机型**；没有喷嘴或涡轮的车辆不适用 |
| `LUB-F12` 传感器/信号/逻辑异常 | 油压开关、测点传感器、线束、电源、ECU/仪表逻辑错误 | 仪表报警或显示与真实压力脱节；也可出现传感器未感知局部缺油 | **没有报警不等于真实供油合格**，反之报警也不能唯一指认机械泵故障 |

表中是候选失效结构，不是某品牌/年份的零件必备清单或出现概率；没有真实可靠保有量与工单分母时，所有 `FREQUENCY=UNKNOWN`。

## 3. “低油压”至少分为三种不同逻辑事件

### 3.1 实际供油总量不足

入口断流、泵输出能力下降、过早泄放可能影响总供油。其根因并不都在泵本体：吸油网/吸油管状况、油液物理性质、机械驱动与调压状态分别属于不同上游位置。**不能从泵出口压降低直接推断更换泵能解决问题。**

### 3.2 总路读数变化，但不等于关键部位缺油范围

轴承间隙、温度、转速、负载及分支需求改变可影响测点压力；不同调压/可变泵策略会主动改变可见压力。某个测点“偏低”可能与设计工况和真实故障有关，必须有同机型 OEM 限值与测点的上下文。

### 3.3 信号报警与实体量不一致

仪表可能从二值开关/模拟传感器或 ECU 判定得到油压信息。若信号链异常，报警不必然意味着油道有同等物理异常；若局部支路缺流，主压开关也可能没有看到。故障树需包含 **实体异常** 与 **信号异常** 两个分支，而不是用单一 DTC 替代诊断。

**反例**：同样是“热怠速报警”，可能是油温/黏度与正常控制策略叠加、泵/轴承/泄压系统问题、油液/传感器偏差或线束；没有 OEM 与实测信息就不能判定单因，更不能说明“继续行驶一定安全”。涉及真实低油压、敲击与过热的风险由专业人员判定停用与检查。

## 4. 冷机、高温、高转速及瞬态工况如何改变失效表现

| 工况 | 合理的机理变化与风险 | 单一解释为什么可能假阳性 |
|---|---|---|
| 冷机/冷油 | 同油品黏度常较高，滤材及油道压降增加、调压与滤芯差压旁通条件可能改变；局部充油与动压油膜建立存在瞬态 | “冷态压力高”不排除局部流速慢、滤材旁通及吸入端不良；寒冷地区表现不能无条件套用缅甸实车 |
| 热怠速 | 油温升高通常降低黏度，泵转速相对低，间隙漏流和调压策略影响测点 | 热机较低的压力不自动代表磨损，更不允许凭普遍经验替代 OEM 标准 |
| 高转速/高负荷 | 需求与热负荷可能增加；供油、调压阀、支路分流及泵控制可能进入不同状态 | 压力不随 RPM 线性变化可能是设计调节，也可能是真异常；不能单看曲线斜率 |
| 坡道/转向/动态加速度 | 湿式油底壳内油面与吸口相对位置可能变化；是否影响由油量、挡油结构与具体几何决定 | 并非每台车辆都会动态缺油，也不能由一次弯道报警证明油底壳设计缺陷 |
| 频繁启停/HEV 电机驱动 | ICE 停转时机械油泵可能停转；再启动润滑取决于系统设计/控制和运行条件 | 不能假定所有 HEV 有/没有辅助泵，也不能把 BEV 纯电热管理故障归入汽油机机油循环 |

条件机理来自一般流体与热/润滑学、MAHLE/Donaldson/Castrol 的公开范围；不是已证明的现场车辆事故事件或失效率。

## 5. 结构耦合导致的“看起来一样、根因不同”

### 5.1 滤清器旁通 ≠ 主油压泄压 ≠ 独立旁路精滤

`FILTER_MEDIA_BYPASS` 在滤材压差过大时允许绕过滤材；`MAIN_PRESSURE_RELIEF` 对泵/主路压力进行调节；`SECONDARY_BY_PASS_FILTRATION` 则是某些发动机独立的小流量过滤支路。把三者混为一谈会导致失效树选择错误的因果路径。Donaldson 原始技术说明中这三者具有不同职责；其重型柴油机示例也不代表所有汽油机的结构。

**反例**：若滤芯冷态差压高导致正常旁通，不能据此写“机油泵主压调节阀卡在打开状态”；若泵泄压过多导致总供流不足，不能凭普通滤芯旁通状态必然检测到。

### 5.2 油压异常 ≠ 油膜必然异常的同一空间位置

主油道测点和曲轴轴承的动压油膜是不同物理量；尤其局部油孔堵塞、涡轮供油或回油异常，可能不首先体现为全局压力低。反过来某个测点低压也不自动证明每个支路发生了实质损伤。

### 5.3 机油与冷却液交互不是同一种故障

油水换热器（若有）通过热交换协调机油和冷却液温度；它们应作为不同流体回路建模。温度控制异常、回路泄漏、油液受污染以及油水非预期混合属于**不同候选机制**；不能把正常换热过程写成“机油与冷却液混合”。参见 [STR-THERMAL](../../thermal/structure.md)。

### 5.4 VVT/涡轮/活塞喷嘴不是所有车的通用必备故障位

有些机型没有涡轮增压或液压 VVT，有些车型的 VVT 控制和油泵调压方式不同。因此应先有实际车辆/发动机代码的 `HAS_COMPONENT` 证据，再建立该失效链；没有证据时标 `UNKNOWN`，而非误判为“肯定损坏”或“绝对不适用”。

## 6. 诊断价值导向的竞争假说和证伪条件（仅研究，不构成现场步骤）

| 假说 | 能够支持的概念证据类型 | 能降低或推翻该假说可信度的反证 |
|---|---|---|
| `H-SUPPLY` 泵供给不足 | 与泵速/负载关联的物理供流/压差、入口状况与系统结构相符 | 被可靠证据证明是仪表信号单独异常；或确认实际供给充分且问题局限另一支路 |
| `H-RELIEF` 压力调节异常 | 实际物理压力/调压行为与对应机型设计不一致 | OEM 条件内的可变泵目标本来就在变化、或只观察到了滤芯旁通 |
| `H-RESTRICTION` 滤芯/局部流道阻力 | 确认位置与流动关系的前/后差压或局部需求证据 | 无实际对应流道、没有滤芯压差证据、目标支路并不经过假设位置 |
| `H-BEARING` 轴承过大漏流 | 有具体运动副/工况和结构证据支持的漏流与磨损联系 | 压力异常能够独立解释为信号错误，或没有对应轴承机械证据 |
| `H-TEMP-OIL` 温度/油品/污染 | 可溯源的实际油温、使用条件、理化状态及适用油液规范 | 原假说需特定污染/过热却不存在相应可信证据 |
| `H-SIGNAL` 传感/线束/仪表 | 读数与对应实体测点不一致、信号路径有不可信环节 | 在同一合法工况下有可信实体压力异常证据，且不能仅靠信号错误解释 |

以上是证据**类型**而非教人执行油压检测、拆装仪表或车辆试验的操作清单。多个根因可以同时成立，不能因某个证据支持 H1 就排除其它所有故障。
