## 1. 三条相互依赖却不能相互取代的工作链

**低压供电链**：电池/发电机/DC-DC 来源 → 配电/熔断或电子保护 → 线束及公共回流 → ECU/传感器/执行器负载。电源存在不等于每个支路真实工作；高电流流过导线/接插件时的压降可能使负载端状态与源端不同。

**控制许可链**：驾驶/车辆状态、系统防盗/挡位/制动与唤醒条件（依架构）→ 控制器作出许可决策 → 负载驱动、供电使能或休眠。电池储能充分并不自动等于允许发动机起动或高压车辆 READY。

**数据通信链**：传感器/ECU 状态 → 网络消息传输/路由 → 接收 ECU 的控制算法及故障管理。消息不是功率流；发送请求不等于执行单元完成动作，收到 DTC 也不等于直接根因已经确定。

概念级状态表达：

```text
低压能量可用 ──> 相关 ECU 获得稳定供电
                         |
驾驶请求 + 状态许可 ─────┼──> 控制器决定唤醒、起动或电源路径
                         |
传感/网络消息 ───────────┴──> 监测执行与反馈 (若有)
```

此处是**功能依赖而非布线/控制时序图**；真实起动与 READY、网关唤醒、负载断电策略因 OEM 差异很大。

## 2. ICE：辅助电池、起动机与发电机是不同功率状态

### 2.1 未起动阶段与起动阶段

起动机把辅助电池的电能转为短时机械转矩，条件许可后使曲轴转动；但**曲轴被起动机驱动转动**不等于发动机已经稳定燃烧运行。实际许可和供能可能还取决于点火开关/按钮、起动继电器/控制器、防盗、变速器/驻车条件、发动机机械阻力与电源回路。

在起动期间，电池端的静态电压、实际电流供给能力、接地/连接电阻及电机机械负载是不同的物理量；某个“电池还有电”的指示并不能证明起动机获得足够的端电压和机械转矩。DENSO 原始起动机说明支持电池驱动起动电机的基本结构，但没有给出任何 Myanmar 车款允许的端子、起动条件或电压试验阈值。

### 2.2 发动机稳定运行阶段

典型发动机驱动交流发电机使用机械动力带动转子，配合整流和调节向低压网络提供电力；**发电机输出和电池净充放电是不同对象**：

```text
发动机机械功率 → 发电机电磁转换与整流/调节 → 车载低压网络
                                                     ├→ 当前负载
                                                     └↔ 辅助电池（补充/暂时放电）
```

可用概念守恒：`I_alternator + I_battery_discharge = Σ I_load + I_battery_charge`，只是某一方向符号与理想瞬态忽略后的账本，不是可直接作为维修测量的车型电流方程。发电机最大可用输出随转速、温度、调节目标等改变；低转速且大负载时，电池可能暂时分担供电。DENSO 原出版方明确解释这种负载超出发电能力时电池辅助供电的现象。

**反例**：发动机正在运转不能推断发电机一定工作正常；电池灯未点亮也不能证明低压所有分支均有足够供电；发电机有输出不证明实际电池已充满或电池健康。

### 2.3 智能充电与启停不能用固定电压规则判断

一些车辆可根据电池状态、温度、车载负载、回收/减速条件和能量管理策略改变发电机调节目标。不能以传统固定调节系统的经验值推断所有现代车型的正常值；带 48 V mild-hybrid/集成起动发电机的架构与传统 12 V 发电机/起动机不同，须以真实装车证明。

## 3. BEV：高压牵引储能与低压辅助供电的因果关系

DOE/AFDC 原始资料明确说明：典型 BEV 的 DC/DC 转换器将动力电池的较高直流电压转换为车辆辅助用电的低压电力，并为辅助电池补电。这不同于发动机驱动的交流发电机，也**不意味着**电驱高压域在任何 OFF 状态下都允许供低压电。

| 运行情境 | 正常功能逻辑（条件化） | 不得推出 |
|---|---|---|
| 车辆处于休眠或停放 | 低压电池可支撑钥匙/安全与必要唤醒等按车型策略工作的负载；部分模块降低工作状态 | 所有 ECU 均持续在线，或者主动力电池一定会自动补充低压电池 |
| 有合法车辆唤醒请求 | 辅助低压使相关控制器执行状态判断，视许可申请牵引域和 DC/DC 工作 | `READY` 未成立就证明高压包损坏 |
| 高压域允许 DC/DC 正常工作 | 转换器按允许的功率/电压条件供给低压负载并补充辅助电池 | DC/DC 输出正常即动力电池全部健康；或可据本文接线 |
| 充电或热管理运行 | 部分低压控制/泵/风扇/网关可能参与高压充电、散热、通信 | 每辆 BEV 都有相同停车补电、充电期间低压电源管理逻辑 |
| 高压故障或限功率 | 控制器可能限制某些供电支路/请求，低压基础供电与高压授权存在联动 | 所有报警都源自 DC/DC；或故障关闭等于高压可以安全接触 |

参见既有 [BEV 高压功能研究](../electrified/high-voltage/function.md) 与 [高压结构](../electrified/high-voltage/structure.md)。该连接只表示跨系统机理引用，不授予高压测量、分离、救援或接触权限。

## 4. 供电分配、熔断与回流：为什么“有电”不等于“能用”

**供电电位需要回路**：电源经配电与负载，最终通过设计规定的回流路径闭合。公共接地/连接点、线束/插头或熔断装置可能影响多个 ECU/负载，但多负载异常**并不必然**同一个配电点损坏。

**保险丝与电源开关不同职责**：传统保险丝是针对规定过流/故障条件的保护元件，不是为了以任意电流保护敏感半导体而精确动作的智能控制器。部分车辆使用继电器或电子开关选择负载供电；其控制端指令、输出状态、负载端的实际电源与保险保护需要区别。

**状态示例**：驾驶端“灯已打开”请求 → BCM 判断与输出驱动 → 灯具回路获得能量 → 灯具真实发光。这四个环节可能产生不同信息；某 ECU 的激活位不能替代灯具实际输出确认。参见 [车身/被动安全结构](../body-safety/structure.md)。

| 可见现象 | 可竞争的不同层原因 | 缺失何种信息时应 UNKNOWN |
|---|---|---|
| 多个灯具与车窗同时无响应 | 公共低压供电、回流、唤醒/BCM、网络请求或多个独立负载 | 没有实际架构、对应工况与实体/信号区别 |
| 单个执行器不响应 | 单支路供电/负载、控制器使能、机械卡滞或传感器状态 | 没有实际输出与机械状态证据 |
| 电池状态看似正常但启动失败 | 供电能力、起动许可、起动机/机械负载、控制器 | 未区分电源、许可和执行 |
| 发电机告警 | 调节/发电输出、电池/线束/信号监测逻辑 | 仅有仪表灯，没有系统物理资料与 OEM 判定条件 |
| BEV 不进入 READY | 辅助电池、BMS/高压功率许可、网关/唤醒、其它动力域状态 | 没有车型 H/V 结构及 OEM 故障语义 |

此表提供后续 `FAIL-LOWV` 的候选问题，不代表已生成其完整失效知识，也不是更换指导。

## 5. CAN、LIN、以太网与网关：消息条件机理

Bosch 官方中央网关介绍支持 CAN、LIN 和车载以太网等多种网络，并通过网关提供不同网络或控制域的信息路由与隔离。是否实际有中央网关、采用 CAN FD 或区控架构，必须由车型年代与配置决定。

| 层次 | 输入条件 | 主要正常作用 | 不能混同 |
|---|---|---|---|
| ECU 上电与唤醒 | 低压供电/回流、使能/睡眠策略、时钟/自身状态 | ECU 可执行本地逻辑并准备通信 | 上电不等于软件正常，也不证明收发器已能够收发 |
| CAN 消息传输 | 物理层、总线访问/帧内容、节点配置与时序 | 多 ECU 以消息共享请求、测量、状态 | 总线上某一帧是传感/ECU 信息，非独立机械真值 |
| LIN 局部通信 | 主从/调度式子网、局部执行器/传感器 | 低成本局部控制与状态传递（按适用架构） | 并非所有旧车门锁/窗电机都有 LIN |
| 车载以太网/网关（适用时） | 区域/域网络配置、路由与数据权限 | 在某些架构跨网络转发/选择连接 | 网关失联不唯一证明所有网络物理断线 |
| ECU 故障显示与诊断访问 | 协议支持、合法地址、网关路由、软件与低压许可 | 向合适设备/显示提供状态/报码 | 无 DTC ≠ 实体无故障，DTC ≠ 直接失效零件 |

**反例**：一个 ECU 不响应可能是睡眠、供电、网关过滤/隔离、不同网络版本、软件策略或真实网络/节点故障；不能仅用“通信故障”宣称线束损坏。网关不只是把所有 CAN 线直接短接的接线盒。Bosch 供应商产品存在也不证明某年 Probox/Fit 有车载以太网。

## 6. 状态与能量耦合中的四个常见错误推断

1. **“有蓄电池电压 → 起动机能转”**：电池的动态供流、低压回路、起动许可与机械条件不同。
2. **“发动机转了 → 发电机必然在充电”**：存在机械驱动或调节/整流/负载条件；低转速时可能由电池补差。
3. **“BEV OFF → 低压没有能源 / HV 安全”**：低压辅助电池可能仍供电，高压系统可能保留能量；OFF 不是现场作业许可。
4. **“DTC/U码 = CAN 导线坏”**：通信证据、控制器状态、网络访问与实体线束不是相同对象。

真实故障鉴别应再参考 [DISC-METHOD](../common/diagnostic-methods.md) 的证据层次，其限定知识质量已在独立 R13 通过，但仍不是 OEM/VIN 诊断工序；这个引用不建立额外 Task DAG 硬依赖。

## 7. 缅甸在用车市场与 OEM 范围

- **Toyota Probox/Succeed**：可能存在不同引擎/生产期/配电、保险/BCM/网络等结构；`ENGINE_CODE`、`ALTERNATOR_REGULATION`、`FUSE_MAP`、`GATEWAY_TOPOLOGY` 未有与车架对应的原始资料时标 `UNKNOWN`。
- **Honda Fit/Jazz**：传统汽油、IMA/i-DCD/e:HEV 在电机参与、辅助能源、起动和充电方式上可能不同；不得把旧汽油机皮带发电机与新混动的低压补电方案当成同一必备结构。
- **通用 BEV**：高压电池、DC/DC、辅助低压电池的功能是可复用层，但牵引电压、自动唤醒/充电逻辑、具体低压电池化学与诊断阈值不通用。
- **明确拒绝**：没有车辆实际 VIN/年份/市场/发动机/ECU 软件的准确版本与 OEM 维修资料时，不给任意电池电压合格线、保险丝编号、端子图、搭电方式、启动继电器操作、高压服务/救援程序或零件更换建议。
