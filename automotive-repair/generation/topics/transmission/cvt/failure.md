## 1. 先排除名称相似但机理不同的总成

| 家族与适用范围 | 主要机械传力路径 | 本文使用的失效机理 | 不可混用的知识 |
|---|---|---|---|
| **机械推式钢带 CVT** | 输入/输出锥形可变有效半径带轮 + 钢制推带/钢环，按实际设计需要供压夹持 | 带轮压力/流量、夹紧失效、传力接触、带轮磨耗、变比和传感控制失效 | 不能当成橡胶附件皮带，也不能把某油泵传动链视作主动力链 |
| **机械链式 CVT** | 两组变径带轮与专门传力钢链、链节/销与锥面接触 | 夹持裕量、接触、链结构动态、磨耗与比率执行等条件机制 | 具体链节/滚针/接触模式与钢带不同，不能套用钢带损伤形态或 OEM 标准 |
| **传统液力行星 AT** | 液力变矩器（若有）/行星排/执行离合器与离散挡位 | **排除**；作为加速迟滞、传动损耗的竞争解释 | 不能把固定档执行换挡问题称为 CVT 锥形带轮夹持故障 |
| **DCT** | 双离合器交替连接离散齿轮挡位 | **排除**；起步/接合抖动只作竞争原因 | 不把离合器磨耗或 7DCT 控制策略混成带/链式 CVT |
| **Honda e:HEV Electric CVT** | 双电机发电与驱动及条件化发动机直接驱动的电混动力路径 | **排除**机械带／链夹压失效树 | 标签 Electric CVT 不代表存在变径带轮、机械推带或主传力链 |

**关键反例**：Honda 官方的 2008 Fit CVT 技术论文同时涉及机械钢带与**油泵链驱动**；油泵驱动链不等于链式 CVT 的**主传力链**。Honda e:HEV 的 Electric CVT 也不能从产品名称推出同样的夹紧油路或带轮故障模式。

## 2. 功能失效应拆成五个互相反馈的变量

机械带/链式 CVT 并非只有“变速箱压力”一个状态。因果分析需要同时区分：

1. **发动机与起步耦合输入**：输入机械转矩、扭矩限制、起步离合器或变矩器等先决环节。
2. **目标有效传动比**：ECU/TCM 按工况、允许限制选择的变比，不是某一固定挡位。
3. **带轮有效半径/比率执行**：主从带轮轴向位置与实际机械变比。
4. **传力夹持容量**：带/链与锥面在实际载荷、接触/摩擦和油液条件下能够传递的转矩；它与比率执行相关，但不相同。
5. **油液、热、监测反馈与控制**：油泵、压力控制、密封、温度、信号、保护限扭与真实负载。

抽象链条：

```text
动力源转矩请求与实际许可 ──> [起步耦合] ───────┐
                                           │
目标速比 ──> [带轮执行机构] ────────────────┤
                                           ├──> [带/链–带轮实际传力]
所需夹持力 ──> [供油/调压/阀/密封] ─────────┤             │
                                           │         速度/转矩/热
润滑/散热/油温 ────────────────────────────┘             │
                                                      v
速度/温度/压力或估算状态 <────── 可信反馈与控制限制 ────┘
```

对特定机械式 CVT，在其它条件相同的简化条件下，夹持能力不足可能造成不希望出现的接触滑移和额外发热；**单独出现目标/实际变比不一致**则不一定是接触滑移，可能是控制、阀/机械执行、转速估算或信号不可靠。

| **F10 速度/压力/温度传感偏差** | 传感器、供电、信号线路、通信或估算模型错误 → 控制器看到的转速、压力、温度与实际不同 | 变比/夹持目标异常或合理性监测触发限制；日志可显示异常速比 | “计算速比偏差”可能只来自错误信号；**不是每款 CVT 都装实际压力传感器** |

| **F12 起步离合器/变矩器路径异常** | 湿式起步离合器、变矩器/锁止或起步附加齿轮（只在配置该结构时）出现不同耦合异常 | 起步抖动、转速差或延迟，可能被误判成带轮打滑 | 早期 Honda Fit 起步离合、2008 Fit 变矩器、Toyota Direct Shift-CVT 起步齿轮**不能跨代视为同一种结构** |

| **F14 电源、供电保护与控制通信异常** | 外部低压供电、通信或控制权限不满足 → 变比/液压指令异常或监测数据不可靠 | 间歇限制、故障灯、部分功能禁用，可能与机械故障同时存在 | 有 CVT 相关故障码不等于钢带/链或油泵实体损坏；需真实车型故障语义和源记录 |

### 3.1 夹紧不足、比率不追随和油温异常：不要压成单一根因

- **夹紧不足**是实际传力能力与需求转矩不匹配的问题；可能造成带/链局部滑移和发热。
- **实际变比未追随目标**首先是目标、执行和实际测量之间的差异；可能存在阀体/活塞动作受限，却并未发生持续带轮接触滑移。
- **油温升高**可能降低某工况的液压/摩擦裕量，也可能是先前的机械滑移造成的热损失，或控制器主动保护所观察到的正常高负荷状态。
- **同一症状不能证明时序**：先发生夹紧不足→滑移→升温，或冷却不足→热状态改变→夹紧能力下降，可能形成反馈环；需要时间一致的真实证据才能定向。
- **变矩器滑移与机械 CVT 滑移不同**：发动机 RPM 与车速并非一一对应，尤其在变矩器未锁止、起步离合器滑差和主动变比调节时。

### 3.2 钢带与链的接触差异

- 推式钢带通常由钢环及大量金属元件组合，带轮夹紧、接触压力、环带载荷与表面状态共同影响可传力；并非家用发动机附件的橡胶同步带。
- 传力链则涉及链节/销与锥面接触、动态路径及设计专属 NVH/磨损条件；不能将钢带推片磨耗直接描述为链节损坏。
- 油泵链、正时链和主传力链均可能被称为“链条”，却不在同一动力路径；Honda 2008 Fit 的油泵链不是 Subaru Lineartronic 等变径带轮传力链。

## 4. 从现象到证据的竞争性判别，而非“症状→换件”

| 研究性现象 | CVT 内部候选 | 重要的外部竞争原因 | 需有可信来源的证据维度（非现场操作步骤） |
|---|---|---|---|
| 起步转速高、推进弱 | F01、F12 | 轮胎低附着、发动机限扭、制动拖滞、下游断传 | 实际变速箱型号、起步机构、输入/输出速度的信号归属、控制请求与负载 |
| 加速 RPM 高且出现啸叫 | F01、F06、F07 | **正常 CVT 高转速功率策略**、轮端轴承/轮胎、发动机/附件噪声 | 有无真实目标变比偏差及机械带轮相对滑移、频率随源转速/车速的关系 |
| 热车后迟滞或限制更明显 | F03、F04、F09 | 发动机热保护、负荷变化、传感器热漂移 | 油液/控制状态与相同工况的时间序列，型式是否有压力温度信号 |
| “换挡”感觉突变 | F02、F05、F10 | 预设模拟挡位、油门变化、坡度/附着或起步锁止事件 | 实际机械比率、OEM 控制策略和起步方式；显示虚拟挡位不足以推断故障 |
| 驱动有噪声/振动 | F06、F07、F09 | 差速器、半轴、轮毂、轮胎、悬置、路面 | 具体动力链位置与频率、转速、负荷、温度的来源对应 |
| 油液中观察到颗粒 | F06、F07 或其他总成磨损 | 正常磨耗、终传齿轮/轴承、外部污染 | 需正规专业材料/来源识别；肉眼观察不能定责带轮或链 |
| 有故障灯、DTC 或保护 | F09、F10、F11、F14 | 发动机/低压电/通信/轮速等跨域故障 | OEM DTC 定义、原始状态和 Freeze Frame；DTC ≠ 失效根因 |
| 车辆失去驱动 | F01、F04、F12 | 发动机未出力、终传/半轴、控制禁用、制动/附着 | 源/变比单元/终传/车轮的实际状态与权限，不可简单推定整台 CVT 报废 |

**可证伪反例 A**：发动机在某加速工况维持较高转速，而车速平顺提升，可能正是正常 CVT 比率策略；没有真实目标/实际带轮比率证据就不能判定钢带打滑。

**可证伪反例 B**：某速比估算值突变同时存在轮速/输入信号异常，可能是传感或估算源问题；不能在传感数据未被可信核实前认定带轮机械滑移。

**可证伪反例 C**：出现高温保护与低驱动力，可能是热保护正常执行，不等于曾发生足以破坏带/链的滑移；反过来机械滑移也可使温度升高。

**可证伪反例 D**：某 Honda e:HEV 仪表上带“Electric CVT”名称，不说明装配有两组可变带轮、钢带、链和相应夹紧阀；故本篇机械链失效假说不能用于认定其故障。

**可证伪反例 E**：变矩器/起步离合器的转速差会使发动机转速与车轮速度脱钩，但 CVT 两带轮间仍可能按目标运行；发动机转速变化不是对夹压部位的直接测量。

## 5. 证据对象、身份与状态分账

每一个后续“确诊”必须先分账：

| 字段 | 示例或规则 |
|---|---|
| `architecture` | `MECHANICAL_STEEL_PUSH_BELT_CVT` / `MECHANICAL_TRACTION_CHAIN_CVT` / `UNKNOWN`；如果是 DCT/AT/e:HEV，**排除本任务** |
| `causal_hypothesis` | 例如 `PULLEY_CLAMP_CAPACITY_INSUFFICIENT`，仅为假设 |
| `mechanism` | 接触传力容量相对于输入转矩不足→非期望滑移及额外热 |
| `effect` | 可能传力不足/磨耗或噪声，损伤实际是否发生 = `UNKNOWN` |
| `competing_causes` | 输入耦合、控制限扭、外部电源/传感、下游车轮、轮胎附着 |
| `evidence` | 具体 OEM 传动总成、实际车型状态、原始数据可信性、专业复核；缺失均 `NOT_OBTAINED` |
| `qualification` | 本篇 `MODEL_GENERATED_UNVERIFIED`；不得自动为 `DEFECT_CONFIRMED` 或 `REPAIR_ADMITTED` |

- 症状/DTC 只能产生候选，不能唯一映射阀、油泵、钢带或变速箱更换建议。
- 没有车型手册时，压力数值、温度警戒点、油液规格、维修限值和“常见故障率”均为 `UNKNOWN`。
- 缺少实车数据时，不采用 AIAG/VDA 风险分数虚构维修市场失效率，也不把网上个例当作缅甸全国保有量故障分布。
