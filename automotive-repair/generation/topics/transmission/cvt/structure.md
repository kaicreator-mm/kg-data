## 1. 结构定义及为什么要另立家族

机械式无级变速器（continuously variable transmission）的目标是使发动机/输入端与驱动输出端之间在允许的工作范围内获得**可连续调节的有效传动比**，而不是依赖若干离散固定档位的行星齿轮选择组合来定义通常意义的每个换挡。机械变比技术存在多个实现路线；本稿以轻型车中厂商证据充分的**可变工作半径带轮/金属带式 CVT 家族**为主，不把“无级”当作某一个车型的标准部件清单。

这一结构的关键不变量是：**变比机构、起步耦合机构、最终减速/差速输出、液压执行/控制、油液/热管理并非同一个零件。** 尤其某个 CVT 可以有液力变矩器，另一个可以有起步离合器或额外起步齿轮；有变矩器也不能把整台 CVT 当作传统固定挡位行星 AT。

| 结构域 | 典型构成 | 正常关系 | 明确边界 |
|---|---|---|---|
| 输入及起步耦合 | 发动机输入、实际型号允许的起步离合器/液力变矩器或其它连接机构 | 将输入扭矩按启动车速、负载和控制条件耦合到变比机构 | 并非所有 CVT 都有同一种变矩器、起步离合或直接连接 |
| 机械变比核心 | 主/从动可变有效半径带轮、金属推动带或相应传力件（在适用车型中） | 改变两端有效工作半径，形成不同的输入/输出速度比 | 这是**本次来源支持的带轮家族**；不能自动把电气“e-CVT”视为这套零件 |
| 带轮夹持/液压控制 | 液压源、调压与执行元件、油路、传动控制器、压力/转速/温度相关反馈（因总成而异） | 提供执行力和可控变比条件，避免驱动力超过可提供的传递能力 | 油压、控制阀、限值、传感器位置和比例均按型号/工况具体定义 |
| 损耗/冷却/润滑 | 油液循环、摩擦/轴承/齿轮润滑、热交换器或其它传热路径（视总成） | 影响传力效率、可持续载荷和热状态 | 不能据“CVT”字样给所有车型指定油液型号、温度界限或补油步骤 |
| 输出与整车接口 | 终减速、差速器、半轴/驱动轮，及发动机扭矩请求、车速/制动等通信接口 | 将可变传动输出送往驱动轮，并与整车控制协调 | 2WD/4WD、终减速路径、控制网络与安全逻辑可能不同 |
| 辅助机构 | 起步齿轮、倒挡机构、特定锁止或其它机械子结构 | 可对特定工作区间/起步性能提供补充功能 | Toyota 2018 **Direct Shift-CVT** 有起步齿轮，不能赋予 Toyota 2014 Probox **Super CVT-i** |

### 结构图（抽象概念而非维修线路）

```text
发动机/输入扭矩
      │
 [起步耦合]  ← 型号条件：离合器 / 液力变矩器 / 其它
      │
 [可变比传动机构] ← 夹持/变比执行←液压/电控调节←转速、温度、负荷反馈
      │                  │
 [终减速/差速器]         └─> 润滑/冷却/热负荷
      │
    驱动轮
```

**图的合法用途**：表达装置的职责与输入/输出关系。**图的非法用途**：依图推断某车可操作的阀门、接头、压力测试位置、离合器接合表或高压/低压维修程序。

## 2. 厂商技术演化的真实对照

| 来源可见版本 | 被确认的实际差异 | 通用结构知识能保留什么 | 不允许外推 |
|---|---|---|---|
| Honda Fit 初代技术论文：**Multimatic S** | Honda 原始研发稿明确称 Fit 装配新开发的轻量紧凑 CVT | Honda 某时期存在带机械变比/起步方式的 CVT 家族，可作为历史技术锚点 | 不等于任意缅甸 GD1 的具体零件、润滑液或控制软件已证实 |
| Honda 针对 **2008 Model Year Fit** 的 CVT 研发论文 | 相比更早 Fit CVT，原厂明确描述**起步方式从起步离合器改为液力变矩器**、带轮间距变化、由链条驱动的油泵和相关控制改进 | **起步耦合不同，但仍是 CVT**；不能因为有变矩器就归入传统多挡 AT | 不以论文中的尺寸、改进百分比或软件控制参数指导缅甸某辆 Fit 维修 |
| Toyota **2014 日本 Probox/Succeed 改款** | Toyota 官方把适用的 1NR-FE/1NZ-FE 版本与 **Super CVT-i** 关联 | “CVT 家族”在该版 Toyota 日本产品线真实存在，与早期 4AT/5MT 有类别差异 | Toyota 此公告不是完整 CVT 内部剖视图；不能编造该型号起步齿轮或每个车型 CVT 内件 |
| Toyota **2018 Direct Shift-CVT** | Toyota 官方单独介绍在一种后续 CVT 上使用 **launch gear（起步齿轮）** | 显示同称 CVT 的不同代技术可以有额外机械分支 | **明确不得**将 2018 新技术特征倒填 2014 Probox 的 Super CVT-i |
| Honda **2020 e:HEV Electric CVT** | Honda 两电机混动以电机/发电机与部分条件下发动机机械直连等能量路径达成车速适配 | 是一个必须排除的词义反例，不等于普通带轮机械 CVT | 不得因表格写 `Electric CVT` 就宣称存在带轮/金属带/夹持液压 |

Toyota 与 Honda 上述发布资料的**市场版本主要是日本**，并没有逐条验证缅甸在用旧车的车架及实车装配。对 2014 与 2018 Toyota 技术名称不同的情况，优先保持明确的时点、装置范围，而不是营销名归并。

## 3. 部件—功能关系与跨层接口

1. **传动比调节**。在带轮/带式家族里，两个带轮的有效接触半径在约束条件下改变，输出速度/扭矩关系发生连续变化；真实有效比仍受输入扭矩、转速、摩擦/夹紧能力、机构几何与效率限制，绝非“无限连续、无限扭矩”。
2. **传力与夹持**。机构必须传递载荷，液压或其它执行机构既参与变比的调节，也可能承担维持有效传力所需的作用力；缺乏具体 OEM 数据不能推出“某传感器读数 = 必然的物理夹紧力”。
3. **起步与锁止**。起步离合与液力变矩器都可出现在不同 CVT 设计中，控制与机械边界有别。Honda 2008 技术论文提供该差异的直接实例。
4. **辅助起步齿轮**。Toyota 2018 Direct Shift-CVT 在低速起步阶段采用齿轮支路这一技术选择，说明某些 CVT 可能包含离散机械子结构；但核心 CVT 传动能力仍以其真实设计与控制切换决定，不能把所有 CVT 都标成“必有起步齿轮”。
5. **热和油液不是附属知识**。摩擦与执行产生热负载，润滑和温度状态可能影响持续传力和控制条件；油液规格和使用方法又强烈依赖真实总成版本，因此只描述作用关系，不给数值/油品。
6. **整车通讯/控制**。发动机扭矩请求、制动许可、传动状态等可能通过控制器联系；它们的具体总线、ECU、TCM 或传感器实现随车型，不由本篇确定。

## 4. 对正常工况、失效机制和诊断知识的适用性提醒

| 表面现象 / 条件 | 通用结构允许的竞争解释 | 常见错误归因（不得据此直接维修） |
|---|---|---|
| 转速改变而车速变化不显著 | CVT 可能正在调节变比、起步耦合/发动机扭矩和整车控制也有影响；需要真实工况信息 | 把**所有**高转速与相对低车速视作“金属带打滑” |
| 起步抖动/延迟 | 不同起步耦合机构、输入源、机电控制条件和驱动输出均在竞争原因集合中 | 不辨型号就说“起步离合器必坏”或“变矩器必坏” |
| 油液温度异常 | 载荷、热管理、液压/机械传力等多个因素可能相关 | 将某型号油温阈值/油压/补油步骤复制到另一 CVT |
| 诊断工具显示“传动控制异常” | 供电/ECU 通讯/实际控制状态与机械执行均可能涉及 | 把一个通用报码直接等于带轮损坏/换总成 |
| 广告只写 Automatic | 可以是传统 AT、CVT、DCT 等不同结构 | 根据缅甸卖家单一字段直接选用 CVTF、ATF 或车型维修程序 |

这些只划分**可能的物理问题空间**，没有开展任何实车诊断实验、故障率统计或专业 Oracle 判定。后续 `FUN-CVT-FAMILY` 才负责输入→机制→输出及条件下的正常操作，`FAIL/REP` 须另立已审任务，不直接执行现场维修。

- 跨系列共用的是机械式 CVT 结构知识、来源和排除反例，不共享具体油泵、带轮型号、油液、阀体、压力、零件互换、DTC、适配 VIN。
- `L4_MODEL_YEAR_BUILD_MONTH_FRAME_TRANSMISSION_CODE`、`REGION`、`OEM_SERVICE_VERSION`、`PART_REPLACEMENT_HISTORY`、`ACTUAL_MYANMAR_STOCK_SHARE`、`SPECIFIC_DIAGNOSTIC_PARAMETERS`：均为 **UNKNOWN**。
- 来源权限：用公开厂商研发/发布材料的原创归纳，不复制版权保护的维修图纸或付费手册。

**可证伪反例**：
1. 有液力变矩器就必定是传统多挡行星 AT——Honda 2008 Fit CVT 提供反例。
2. 每个 CVT 都有起步离合器——有变矩器或起步齿轮的变型。
3. 所有 CVT 都有 Toyota 2018 Direct Shift 的起步齿轮——2014 Probox 无此证据。
4. e:HEV `Electric CVT` 必定用带轮金属带——Honda 双电机混动架构不支持这种推断。
5. Toyota 和 Honda 都有 CVT ⇒ CVTF/阀体/软件/零件可互换——无专业适配证据。
6. 缅甸 Probox/Fit 挂牌标题写 Automatic ⇒ 知道具体变速器——卖家条目与实际车架未匹配。
7. 转速在加速时变化大 ⇒ CVT 某传力部件故障——正常变比控制和其它系统仍可能解释。
