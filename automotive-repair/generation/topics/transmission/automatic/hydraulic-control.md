## 1. 必须拆分的五种物理量

| 量或状态 | 是什么 | 为什么不可以与其它量等同 |
|---|---|---|
| **泵流量（可利用供流）** | 泵在实际转速、泄漏与结构条件下可提供的油液体积流率 | 有油压读数不代表冷却/润滑有足够持续供流 |
| **主油压（line pressure）** | 由泵、主压调节及系统负载共同形成的受控压力 | 油压不是一个车型恒定数值；压力高/低都可能依控制需求变化 |
| **执行支路压力/活塞力** | 阀体导流与控制阀向特定摩擦元件油腔供压，活塞力受有效面积/密封/回位等影响 | 电磁阀指令“接合”不等于油腔压力已建立或离合器足以传扭 |
| **变矩器充油及 TCC 控制状态** | 泵/调压与变矩器、锁止离合器的供排油之间的关系 | 变矩器内部泵轮负责液力耦合，**不是**变速器主油泵 |
| **冷却与润滑流量/热状态** | 把损耗产生的热量输送到换热系统，并给齿轮、轴承、摩擦副供润滑 | 可有不同支路、旁路、节流和温控阀；不能以主油压代替真实流量测量 |

在通用液压关系中，压力的建立需要流量与管路/阀/执行器等实际阻力/调节共同形成；内部泄漏可能消耗泵流量。本文不提供任何车型的“合格油压应为多少”或可操作油压测试程序。

## 2. 正常油液流路图：是功能网而不是串联万能线路

```text
储油区 / 吸油网或滤清
          │
      [ATF 供油泵]
          │
      [主压调节阀] ← 负载/压力要求/调节反馈
          ├── [阀体选择与调制] ──> [离合器/制动器油腔] ──> 回油
          ├── [变矩器供/排油控制] ──> [TCC/变矩器循环] ──> 回油/冷却支路
          └── [按型号的冷却/润滑/辅助油路] ──> [换热器/齿轮/轴承] ──> 回油
                                  ↑
                       油温、限制、热交换和流阻
```

**极重要**：上述是拆分五个功能域的抽象图；一些变速箱的**变矩器→冷却器→润滑**在具体部分油路是串联，一些回路有再调压、旁路、温控、不同反馈或别的节流分支。**不得依据这张图推断所有 AT 的冷却/润滑在主调压阀上游或下游的固定顺序**。Sonnax 专业技术文章正以具体油路实例证明主压调节阀状态可影响变矩器/冷却/润滑供流。

## 3. 液压供给和主压调节：有压力未必有供流

**阶段 A — 泵建立可用供流**：实际 ATF 供油泵从储油区抽取介质并提供流动驱动力。常见传统设计可能由变矩器轮毂/发动机侧驱动；若车辆有启停支持或混动辅助电泵/蓄压元件，停机供流状态需要单独看 OEM。发动机转速、泵容积、介质黏度、密封泄漏与支路负载都可能影响可用供流。

**阶段 B — 主压力调节**：典型调节阀通过阀芯平衡与供/排油、反馈压力或电控负载信号相互作用，在变化的工况下建立主压。Sonnax 主压调节教程明确强调油泵输出随速度变化且调压阀需要在动态条件中控制。**油泵的最大容积能力并不等于实际每一工作状态都允许同样供油**。

**阶段 C — 分配和执行**：换挡阀、液压板、先导/压力控制电磁阀等把受控油流送到指定离合/制动活塞。电控指令 → 阀芯位置/先导压力 → 油路阻力/充油量 → 活塞实际接合力 → 对行星机构的运动约束；中间任意阶段均不能由上游“已命令”自动得出下游“已接合”。

**阶段 D — 各支路耦合**：变矩器、冷却器、润滑分支也消耗泵供流，某些设计的主调压阀位置决定这些分支的可用流量。主压读数可因调节保持在目标附近，而某分支供流不足仍属待鉴别的情况。不得把“主油压合格”当作“润滑、变矩器 TCC、换挡全部健康”的证据。

## 4. 从 TCM 控制到机械结合的完整功能链

| 阶段 | 输入/条件 | 预期状态转换 | 未建立时的竞争解释（非实际故障判定） |
|---|---|---|---|
| 驾驶者选挡/整车负载与控制目标 | 真实挡域、转速、发动机扭矩与控制许可 | TCM/PCM 选择合法换挡/锁止/调压目标 | 目标未下达、传感器/通讯/许可条件不满足 |
| 电控压力/换挡阀执行 | 电源、可用油流/主压、控制阀与先导压力 | 形成特定的阀芯/支路供油状态 | 有电流/指令不等于机械阀必动作，亦可能是液压支路不满足 |
| 指定离合/制动活塞建压与充油 | 阀体实际油路、容积、密封、活塞位置 | 摩擦片建立接触与规定转矩容量 | 流量不足、泄漏、回位/摩擦负荷等机理可能竞争 |
| 旧/新摩擦元件交接 | 挡位接合组合、实际发动机与变矩器扭矩 | 形成新的行星约束、实际变比输出 | 旧元件提前释放/新元件未建立，导致输出暂时不足或冲击 |
| 换挡后稳定运行 | 油温、密封、润滑/冷却和控制反馈 | 继续保持允许的摩擦传扭与热状态 | 某个瞬态主压不代表所有时刻正常 |

实际活塞的摩擦力/扭矩容量与油压、有效面积、摩擦副/钢片状况、回位弹簧和控制状态等相关，但**不按通用未知系数填具体压力/油液阈值**。有些早期全液压变速箱没有今天意义的独立 TCM；模型中电控只是有条件存在的执行层。

## 5. 变矩器 TCC、冷却器及润滑的真实耦合

Sonnax 的主压调节/油流研究用具体变速箱说明：主压调节阀不仅影响线压，还能控制通向变矩器充油、冷却和润滑的供流。一些回路会经变矩器、换热器及润滑油路转换；阀芯平衡位置和油泵余量可能改变可用流量。**所以主油压和润滑/散热流量不应视为同一被控制量。**

- 变矩器 **TCC（Torque Converter Clutch）** 锁止是在实际设计允许的油压/供排油、摩擦和控制条件下减小变矩器滑差；有些型号使用调制锁止，不能写成只有“全开/全闭”两种状态。
- 一些设计区分 TCC 释放、结合与散热/变矩器充油分支的油压方向及阀芯位置；实际哪边受控取决于专用油路，不可跨车系移植。
- 持续热负载会受变矩器滑差、离合摩擦、机件损失、冷却液/空气换热和冷却支路流量影响。**没有某车型完整油路图，不应将散热不足直接归咎于油泵**。
- “冷却有 ATF 流动”不等于“主压可使所有离合器满足传扭”，反过来主压合格也不等于冷却、润滑供流一定足够。这两个方向都需要被明确保留。

## 6. 条件化正常功能与反例

| 观察状态/工况 | 正常控制与机理可能性 | 不能由此直接推断 |
|---|---|---|
| 起步刚选挡 | 控制系统可按设计建立油路/执行器压力，让离合器逐步传递转矩 | “挂挡后有延迟 = 某个电磁阀必坏” |
| 发动机怠速、不同负载 | 发动机驱动泵的供流和阀体调节处于特定平衡 | “怠速主压读数等于高速/高负载压力” |
| 高温或重负载 | 油温/黏度、内部损失与冷却流量可能改变可用窗口 | “某一品牌变速箱能用另一个 ATF/压力限值” |
| 有锁止功能的巡航 | 变矩器 TCC 可按车型控制条件减小液力滑差 | “变矩器锁止在所有挡位与温度下必然同时发生” |
| 发生换挡扭矩交接 | 新元件充油/建压与旧元件释放、扭矩管理共同影响输出 | “电磁阀命令一变化就证明新档位已接合” |
| 某时刻主压力似乎稳定 | 反馈调节可能使主压保持，但其它分支流量与热/润滑条件未知 | “主压存在 = 油冷却器与所有轴承已得到足够润滑” |
| 变矩器/冷却器支路流量变化 | 调压阀位置、供流余量、节流和支路关系可能相关 | “冷却不足只有外部油冷器堵塞一种原因” |

**反例清单**：油泵流量≠油压读数；变矩器泵轮≠液压供油泵；电流命令≠实际离合器接合；主压正常≠所有支路流量正常；TCC 锁止≠行星换挡；存在冷却器≠所有型号通用相同油路；温度升高≠唯一零件故障；CVT/DCT 即使使用液压也不是本稿行星液力 AT 家族。

## 8. 与动力路径任务的组合及后继 STOP

- [FUN-AT-PATH](./power-path.md) 解释机械输入与行星构件约束形成的运动学路径；本 FUN 解释液压供流、调节与摩擦元件是否有能力实际建立机械约束。**两者必须一起阅读**，才有资格规划传统 AT 的深度失效模式候选。
- `FAIL-AT` 在两个 FUN 的真实 Git Commit/Blob 均存在且其来源/技术范围被核对后，才可按已审原 PLAN 的依赖推进；本轮不自动把它标为已生成。它需要区分油泵供流、调压失衡、支路漏油、活塞泄漏、阀体控制、电机/发动机输入、齿轮/摩擦材料等竞争原因。
- `REP-AT` 严格依赖 FAIL-AT 实际已生成及其专业适用条件；在无 OEM 手册/技术安全资质之前，仍不得提供实车危险操作与错误部件更换建议。
- 如果目前新 CVT/HEV 家族知识存在待审核问题，不把其功能论文变成传统 AT 的硬前置；只保留排除非适用结构的对照关系。
