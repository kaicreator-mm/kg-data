## 1. 功能目标：温度是受控状态，热量必须有真实去向

汽车热管理的输入不只是环境温度，而是热源损耗与工况、可用电力或发动机动力、传热介质、流路与空气流。目标是把发动机、机油、乘员舱、电池、电机和功率电子等对象保持在其**各自、车型规定**的适宜工作范围，同时控制能耗、舒适性与保护状态。不同对象的目标温区未必相同；温控请求、实际换热能力与结果温度分别属于三种证据。

对任一边界明确的热系统，研究级能量收支可写为：

- 储热变化 ≈ 内部产热 + 外部吸热 − 向其他回路/环境排热 ± 通过流动带入或带出的热。符号依约定，不能直接当作整车传感器算法。
- 换热需要可用的温差、传热面积、有效流动及换热器状态；泵/风扇提供流动或空气侧换热条件，却不直接“消除”热量。
- 控制回路是“目标/测量 → 控制器允许和命令 → 泵/风扇/阀/压缩机实际动作 → 热流变化 → 新测量”。命令已经发出不等于致动器确实运行，致动器运行不等于热流已达到需求。

这里的三个分离原则：**热源 ≠ 热汇；冷却液循环 ≠ 制冷剂相变循环；系统可以限制功率而非立刻达成温控目标**。此概括与 [Bosch ICE 热管理](https://www.bosch-mobility.com/en/solutions/thermal-management/thermal-management-for-combustion-engines/) 和 [Bosch 电驱热管理](https://www.bosch-mobility.com/en/solutions/thermal-management/thermal-management-for-hybrid-systems-and-electric-drives/) 的供应商功能说明相容，不代表每款车辆都有这些模块。

## 3. ICE 发动机冷却：输入、回路、反馈、限制

**输入和作用链**：发动机燃烧释放的能量一部分成为机械输出，其余包括排气、金属及液体吸收的热；冷却液通过机体/缸盖水套带走部分热。泵提供循环能力；节温器、旁通或主动阀按实际配置改变通路；散热器向环境空气排热；车速自然风与可控风扇共同影响空气侧能力。冷态暖机时，减少经过前端散热器的换热可能有利于较快达到目标，但不是所有车都采用相同节温、旁通或电子泵逻辑。

**反馈与输出**：传感器测得的是特定位置的温度或状态；控制器结合工况决定目标和许可；泵流量、阀实际位置及空气侧风量决定真实响应。稳态是热量输入与净排热相近，不是“发动机不再产热”。

- 怠速/低速：车辆迎风减少，部分架构需要风扇提供空气流；风扇启停还受设定阈值、空调负荷和保护策略影响。
- 爬坡、高负载、炎热环境：热源增加或温差余量减少，排热能力可能成为限制；不能用某一种风扇转速表现推定系统正常。
- 冷启动/暖机：冷却液、金属、机油温度不同步；节温/旁通的行为不能从单一仪表读数反演。
- 关机后的短时热再分配：局部热浸和余热条件与发动机正在产热不同；是否有后运行泵/风扇取决于车型。

**反例**：发动机过热并不总是“节温器卡住”；同一温度趋势也可能来自热负荷、散热器空气侧、冷却流不足、传感器偏差或保护策略。发动机低温也不能只凭表针判断节温器已失效。Bosch [ICE 热管理](https://www.bosch-mobility.com/en/solutions/thermal-management/thermal-management-for-combustion-engines/)仅支持上述一般性控制目标和冷却模块功能。

## 4. ICE 机油散热：润滑与热控制相耦合但不得混写

**输入**：机油在轴承、活塞/缸壁相关部位、配气与适用的涡轮/传动部件吸收部分摩擦与部件热，并随循环把热带回油底壳或油冷支路。润滑泵保障流动及油膜形成所需的供给条件；油温又影响机油粘度和流动阻力，因此热与润滑可双向耦合。

**可能的换热方案**：机油直接向机体和周围空气散热，或通过适用的油-冷却液 / 油-空气换热器向另一回路散热；有些设计用旁通/热管理阀调配油冷。油-冷却液换热在不同温度相对关系下既可能把热从油传到冷却液，也可能协助冷油升温；不能把所有油冷器限定为永远单向“降油温”。

**反馈与输出**：如果实际安装油温感知/油冷调节，控制可能按油温、负荷和其它系统状态影响阀或风扇。油温变化是热态证据；油压告警反映另一类液压/电信号链，既不能凭油温单独认证润滑膜，也不能凭油压正常排除局部过热。参见同仓已生成的 [FUN-ENG-LUBE 润滑正常机理](../engine/lubrication/function.md)、[FAIL-ENG-LUBE 候选失效](../engine/lubrication/failure.md)，以及 [MAHLE 机油冷却器产品范围](https://www.mahle-aftermarket.com/na/en/products-and-services/engine-cooling-%26-air-conditioning/)。

**竞争解释**：热负荷增大、油流变化、油冷器换热不足、散热器空气侧或冷却液支路异常、传感器偏移，均可影响油温；发动机冷却液温度正常不构成“机油不存在热风险”的证明。

## 5. 空调制冷、除湿与可选热泵：相变回路不是水冷回路

在**适用的蒸汽压缩式 HVAC** 中：压缩机提供外加功以维持制冷剂循环的压差与状态变化；高温一侧的冷凝/气冷换热器向空气或另一介质排热；节流/膨胀机构改变进入低温侧的条件；蒸发器从穿过的空气或关联介质吸收热量。蒸发器表面条件适当时，空气中水分还可能冷凝，形成除湿作用；实际空气舒适度同时取决于鼓风、滤网、内外循环与混风门。

- **输入**：舱内人数/太阳辐射/环境温湿度、设定点、可用压缩机驱动能量、空气流、换热器状态及车辆保护许可。
- **执行与反馈**：控制系统按所安装的舱温、蒸发器、压力或其它感知量协调压缩机、风机、风门及节流装置；部分保护状态会限制或停止压缩。
- **输出**：出风温度、湿度及舱内状态响应；单项“吹风/压缩机请求/压缩机声音”都不足以证明制冷正常。

**热泵是可选的热量搬运架构，不是“有空调”自动成立**。部分 BEV 可通过阀路切换或模块化换热实现客舱供暖、电池预调温、回收可利用部件热；另一些只有电阻加热和常规制冷，或因低温能力/除霜要求联用辅助加热。电阻加热是电能转热，热泵通常是搬运环境或其它热源的热并消耗压缩机功，两者能耗比较必须指定工况。参见 [Bosch 电驱热管理](https://www.bosch-mobility.com/en/solutions/thermal-management/thermal-management-for-hybrid-systems-and-electric-drives/) 与 [美国能源部 2024 寒冷环境 BEV 研究](https://www.energy.gov/cmei/vehicles/articles/program-record-impact-cold-ambient-temperature-and-extreme-conditions)。

**反例**：舱内制冷不足可能来自制冷剂侧、外界热负荷、风道/混风、过滤、控制保护或传感链；“风很大但不够冷”不证明制冷剂不足。“有冷凝器”不说明它与 ICE 散热器通液；“制冷剂压力读数”也不能直接表示液态冷却液流量。

## 6. BEV 电池、电驱和客舱：不同温区与工况下的资源协调

### 6.1 牵引电池

电池在充放电时因内部损耗发热，环境和充电功率需求会改变热负荷。按车辆设计，热管理可采用冷却板与冷却液、空气冷却、独立换热器、可选制冷剂-chiller、电阻/热泵加热等不同组合，**不能预设所有电池液冷**。

- **输入**：电池温度状态、预估/请求充放电功率、环境条件、可用热管理电能、充电或行驶状态，以及实际 BMS/整车许可。
- **控制**：BMS 或整车热管理在真实可用的传感数据下，可能请求泵、阀、压缩机或加热，并按保护策略限制充电、回收或驱动能力。
- **输出**：电池热状态的变化趋势及受许可影响的可用功率；限制是一种保护决策，**不等价于某一个冷却零件已损坏**。

停放预调温、快充、高负载行驶、寒冷环境中“加热以保证可用性能”的热目标可能不同。美国能源部的样本研究支持“不同车型采暖硬件和低温能耗表现不相同”，不能将其样本温度、续航损耗或技术效果外推到缅甸任一实车。

### 6.2 电驱与功率电子

电机有绕组和磁路损耗，逆变器/DC-DC/车载充电机在其工作状态下有电能转换损耗，减速机构也可能有机械热负荷。按设计可用液冷、油冷、空气或混合换热；电驱与电池可独立热回路、共享一部分散热设施，或经阀路按条件交换热量。参见 [Bosch 电驱热管理](https://www.bosch-mobility.com/en/solutions/thermal-management/thermal-management-for-hybrid-systems-and-electric-drives/) 及 [Bosch 油冷热管理模块实例](https://www.bosch-mobility.com/en/solutions/thermal-management/flexible-thermal-module-for-oil-cooling/)。

电驱控制输出可体现为允许的连续功率、峰值持续能力和温度保护趋势；同样动力限制也可能源自电池 SOC/温度、逆变器、电机、轮胎附着或控制策略，不能凭驾驶感受唯一定位冷却系统。

### 6.3 客舱舒适与整车能耗的竞争

BEV 乘员舱通常没有 ICE 的持续燃烧废热可用，制热需求需由电阻热、可利用余热、热泵或其组合满足，因而可能与驱动和电池预调温争用电能或换热能力。某个热管理控制器发出阀位或压缩机命令，并不证明相关回路已构成有效热通路。热泵能耗优势取决于热源温度、压缩条件、除霜和辅助加热策略；不承诺确定续航百分比。

**接口限制**：冷却液泵、chiller、热泵阀、BMS/电驱温控和充电许可的具体控制报文、互锁序列、工作压力与温度窗口必须来自真实车型 OEM 文档，均不可从通用供应商模块反推。

|---|---|---|---|

| TH-F01 | ICE 热负荷↑，有效散热余量不足 → 冷却液温度可能持续上升 | 传感器偏移或实际保护状态可使仪表与真实金属温度不一致；泵故障不由此成立 |
| TH-F02 | 低车速空气流减少 → 散热器/冷凝器空气侧能力可能下降 | 可控风扇实际运行可补偿；行驶速度与风扇命令都不是实测换热率 |
| TH-F03 | 油温变化 → 粘度/流动阻力与散热可能变化 → 润滑相关工况受影响 | 主油道压力数值不能单独证明局部油膜或换热器状态 |
| TH-F04 | 油与冷却液温差方向改变 → 油-水换热热流可能反向 | 所有油冷器都只能单向冷却的假设不成立；真实结构/阀位未知 |

| TH-F06 | 空调压缩机请求存在 → 若实际保护不许可，制冷剂热循环可能不工作 | 请求/实际运转/冷量是三个不同层面的证据 |
| TH-F07 | BEV 充电功率被限制且电池温度变化 → BMS 可按热状态限制功率 | SOC、站端功率、其它保护同样可限制功率；并不指认冷却泵损坏 |
| TH-F08 | BEV 电驱热负荷增大 → 若排热不足可触发连续功率限制 | 电池、电机、逆变器及环境温度约束须分别识别 |
| TH-F09 | 客舱制热耗能↑ → 可能增加 BEV 电池辅助能耗 | 车型是否装热泵、天气、除霜和余热回收都未知；不能给固定续航损失 |
| TH-F10 | 适用 chiller 参与电池换热 → 两类介质隔壁传热 | chiller 存在不证明制冷剂直接流过电池包或与液态冷却液混合 |
| TH-F11 | 冷却泵或电子阀获得命令 → 目标回路可能发生换热变化 | 命令不等于电机转动/阀位、实际流量及介质温差 |
| TH-F12 | 设备温度处于某范围 → 控制器可能允许驱动或充电 | 该范围必须有 OEM/配置限定；一个温度传感器正常不保证所有电池芯/支路正常 |

**机制之间的区别**：故障症状、物理热机制、执行器是否动作、控制器是否发出请求、某种温度告警或 DTC，各属于不同证据，不可串成已经验证的唯一故障因果链。相反，也不能从“没有告警”推出所有热管理功能合格。
