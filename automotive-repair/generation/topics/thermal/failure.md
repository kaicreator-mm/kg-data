## 2. 失效机理分层：四个网络的竞争谱系

沿用 [STR-THERMAL](./structure.md) 的液路/气路/控制/制冷剂四网络分离。同一症状可由多个网络独立产生，交叉归因前各网络证据分别成立。

### 2.1 液路：泄漏点谱系、气阻与变质

| 泄漏/失效点 | 物理机理 | 关联观察线索（线索≠确诊） |
|---|---|---|
| 水管/软管与接头 | 橡胶老化、卡箍松脱 | 可见冷却液湿痕、液位缓降 |
| 散热器芯部 | 鳍片腐蚀、石块击穿 | 干燥的白色/锈色结晶痕 |
| 水泵轴封 | 密封面磨损 | 泵体排气孔/皮带侧滴漏痕 |
| 暖风芯体（舱内） | 芯体渗漏 | 副驾侧地毯湿、玻璃反复起雾、液位同步下降——舱内线索常先于舱外 |
| 缸垫（机理级候选） | 燃烧气体窜入液路产生气阻 | 液位降但外部无痕、暖风忽冷忽热、软管变硬；证实需专业测试，本文不给操作 |

气阻（air pocket）与冷却液变质（老化、混入不当介质）是液路的非泄漏失效：气阻使高位测点/暖风芯失液，造成温度波动与暖风不热；变质降低换热与防腐能力，但**颜色不能单独当变质证据**。

### 2.2 气路：散热器空气侧与风扇

| 气路失效 | 机理 | 缅甸条件化线索 |
|---|---|---|
| 鳍片被尘土/飞虫/异物堵塞 | 空气侧换热面积与流量下降，热源不变则液温升高 | 尘土路况+护网缺失时渐进恶化；洗车后短暂改善属可疑支持证据 |
| 风扇不转/仅高速档失效 | 停车无自然风时空气侧能力骤降 → 怠速升温、行驶缓解 | 堵车温度升、巡航正常是典型但非专属模式 |
| 护网缺失 | 异物直接击伤芯体与扇叶 | 与鳍片损伤痕迹互证 |
| 冷凝器与散热器之间缝隙堵 | 制冷与冷却两侧同时退化 | 「冷气不足+水温偏高」同源的候选解释 |

### 2.3 控制与传感：把「假信号」与「真过热」分开

| 失效 | 机理 | 与竞争假说的区分点 |
|---|---|---|
| 节温器卡在关闭 | 液路不流经散热器，快速升温 | 升温快且持续；但液位低/气阻可有相似仪表表现 |
| 节温器卡在开启 | 暖机慢、暖风不热；一般不致过热 | 暖气症状多于温度症状 |
| 风扇继电器/温度开关/供电失效 | 风扇无命令或无电力（电气面见 [FUN-LOWV](../electrical-low-voltage/function.md)） | 风扇完全不转 vs 液路问题的行驶/怠速差异 |
| 温度传感器/接地/线束失真 | 仪表显示与真实液温脱节（假高、假低、跳动） | 需蒸汽/液位/暖风温度等独立通道仲裁；接地失真属低压电气失效面 |
| 水泵叶轮蚀损/打滑 | 流量下降，行驶风掩盖不住高负荷 | 与节温器卡关竞争；证实需专业检查 |

### 2.4 空调机理面（仅机理，无操作）与暖风水路

| 机理候选 | 因果链 | 不得外推 |
|---|---|---|
| 冷凝器散热不足/堵塞 | 高压侧排热差 → 制冷量降，且冷凝器常前置加速热水箱升温（两症状同源） | 不能凭此认定压缩机损坏 |
| 蒸发器结冰 | 防结冰控制或传感失效 → 结冰堵风 → 风量衰减、化冰后恢复（时有时无） | 结冰成因在控制面，不是「制冷剂太多」 |
| 压缩机机械/驱动失效 | 制冷剂循环不建立 → 完全无冷 | 「不够冷」≠「无冷」；两者候选集不同 |
| 制冷剂缓慢渗漏（机理候选） | 循环质量流量下降，制冷能力渐弱 | 种类/加注量/压力值 UNKNOWN；本文无任何作业程序 |
| 暖风水路堵塞/流量不足 | 暖风芯失流 → 暖气不热而发动机温度正常 | 暖风阀存在性按版本 UNKNOWN |

## 3. 症状 → 竞争解释 → 有区分力证据矩阵

每行是研究级竞争假说，不是现场操作指令；证据采集须由合格人员完成。

| 症状 | 竞争假说（均保留） | 有区分力的证据 | 不得直接下的结论 |
|---|---|---|---|
| 怠速/堵车温度升，行驶后降 | H1 风扇及控制失效；H2 鳍片部分堵塞；H3 液位低/气阻 | 风扇是否转（听/看）、液位、鳍片状态；行驶风即维持→空气侧权重大 | 「风扇不转=只换继电器」（电机/开关/供电竞争） |
| 暖气不热但水温正常 | H1 暖风芯水路堵塞；H2 节温器卡开；H3 液位低/气阻失液；H4 混风风门失效 | 冷车暖机时长、液位、出风温度随转速的变化；风门动作 | 直接拆暖风芯体（高误修代价+大工时） |
| 冷气时有时无 | H1 蒸发器结冰-化冰循环；H2 压缩机驱动/控制间歇；H3 冷凝器热负荷临界 | 风量是否同步衰减、发生工况（高湿/怠速）、「恢复」的时间模式 | 判「缺制冷剂」并加注 |
| 水温表忽高忽低 | H1 真实温度波动（气阻/低液位间歇覆盖测点）；H2 传感/接地/线束失真；H3 节温器周期开闭 | 与暖风温度、液位、蒸汽等独立通道交叉；跳动是否伴随电气负载 | 换传感器了事，或反着信仪表为真 |
| 开空调就水温高 | H1 冷凝器堵/缝隙堵；H2 风扇容量/档位不足；H3 液路本已临界（节温器/液位/水泵） | 不开 A/C 同工况表现；鳍片与缝隙检查；风扇档位行为 | 「压缩机负载大」换压缩机 |
| 冷气不足但风很大 | H1 冷凝器散热不足；H2 蒸发器风路/滤堵；H3 制冷剂渐漏（机理）；H4 混风门 | 出风温度趋势与工况关系、风量本身是否衰减 | 无压力测量资格即认定并补充制冷剂 |
| 副驾地毯湿/玻璃反复起雾 | H1 暖风芯体泄漏；H2 空调冷凝水排水堵塞（清水错位） | 液体性质（冷却液滑腻/甜味 vs 清水）、液位是否同步下降 | 当空调水忽略——若为冷却液将接通过热链 |
| 蒸汽/开锅/焦甜味/报警 | 真实过热为第一优先；传感假报警只是罕见反例 | 蒸汽、异味、动力衰减是独立于仪表的物理证据 | 「仪表正常所以没事」继续行驶 |
| 冷车后数分钟即升温 | H1 节温器卡关；H2 液位低/气阻使测点失液 | 液位与气路排气历史；暖风水路温度渐进性 | 仅凭升温速度换节温器 |

## 4. 过热是第一优先安全事件

任何真实过热证据（蒸汽、焦甜味、明显动力衰减、温度报警）出现时：立即驶离行车道安全停车并熄火，等待充分自然冷却后再评估；**禁止**热机立即开盖（高温冷却液与蒸汽喷出烫伤）、**禁止**向热机加冷水（骤冷致金属变形开裂，机理级）、**禁止**继续行驶「撑到目的地」、**禁止**自行开盖补液后继续路试。之后拖车移交合格人员。即使仪表读数看似正常，蒸汽/异味等物理证据优先于仪表。机油与过热的交叉竞争（油温、油压、润滑耦合）见 [FAIL-ENG-LUBE](../engine/lubrication/failure.md)，其安全边界同权重适用。

## 5. 缅甸存量候选研究案例（反例，正确出口）

**案例 A：尘堵水箱被当节温器坏。** 研究对象为挂牌身份不明车（如「卖家只写 2011 Probox Automatic」，年份字段冲突，[发现稿 §2.1](../../series/myanmar/toyota/probox/discovery.md) 口径），主诉堵车水温高。叙述中节温器被更换后症状复发。竞争分析：怠速升温/行驶缓解同时支持风扇控制失效与鳍片堵塞；尘土路况+护网缺失使气路候选权重大。误修机理：升温快被单独归因节温器卡关，而气阻/低液位可产生相似仪表表现。正确出口：气路/液路/控制候选并列保留，实车身份 `UNKNOWN`，移交合格人员。

**案例 B：冷气不足被判「缺制冷剂」直接加注。** 叙述：冷气渐弱，未经任何回路证据即补充制冷剂，短期改善后复发，且伴随堵车水温偏高。竞争分析：「冷气不足+水温高」两症状同源指向冷凝器/缝隙堵塞或风扇容量不足（§2.2 末行）；制冷剂渗漏只是并列假说之一。且实车制冷剂种类/加注量 `UNKNOWN`，任何加注/回收/压力表操作均被本文排除。正确出口：`UNKNOWN`，候选保留，移交有制冷剂资格人员。

**案例 C：水温表忽高忽低被连换节温器与传感器。** 叙述：两轮换件后跳动依旧。竞争分析：仪表是单一信号链；接地/线束失真属 [低压电气失效面](../electrical-low-voltage/function.md)，气阻导致的测点间歇失液亦可产生跳动——两类原因都不能由换件排除。区分证据是独立通道交叉（液位、暖风、蒸汽），而非仪表自身。正确出口：`UNKNOWN`/候选保留；若出现任一真实过热证据，先执行 §4 停车边界。
