## 1. 功能边界：分开五件经常被混淆的事

驱动系统的目标是把动力源的机械功率或电驱输出按**所选传动架构**送到驱动轮，并允许必要的轮速、角度与悬架位移；这不意味着任何工况下轮胎一定能把所给的轴端转矩变成前进牵引力。

| 物理量/约束 | 由什么主要决定 | 不能推断什么 |
|---|---|---|
| **转速 `ω`（rad/s）** | 变速比、终传齿比、差速器的运动学约束、车轮有效滚动半径及滑移 | 两轮同轴转速不同就证明差速器损坏 |
| **轴端转矩 `T`（N·m）** | 动力源/变速机构输出、齿轮与耦合器、差速器类型、传动损失及控制限制 | 转矩总按固定比例落到四个轮，或转矩数值直接等于路面牵引力 |
| **可用路面附着** | 轮胎—地面条件、轮胎状态、各轮法向载荷、纵/横向力共同占用 | 装了 LSD、AWD 或差速锁就消除了轮胎抓地上限 |
| **接头工作角** | 转向转角、悬架几何、轮端和变速驱动桥相对姿态 | CVJ 可以在任意角度持续正常传力 |
| **轴向行程（plunge）** | 悬架压缩/回弹、动力总成位移与机构几何 | 所有等速节都具有轴向伸缩自由度 |

抽象功率关系为 `P = T × ω`（同一旋转截面的瞬时机械功率）。在近似稳态且忽略部分损失时，降低输出转速的齿比可以提高输出转矩；**并不增加能量，也不保证有足够抓地**。功率、转矩、转速、附着和轮端实际推进力应分别观察。

## 2. FWD / RWD / AWD：动力路径不等于固定部件清单

| 条件化架构 | 正常传递路径（示意） | 轮速差如何容纳 | 不适用/不能默认 |
|---|---|---|---|
| **横置 FWD** | 发动机/电机 → 变速或减速机构 → 集成终传/前差速器 → 两侧半轴与 CVJ → 前驱动轮 | 前差速器允许左右轮在转弯时异速；转向轮外侧接头允许偏转 | 不要求独立纵向传动轴、后桥差速器或液力变矩器 |
| **纵置 RWD、独立后悬架** | 变速器 → 纵向 propshaft → 后桥终传/差速器 → 两侧后半轴/CVJ | 后差速器容纳内外轮异速；独立悬架半轴接头适应位移 | 不是每种 RWD 后桥都有两根外露 CVJ 半轴 |
| **RWD、整体式后桥** | 动力源与变速器 → 传动轴 → 后桥终传/差速器 → 桥壳内轴 | 同轴左右车轮通过差速器异速；轴壳随整体桥运动 | 不能把独立后悬架的内外 CVJ、滑移行程逐项套用 |
| **机械式 AWD/4WD** | 主驱动路径 → PTU/分动箱或耦合器 → 前后驱动模块 → 各轴差速和轮端 | 轴内差速器处理左右轮；轴间速差取决于中央差速、耦合、分动及锁止模式 | 不保证有中央开放差速器；不保证恒定 50:50 |
| **双电驱动桥 AWD** | 前电机及减速器 → 前驱动轮；后电机及减速器 → 后驱动轮 | 前后驱动单元可分别受控；各轴内部仍须按结构解决左右轮速差 | 可不存在机械中央 propshaft、传统分动箱；双电机不等于四独立轮端电机 |

**条件性判断**：看到两个驱动轴均有输出，不代表这两个轴在所有路况下接收同一转矩；看到单个车轮空转，也不证明中央耦合故障。AWD 模式、主动脱开、离合器热保护、ESC/牵引控制和胎面条件都可能改变实际传力。实车是否配备某一方案，仍须由车型配置和 OEM 资料确认。

## 3. 终传减速（final drive）如何影响转速与转矩

### 3.1 基本速比

以环齿轮、主动小齿轮构成的终传为例，可在理想近似下定义终传减速比：

`i_f = N_ring / N_pinion = |ω_in / ω_case|`

其中 `N` 是齿数，`ω_case` 可理解为终传带动差速器壳体的转速；方向变化、啮合布置与符号约定另行处理。在约定 `i_f > 1` 且减速工况下，`|ω_case| ≈ |ω_in| / i_f`、`|T_case| ≈ η × i_f × |T_in|`，`η` 为相应路径效率。**这些式子不是某车型的真实齿比或扭矩限值**。

- 终传可布置为驱动桥内齿轮、后桥环齿/小齿轮、集成电驱动模块的单级或多级减速；不可把 Dana 后桥齿比示例直接当作横置 FWD 或电驱的原厂齿比。
- 在其他条件不变时，较大总减速比趋向于提供较大的低速轮端转矩、较低的相应车轮转速；对最高车速、效率、温度与噪声的净影响还受动力源工作点、传动损失和控制策略影响。
- 传力反向（发动机制动、再生制动）时，轮端功率可向动力源回传，但需要实际机械连接及控制许可；不能从“有终传”推断任何车均具备能量回收。

### 3.2 反例：终传与差速器并不是一回事

在转向时，同轴左右轮速有差异，不必表示终传齿比改变：普通终传维持齿轮传动比，左右轮速差由其后的差速机构处理。相反，终传齿轮齿数/速比属于传动设计选择，**不能靠锁止差速器改变终传减速比**。

来源边界：[Spicer 齿比计算器](https://spicerparts.com/calculators/gear-ratio-calculator) 只证明特定后桥环齿/小齿轮速比的计算原理；[Spicer 差速器总成](https://spicerparts.com/parts/axle/automotive-performance/differential-case-assemblies) 只展示真实存在的不同总成配置，不提供缅甸 Probox/Fit 的速比或维修值。

## 4. 差速器：先判断运动学，再判断转矩与附着

### 4.1 对称开式差速器（open differential）

对**理想、对称、同齿数侧齿轮的普通锥齿轮差速器**，忽略轮胎滑移和结构变形时：

`ω_left + ω_right = 2 × ω_case`

直线行驶、等有效滚动半径、无明显轮胎滑移时，通常有 `ω_left ≈ ω_right ≈ ω_case`。转弯时左右轮轨迹长度不同，差速齿轮允许一侧快、一侧慢，而壳体转速仍满足平均关系。**这是特定理想结构的运动学关系，不是所有主动差速、轮内电机系统的通用等式，也不是诊断限值。**

对理想、对称、无内部摩擦/预载的开式差速器，两侧半轴输出转矩**近似相等**；这与两侧轮速可以不同并不矛盾。其结果是低附着轮先失去有效牵引时，另一侧虽然附着较好，也可能因分配机构的转矩约束得不到足够的驱动力。不能把“转速差较大”解释为“高转速轮必定分到了更高转矩”。

示意工况：

1. **同一驱动轴左轮在低附着面、右轮在高附着面**：开式差速允许左轮更快空转；理想同轴转矩近似相等，低附着轮的可持续接地反力可能限制整轴可利用推进力。
2. **两轮附着都好且车辆平稳转弯**：正常轨迹半径不同就会出现轮速差；这不是“左/右打滑”的充分证据。
3. **一侧轮腾空**：理想开式差速很难向接地侧输出高转矩；现实中摩擦、制动介入等可能改变结果，不得用“接地侧永远零转矩”作绝对结论。

### 4.2 LSD、锁止与基于制动的牵引控制

| 系统 | 对轮速差的影响 | 对两侧可传转矩的影响 | 重要的工况和反例 |
|---|---|---|---|
| **开放式差速器** | 允许被动异速 | 理想对称机构输出转矩近似相等；高附着轮不一定得到所需推进力 | 轮速差是正常转弯要求，非故障本身 |
| **摩擦片式 LSD** | 通过摩擦/预载限制左右相对运动，仍可能允许差速 | 在差异附着下可产生转矩偏置；能力取决于预载、磨损、温度和设计 | 不是完全锁死；有预载不表示任何工况都无限偏置 |
| **螺旋齿轮/转矩感应式 LSD** | 借内部摩擦/齿轮反力形成有限转矩偏置 | 常依赖两侧一定反力；完全无反力的一侧可能仍需其他制动/预载机制 | 有 LSD 不等于单侧悬空也必可满额传力 |
| **黏性耦合等速度差响应机构** | 对相对转速差与热状态响应，可能提供逐步耦合 | 偏置能力随速度差、温度与设计变化 | 不要假定“任何转速差都立刻锁止” |
| **可选差速锁** | **锁定状态**下同轴左右轮相对转速被强限制；解锁后按其基础机构运动 | 可允许不同附着侧承担不同路面转矩，但并不保证轮胎能抓地 | 高附着转弯仍需要轮速差；锁止可能产生轮胎擦滑和传动系扭曲载荷 |
| **制动介入式牵引控制** | 通过选择性制动打滑轮影响系统转速/反力 | 可能令开放差速器向另一侧提供更多可利用驱动力，但能量在制动器中耗散 | 这是制动与控制的作用，**不**代表内部变成机械 LSD |

示例来源：[Dana/Spicer Trac-Lok LSD](https://spicerparts.com/press-release/dana-introduces-genuine-spicer-trac-lok-for-aftermarket)、[Spicer 商用桥开式/LSD/锁止产品](https://spicerparts.com/parts/axle/commercial/commercial-vehicle-differentials-for-medium-duty-axles)。这些资料仅证明**机制和产品类型确实存在**，不证明适配具体缅甸乘用车，也不代表 LSD 有统一锁止率、扭矩偏置比或油品规格。

### 4.3 轴间差速不等于轴内差速

轴内差速用于左右驱动轮；机械 AWD 的轴间分配可能由中央差速器、受控摩擦耦合器、分动箱或电驱前/后轴控制协同完成。中央耦合/差速器是否允许前后轴速差，与前、后**各自**是否有开放式差速器，是两个问题。

- **固定 50:50 不是 AWD 定义**：控制器可因行驶需求、附着、离合器温度、转向、能量管理而改变前后轴输出；某些设计还会在巡航时断开次驱动轴。
- **主动扭矩矢量控制**与普通前后轴扭矩耦合不同：前者还可能有驱动轮侧向分配能力，具体要看驱动桥内是否存在相应机构。
- **双电机前后轴**可在软件上独立决定前、后电机转矩，但每个轴内部的左右轮速差仍受各自的差速/轮端结构约束。

参考 [GKN AWD 系统](https://www.gknautomotive.com/en/products-and-systems/awd-systems/) 及 [GKN 转矩管理设备](https://www.gknautomotive.com/en/products-and-systems/torque-management-devices/)；它们是制造商能力示例，非任何车辆功能已安装的事实。

## 5. 路面抓地：轮端转矩到牵引力的条件转换

在粗略的轮胎—路面模型中，轮端纵向接地力可用有效半径近似联系轴端转矩：`F_x ≈ T_w / r_eff`（先忽略轮端惯量、滚阻及传动损失）。轮胎能够持续传递的纵向力仍受附着与垂直载荷约束，极简示意为：

`|F_x| ≲ μ × F_z`

其中 `μ` 随路面湿滑、轮胎材料/温度、滑移率和条件变化；`F_z` 是当前轮胎法向载荷。真实轮胎在转弯时还要分配侧向力 `F_y`，**不能把最大纵向牵引与最大侧向抓地当作可同时完全独立达到**。这些关系仅为原理模型，非胎路摩擦系数实测表或车辆安全限值。

由此可区分：

- **转矩充足但抓地不足**：动力源、终传和半轴可输出转矩，车轮仍可能空转。
- **抓地充足但传力路径不足**：离合器、耦合器、差速器、轴或相关控制受限时，轮胎即使能抓地也得不到所需转矩。
- **转角、悬架载荷转移改变轮胎受力**：同一车辆左右侧轮的瞬时 `F_z` 可以不同，但不可直接推断差速器已经主动改变左右转矩。
- **AWD 可增加可用驱动接地点，但不能突破每个接地点的物理上限**；AWD 不自动缩短制动距离，也不能保证在低附着转弯时不侧滑。

**可证伪反例**：若一辆机械开放式 FWD 在湿滑上坡时单前轮打滑，把原因直接归为“发动机输出不足”就与同样可能发生的附着受限相竞争；若 AWD 模式显示启用却只有一轴实际出力，不能仅凭仪表显示判定机械差速器坏，必须进一步区分控制命令、离合器保护/热状态、传感信息与实际轴端响应。

## 6. 半轴、CV Joint、纵向轴如何容纳角度与行程

### 6.1 CV Joint 的两个不同运动要求

**等速（constant velocity）**的核心是，在接头允许的工作角、运动状态及正常润滑条件下，输入轴与输出轴可保持近似相同的瞬时角速度关系；这并非指没有传动损失、没有转矩波动、可以任意折弯，或所有接头都能轴向伸缩。

- **外侧/轮端固定式 CVJ**：常用于需较大转向角的驱动轮；允许角度变化，通常不承担主要轴向滑移任务。
- **内侧滑移式 CVJ（plunging joint）**：常通过三销/球道等机构容纳悬架压缩回弹导致的轴端距离变化，仍需允许一定角度。
- **轮端不转向、整体桥或某些电驱设计**：接头及半轴配置可能不同，不能机械地套用“每根半轴一定一固定一滑移”的部件清单。
- **接头角度和行程是有界的设计条件**：超出结构几何/润滑/负载允许范围可能导致传力和振动问题；本文不给出车型的工作角、游隙或限值。

GKN [Sideshafts](https://www.gknautomotive.com/en/aftermarket/portfolio/sideshafts/) 与 [CV joints](https://www.gknautomotive.com/en/aftermarket/portfolio/constant-velocity-joints/) 提供轮端固定节、内侧滑移节的具体制造商设计例子，**不构成任何 Toyota/Honda VIN 的零件型号证明**。

### 6.2 为什么转向角和悬架行程不能混成“转速差”

举例：同一前驱车在弯道中，**左、右轮速差**由车辆运动轨迹、轮胎有效滚动和车轮差速机构共同决定；与此同时，左右半轴的**接头折角**随转向和悬架位置变化，**内侧滑移副轴向位置**随轮端与驱动桥距离变化。这是三组不同变量。

| 情境 | 轮速约束 | CVJ 角度 | 轴向长度补偿 |
|---|---|---|---|
| 直线平路、两轮抓地 | 理想时左右近似同速 | 仍可能存在静态悬架工作角 | 需适应安装位置及小幅悬架运动 |
| 平稳转弯、两轮抓地 | 左右轮轨迹半径不同，允许异速 | 转向驱动轮外侧节偏转 | 悬架载荷/几何变化可引起内侧滑移 |
| 单轮压过路面起伏 | 轮速可能因滚动/滑移及控制而变化，不能仅靠起伏推断差速状态 | 随悬架压缩、回弹变化 | 常需要伸缩行程；不能错当成差速器“分配更多扭矩” |
| 一侧低附着、明显空转 | 左右轮速差可能显著增大 | 接头几何不必出现对应显著改变 | 滑移量也不由单侧空转直接决定 |

**传统单个十字轴万向节（U-joint）≠ 等速 CVJ**。普通十字轴在非零工作夹角下可出现瞬时角速度波动；双万向节在合适的相位和几何条件下可部分补偿，但不能由“有两个十字轴”就断定完全等速。在 RWD/AWD 纵向轴上，还要分别考虑中间支承、滑移、扭转惯量和平衡条件。

参考 [GKN Propshafts](https://www.gknautomotive.com/en/aftermarket/portfolio/propshafts/)；它支持轴间扭矩连接和相对位移问题，不支持套用其产品的安装角、尺寸或维修扭矩。

## 7. 正常工况与反例：建立竞争解释，而非凭现象给故障结论

| 工况/观察 | 与正常机理一致的解释 | 重要反例或竞争机制 | 需要独立核实的证据类型 |
