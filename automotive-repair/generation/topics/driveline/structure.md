# 传动轴、差速器、半轴和驱动接头：结构与架构边界（STR-DRIVELINE）

> 任务：`STR-DRIVELINE` · 主控：[`parts-system#61`](https://github.com/kaicreator-mm/parts-system/issues/61) · 阶段：**汽车维修知识生成 / 第一阶段** · 资格：`MODEL_GENERATED_UNVERIFIED` · 车型级事实：`UNKNOWN`。本文为来源锚定的结构机理研究，不是车型维修手册、零件适配表或可直接操作的维修指令。未获得缅甸市场 VIN、底盘码、具体变速箱/差速器编号及 OEM 文档，不推定某车采用任何具体结构。

## 1. 先区分系统边界：变速器不等于整套车轮传动

车轮驱动路径可抽象为：**发动机/电机的输出 →（离合器/变矩器及变速机构，按动力架构选用）→ 终传/分动或耦合单元 → 差速或转矩分配单元 → 驱动轴与接头 → 轮毂及轮胎路面接触**。具体单元可能集成在同一壳体、前后轴各自分布，或根本不存在。

- **变速器/减速机构**：改变转速、转矩的传递关系；传统液力行星 AT 的变矩器/行星排见 [STR-AT](../transmission/automatic/structure.md)，不可将其视为所有 FWD、CVT、DCT、HEV 或 BEV 的共同结构。
- **终传（final drive）**：在驱动轮前进行最终速比与方向配置；部分横置变速驱动桥（transaxle）把终传和差速器集成到变速器壳体。某些电驱动桥将电机、减速机构与差速机构组合。
- **车轮差速器（wheel differential）**：适应同一驱动轴左右车轮的转速差；差速机构的位置、类型与控制程度依架构而异。
- **传动轴（propeller shaft / propshaft）**：通常用于纵向或跨轴间传递转矩，可能为多段式，包含万向节、伸缩机构、中间支承和动态平衡要求；**并非所有车都有独立纵向传动轴**。
- **半轴（sideshaft / axle shaft）与万向/等速接头**：把差速/终传输出连接到驱动轮，使车轮转向、悬架跳动和车身与轮端相对位移时仍能传递转矩。车轮端固定式等速节与差速器端可轴向伸缩接头是常见组合，但不具普遍性。
- **转矩管理（AWD coupling / disconnect / vectoring）**：四驱系统可能有动力分配/脱开/主动耦合，不能简单写成“四驱=永久固定 50:50 分配”。

**常见误区**：车轮不转不必然是“变速箱坏”，变速箱档位正常不代表差速齿轮、耦合单元、半轴花键、接头和轮胎附着均有效；反过来，轮端异响也不必然意味着差速器失效。

## 2. FWD、RWD、AWD 和电驱的结构切片

| 条件化构型 | 典型传力路线（仅抽象） | 可能有的部件 | 不应误认为必需 |
|---|---|---|---|
| 横置前驱 FWD | 发动机/电机 → 变速驱动桥/终传 → 前差速器 → 左右半轴及接头 → 前轮 | 半轴、轮端固定节、内侧可伸缩节、前轮毂 | 纵向 propshaft、后差速器、传统 AT 变矩器 |
| 纵置后驱 RWD | 纵置动力单元与变速器 → 纵向传动轴 → 后桥终传/差速 → 后轮传动轴或桥内轴 | U-joint/CVJ、支承、后桥差速、桥壳或独立悬架半轴 | 横置前桥差速、前轮驱动半轴；具体轴壳形式 |
| 前置动力 AWD/4WD | 一条主要动力路径 + 分动/主动耦合/跨轴传动 → 各驱动轴差速/轮端 | PTU、propshaft、后驱动模块、离合器/电子控制 | 持续全轮等扭矩输出、固定式中央机械差速 |
| 双电机或电驱 AWD | 前后分别配置电驱动桥/终传，按控制要求输出 | 前后电驱总成、局部差速器、独立轮端传动 | 一条机械纵向 propshaft、传统分动箱 |
| 横置混合动力 | ICE/电机通过厂商规定的变速/耦合结构作用于一个或多个驱动轴 | 视 IMA、i-DCD、e:HEV 等实际平台而变 | 将 HEV 的电驱和机械动力路径自动等同 BEV 或单一 e-CVT |

GKN 的 sideshaft、propshaft 和 AWD 产品明确展示多种布局，而非“一套标准部件”；其可断开 AWD 与 BEV 独立电驱也展示了跨架构差异（资料见 §7）。**结构图只描述候选架构；只有车型与 VIN/驱动配置配对后才能进入真实适用性判断。**

## 3. 半轴、接头、车轮和悬架不是独立的孤岛

### 3.1 轮端角度与轴向变化是两种不同需求

驱动轮沿悬架运动并转向时，车轮中心与驱动桥之间不仅夹角改变，有效轴向距离也会变化。因此半轴方案往往同时解决：

1. **角度传动**：固定式等速接头（例如轮端球笼类设计）容许角度变化并尽量保持输入/输出的瞬时角速度关系；不是“任意角度都允许”。
2. **长度补偿**：滑移式/伸缩式 CV 接头或花键配合允许工作行程中的轴向位移；不能把“可伸缩节”错认为所有接头均可轴向移动。
3. **密封润滑**：护套、卡箍与密封把润滑脂保持在接头内并隔离污染；护套破损会增加污染与润滑流失风险，但不单凭一处视觉迹象判定失效已发生。
4. **力与振动路径**：转矩脉动、轴的扭转刚度、安装偏差、悬架动态、轮胎不平衡会形成不同激励；同一车速振动不等于单一半轴故障。

传统十字轴万向节与等速万向节并非运动学等价；单个非等速 U-joint 在非零夹角下可出现瞬时角速度波动，串联与几何布置可补偿某些波动但取决于夹角/相位条件。**不能从“装了两个万向节”直接推出完全等速或无振动**。

GKN 官方资料针对前驱半轴给出“外侧固定 CVJ + 内侧滑移式接头”的产品实例，并指出侧轴必须适应转向角与悬架行程；这并不证明任何 Toyota/Honda/缅甸车款的原装接头型号。[GKN Sideshafts](https://www.gknautomotive.com/en/aftermarket/portfolio/sideshafts/) · [GKN CVJ systems](https://www.gknautomotive.com/en/products-and-systems/sideshafts/)

### 3.2 纵向传动轴的独立结构链

典型传动轴研究对象包括轴管/轴本体、两端联接法兰或叉头、U-joint/CVJ、可能的滑移副、中间支承及其橡胶隔振、平衡配重和防护结构。某些车使用单根轴，某些车因轴距/空间分段；也可能由电驱断开或没有这条路径。

常见的结构互相作用：传动轴转速随车辆速比和驱动路径变化，轴弯曲/不平衡与支承顺应性影响振动；接头工作夹角、相位和滑移行程是另外的运动学条件。**不能仅凭“高速抖动”确诊传动轴，也不能移用某家商用车传动轴的安装角、螺栓扭矩或临界转速作为乘用车维修参数。**

原始产品锚点：[GKN Propshafts](https://www.gknautomotive.com/en/systems-and-solutions/sideshafts-propshafts/propshafts/) · [GKN 产品概览](https://www.gknautomotive.com/en/aftermarket/portfolio/)

## 4. 差速器：转速约束与可用牵引力是两个问题

### 4.1 开放式差速器（open differential）

对对称的理想锥齿轮式开放差速器，可用概念关系 **`ω_left + ω_right ≈ 2 × ω_case`** 表述左右车轮转速的平均值由差速器壳体/终传输出约束；拐弯时左右轮可不同速。该关系是**理想运动学示意**：实际结构速比、轮胎有效半径、间隙、附着和控制需要单独考虑，不直接用于维修限值。

典型开放差速结构含壳体/行星（spider）齿轮、半轴侧齿轮、轴承与终传环齿/小齿轮（依配置）。差速器能容许左右轮速差，但**不能保证两侧在附着不同时各获得足够牵引力**；输出可受低附着轮所能承受的转矩限制。

### 4.2 LSD、锁止、电子制动模拟和主动转矩管理

- **机械限滑差速（LSD）**：可能通过摩擦片、螺旋齿轮或黏性机构产生左右差异转矩的约束；限滑强度、预载、油液规范不通用。
- **差速锁**：在满足机构条件的情况下强制限制相对轮速，改变转弯与附着适应特性；不能把“锁止模式”当任何路况下都安全的永久状态。
- **基于制动的牵引控制**：通过对打滑车轮施加制动等手段影响可用牵引表现；不是机械差速器内部变成 LSD，也不表示车轮摩擦极限消失。
- **主动耦合与扭矩矢量控制**：可能跨轴分配，或在左右驱动轮间差异分配，取决于离合器、电机、控制器与热/功率保护条件；存在不具备该功能的 AWD。
- **电驱电子差速/双电机**：具有多种架构实现，不能把双电机分别驱动前后轴等同每个车轮独立电机。

结构层面必须识别 `OPEN/LSD/LOCK/ACTIVE/UNKNOWN`。观察到同轴一轮打滑，不足以推断差速器“坏”；观察到某模式仪表亮灯也不能证明耦合器执行成功。

制造商案例：[GKN AWD systems](https://www.gknautomotive.com/en/products-and-systems/awd-systems/) · [GKN torque management devices](https://www.gknautomotive.com/en/products-and-systems/torque-management-devices/) · [Spicer differential assemblies](https://spicerparts.com/parts/axle/automotive-performance/differential-case-assemblies)。Spicer/Dana 的商用桥、后市场/性能零件示例**不得直接嫁接给缅甸 Probox/Fit**。
