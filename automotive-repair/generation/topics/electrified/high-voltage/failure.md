## 1. 分清六种证据层级，禁止由症状直接推导带电安全

高压系统可能涉及电池包、电池管理系统（BMS）、接触器和配电、逆变器/电驱、车载充电机（OBC）、DC/DC、绝缘监测、互锁（HVIL）、预充及热管理。正常功能在 [FUN-HV](./function.md)；本稿只研究“原因 → 物理/信息机理 → 功能影响 → 可见现象/证据 → 竞争反例”。控制器的“请求”不等于实际执行，接触器线圈状态不等于触点状态，主电源断开更不等于所有储能已经消失。

| 独立证据层 | 可以回答什么 | 不能凭此推定什么 |
|---|---|---|
| 请求与模式 | 是否曾请求 READY、驱动、充电、闭合接触器或预充 | 已成功执行、当前全车高压安全 |
| 许可与保护 | BMS、低压和车辆控制是否允许某操作 | 被禁止的直接原因只有某个元件故障 |
| 致动器反馈 | 适用车辆是否具备接触器/阀/继电器状态反馈 | 反馈必然代表触点、绝缘和导体的物理真实状态 |
| 电压、温度、绝缘等感知 | 已安装感知点的测量或诊断状态 | 所有支路、电芯、储能节点均与之同态 |
| 外部现象 | 无 READY、无法充电、限功率、告警、异常热/气味 | 一定是 BMS、电池、逆变器或接触器的唯一故障 |
| 安全资格 | 车型和受训人员按原厂程序形成的独立权威证据 | **任何仪表 OFF、断开命令、故障灯消失或本文的假设可证明高压安全** |

仅区分这些层级，不构成任何实时测量或维修指令。**有高压异常、碰撞、进水、疑似电池受损、烟雾/异味/异常热或火情时，停止使用并按原厂与当地有资质专业人员/应急部门处置；不进行现场高压诊断或试验。**

## 2. 绝缘下降：高压导体与车身电隔离的失败假设

绝缘保护要求设计规定的高压带电部分与车身或其他回路保持符合该车型的电隔离；公开的 [TI TIDA-01513](https://www.ti.com/tool/TIDA-01513) 是**绝缘监测技术实例**，不是车辆通用电阻限值或现场操作法。

| ID | 候选原因 → 作用机理 → 影响/症状 | 有区分意义的证据类别与反例 |
|---|---|---|
| HV-F01 | 线路/连接器的绝缘层损伤、潮湿或污染 → 可能增加高压对车身的漏电路径 → 控制器报告绝缘异常、限制驱动/充电或拒绝上电（取决于设计） | 电池包内/外、OBC、逆变器或线束是不同候选；仅“绝缘低”信号不能定位部位，更不能证明具体漏电流或安全 |
| HV-F02 | 电池包内部受潮、部件老化或机械损伤 → 局部电隔离恶化或其他电气危险 → 保护许可变化 | 同一告警也可能由外部附属高压模块、监测器自身或通信/时序问题引起；不能据此判断电池包内部已发生某种失效 |
| HV-F03 | 绝缘监测通道、采样参考或通信不可信 → 控制器观察值异常而真实漏电状态 UNKNOWN → 可能保守阻断 | “监测信号故障”与“物理绝缘损失”两条链不能混同；监测无法证明正常时，同样不能反向宣告电隔离安全 |

**否定错误推理**：HVIL 连续不等于绝缘符合要求；绝缘告警解除不等于可以接触高压导体；湿度、雨季、冲洗或碰撞后的安全状态不能由症状清除推断。**不提供绝缘表、阻值、针脚、试验位置、工装、断电、拆卸或连接步骤。**

## 3. 高压互锁 HVIL：连接完整性和信号完整性，不是残余能量证明

HVIL 可能通过低能量监测路径判断指定连接器/盖板等的连接完整性，并向控制器报告状态。是否配备何种回路由车辆架构决定；[TI TIDA-020069](https://www.ti.com/tool/TIDA-020069) 仅说明一种供应商参考设计。

| ID | 原因 → 机理 → 功能影响 | 竞争原因及反证 |
|---|---|---|
| HV-F04 | 被监测连接、线束或回路实际中断/接触异常 → HVIL 状态改变 → 按车型策略禁止新的高压许可、限制工作或请求隔离 | 低压供电丢失或监测器输入故障也可能产生类似状态；不能只凭 HVIL 报警认定哪个连接器未就位 |
| HV-F05 | 回路检测元件、传感/控制线路或软件状态异常 → 虚假开路/不可信互锁状态 → 高压被拒绝但物理连接可能仍存在 | **反向亦然**：显示 HVIL 正常不代表绝缘、接触器状态、直流母线能量或事故后安全均正常 |

HVIL 是“被监测接口状态的一种证据”，不是高压系统“已经放电”的证明。尤其禁止将 HVIL/盖板作为探测、短接、绕过或恢复电气许可的操作目标。

## 4. 预充与直流母线：浪涌抑制及允许闭合的条件机理

逆变器和其他设备可能有直流母线电容。按车型，预充功能在允许形成主高压通路之前使母线电压状态以受控方式变化，以限制不受控充电电流；[TI TIDA-050063](https://www.ti.com/tool/TIDA-050063) 提供的是**高压预充拓扑参考实例**，而不是所有 BEV 的电路图。

| ID | 条件/候选原因 → 电气或控制机理 → 可能影响 | 竞争假说与可区分证据类别 |
|---|---|---|
| HV-F06 | 预充支路、受控功率器件或其驱动失效 → 预期的母线电压演化未形成 → READY/主接触器许可可能被拒绝 | 主电池不允许输出、低压驱动不足、测量通道异常或正常保护都可能造成相同“预充未完成” |
| HV-F07 | 直流母线电容/负载存在异常漏耗或短路候选 → 所需预充能量与预期不符 → 预充保护或供能失败 | 对应观测也可能来自某个非电池负载、执行器或控制时序；不应直接推断“预充电阻已坏” |
| HV-F08 | 电压感知/状态反馈与真实母线状态不一致 → 控制器误判断完成或失败 → 可能保守拒绝上电或产生更严重风险 | 观察到预充成功标志并不证明母线所有节点无危险；没有原厂定义的时间窗/阈值不得给定量结论 |

预充失败不等于可以重复上电验证，更不能旁路预充、强制合闸、触碰母线或人为放电。

## 5. BMS、电芯监测与充放电许可：不能把限功率等同于坏电池

[博世 BMS 与电池断开单元](https://www.bosch-mobility.com/en/solutions/powertrain/fuel-cell-electric/battery-management-system/) 说明电池状态监测、管理和断开保护等模块可如何分工；该页面为供应商实例，**不等于缅甸任何 BEV 的电芯数、化学体系、SOC 算法或熔断保护**。

| ID | 候选原因 → 状态机理 → 影响/现象 | 竞争机制与证伪问题 |
|---|---|---|
| HV-F09 | 电芯/模组容量、内阻或一致性差异增大 → 某些单体提前触及受限条件 → 整包允许放电/充电能力可能下降 | 环境温度、实际 SOC、老化、负载与测量偏差竞争；可用功率降低不等同电池包故障确诊 |
| HV-F10 | 温度、电压、电流测量链或 BMS 通信异常 → 状态估计不可信/许可收紧 → READY、快充、再生或扭矩请求受限 | 实际过温/过压/欠压也可能触发同一保护；“传感器坏”不能仅由报警类别推定 |
| HV-F11 | 保护状态、充电接受能力或 SOC 边界变化 → BMS 合法拒绝部分能量流 → 驱动/充电/回收减小 | SOC 高不等于允许继续快充或强再生；SOC 低不等于整个电池损坏 |
| HV-F12 | 电池内部安全事件、严重过温或物理损伤 → 可能产生无法由软件许可消除的危险、保护停机或热事件 | 不是所有温度告警都表示热失控，但任何烟雾、气体、明显异常热或事故损伤须按危险情形处理，不能继续实验以区分根因 |

**失效与正常保护必须分账**：保护限制可能恰是正常响应；需要原厂上下文才能区分控制逻辑错误、采样错误、真实储能问题与环境条件。公开资料不支持推断某辆车“电池寿命已尽”或“应拆包”。

## 6. 主接触器、驱动反馈、开路与粘连：命令 ≠ 实际电气状态

接触器和适用的电池断开装置按设计管理高压能量路径。控制状态、驱动供电和触点物理状态是不同证据；并非所有车辆具有相同数量的接触器或可读的反馈节点。

| ID | 候选原因 → 物理机理 → 后果 | 竞争原因与反例 |
|---|---|---|
| HV-F13 | 接触器驱动线圈/低压供电/控制许可缺失 → 请求闭合但不能形成预期主电路 → 无 READY 或驱动/充电许可失败 | BMS 不允许、HVIL 或预充失败可能同样不闭合；此时接触器未必损坏 |
| HV-F14 | 触点机械卡滞、粘连或异常接触阻抗 → 已请求的断开/闭合与真实导通状态不同，可能造成电弧/发热/残余连接风险 | 控制器的断开命令或反馈异常不能凭表面现象证明真实电气隔离；粘连是**危险假设**，非现场允许验证的检查项目 |
| HV-F15 | 状态感知或通信失真 → 接触器物理真实状态无法可信确认 → 控制器可能拒绝后续状态转换 | 可能与驱动电源、采样链、BMS 的安全策略竞争；不能用“无高压工作”推断全部触点已断开 |

**关键反例**：所有接触器均被“请求断开”，也**不能证明**高压电池内部、母线电容或其它支路已无危险电能。绝不提供触点强制操作、接触器电阻/电压测量、焊接/拆装、手动闭合或放电路径。

## 7. 热管理与温度限制：合法保护、传热失败与信号错误各不相同

电池、电机、逆变器和适用的充电/低压变换模块在不同工况产生热量；车型配置决定风冷、液冷、油冷、冷媒换热、加热、多个回路或共享管路。参照 [DOE AFDC BEV 组件说明](https://afdc.energy.gov/vehicles/how-do-all-electric-cars-work.html) 和同仓 [FUN-THERMAL](../../thermal/function.md)。

| ID | 原因 → 热/控制机理 → 影响 | 竞争解释与证据类别 |
|---|---|---|
| HV-F16 | 环境温度、充放电负载或散热余量变化 → 部件热限制先于硬件故障触发 → 允许功率/快充/再生受限 | 这是可能的正常保护；仅凭充电变慢不能认定冷却泵失效 |
| HV-F17 | 按车型存在的泵、风扇、阀、冷媒/换热支路不能满足实际热流 → 局部温升或温区差异扩大 → 热许可降低 | 泵命令不等于真实流量；制冷剂或空气侧能力、液体流路和传感偏差等竞争 |
| HV-F18 | 温度传感器、线束/通信或状态估计异常 → 系统感知温度与物理热态不一致 → 错误限制或未识别风险 | 温度警报不能单凭一个读数确定热事件已发生或已排除；不能推荐故障清除后继续试驾 |

事故、进水、疑似电池包热失控、冷却液接触高压系统等属于停用/专业救援边界。参照 [NHTSA 电动及混动车安全](https://www.nhtsa.gov/vehicle-safety/electric-and-hybrid-vehicles)，资料描述物理损伤后可能的延迟危险，不能由车辆冷却或仪表无告警证明安全。

## 8. 低压唤醒、DC/DC 与信息许可：避免用“高压故障”掩盖低压根因

BEV 仍依赖低压车网支持控制器唤醒、通信、继电器/接触器驱动及其他必要功能；某些情况下 DC/DC 又需要高压系统许可才能持续为低压网络供电。因此低压失供与高压拒绝相互影响，不构成“哪个先坏”的循环因果定论。参阅 [FUN-LOWV](../../electrical-low-voltage/function.md) 与 [DOE AFDC BEV](https://afdc.energy.gov/vehicles/how-do-all-electric-cars-work.html)。

| ID | 候选原因 → 信息/供电机理 → 现象 | 竞争解释与边界 |
|---|---|---|
| HV-F19 | 辅助电池、低压配电/供电或接地异常 → BMS/VCU/接触器控制失去工作条件 → 高压许可/READY 不成立 | 表现像“高压电池没电”，却可能只是低压/唤醒失败；不能通过高压带电测试判定 |
| HV-F20 | DC/DC 供电能力或许可异常 → 辅助电池无法获得所需补能 → 低压功能与高压控制之间出现反馈性限制 | 也可能是低压储能、负载异常或上游高压根本未接通；不能仅凭 12V 告警判 DC/DC 损坏 |
| HV-F21 | CAN/其他车内通信与状态同步异常 → 控制器无法获得可信 BMS、HVIL、热或接触器许可 → 驱动/充电请求被拒绝 | 通信超时或故障码不等于物理绝缘已损坏；断言哪条线/控制器故障需要车型级资料 |

本节不含任何端子测量、搭电、断开 12V 电池、复位/旁路控制器等可执行步骤。

## 9. 充电和驱动的竞争故障：避免误把所有“充不进电”归为 BMS

| 观察（非确诊） | 高压相关候选 | 同样合理的竞争机制/正常边界 |
|---|---|---|
| READY 不成立 | 绝缘/HVIL、预充、BMS、接触器、低压许可 | 外部充电模式、车辆身份认证、正确的非高压控制状态、通信或其它架构保护 |
| 行驶限扭矩 | 电池可用功率、逆变/电机和热保护 | 附着、驾驶模式/控制请求、道路坡度，控制器在温度/储能边界的正常降额 |
| AC 充电无法开始 | 电池充电许可、OBC/车内接通状态 | 交流供电/EVSE、接口/协议、设定充电计划、低压与通信 |
| DC 快充无法开始或功率低 | BMS、电池温度/允许功率、受控高压路径 | 直流充电设备与协议、站端限额、SOC 高/低温、其他正常热限制；不能直接套用 OBC 交流转换缺陷 |
| 再生制动减弱 | 电池接收能力、逆变/电机或热许可 | SOC、低温、ABS/ESC/附着、减速/摩擦制动协调；不能由弱回收推断摩擦制动正常或失效 |
| 关机后仍有热/噪音变化 | 按车型允许的热管理或余热状态 | 也可能是某个故障，但不表示高压已经消失、可以检修 |

[DOE AFDC](https://afdc.energy.gov/vehicles/how-do-all-electric-cars-work.html) 区分车载 OBC、DC/DC、牵引电池和热系统。实际充电协议/版本、连接器与适用性必须来自具体车辆/站端资料。

## 10. “证据可辨识度”矩阵：同一告警至少存在两条不同原因链

| 假设争议 | 支持某一假设所需的合法信息类别 | 明确反例、尚未解决的 UNKNOWN |
|---|---|---|
| 物理绝缘下降 vs 监测误报 | 车型规定的独立感知/诊断一致性、发生条件与上下文 | 单个告警码或一次复现不构成安全与根因证明 |
| HVIL 真实开路 vs 低压/采样故障 | 原厂定义的多信号一致性、装配接口和版本 | 不同车辆未必有同一 HVIL 拓扑，无法由一般资料定位 |
| 预充支路失败 vs BMS 拒绝 | 原厂状态语义、许可历史、控制和反馈相互关系 | 不允许强制预充、反复上电或对母线做现场试验 |
| 接触器物理粘连 vs 反馈不可信 | 车型原厂物理状态验证/审计证据 | 接触器“断开命令”不证实断开，更不证实无残余电能 |
| 电芯限制 vs 热保护 vs SOC 正常边界 | 原厂限功率原因及安全受控历史记录 | 任何 SOC 单值、最高温度单值都非故障诊断或安全证明 |
| 电驱故障 vs 低压/通信/充电外部因素 | 真实架构、同一时间段的请求/许可/反馈和工况身份 | 性能下降、无 READY、充不进电不是某个高压部件坏的充分条件 |

**技术深度限制**：以上“所需证据”只表达因果鉴别逻辑，不授权读写 ECU、执行保养模式、故障码清除、运行高压测试或车辆道路测试。没有车型与受训人员，就只保留 UNKNOWN。

## 11. 危险边界、适用范围和后续知识缺口

1. **高压危险 STOP**：不涉及带电/断电、开盖、插拔、短接 HVIL、绝缘测量、接触器手动操作、预充测试、放电/放电等待、维修口/服务插销、线束针脚测量、冷却液高压部件拆卸、电池拆包、碰撞救援或自动化操作步骤。
2. **残余能量/事故危险**：仪表 OFF、READY 消失、低压电池失电、接触器“请求断开”、主保险或熔断状态、HVIL 报警/恢复均不等于安全。事故、挤压/刺穿、进水、火情、烟雾、异味及疑似热失控可能存在持续或延迟风险，需交由 OEM 授权专业人员/应急部门按本地规定处理。[NHTSA EV 安全](https://www.nhtsa.gov/vehicle-safety/electric-and-hybrid-vehicles) 只支持安全风险的研究说明，不替代缅甸法律或救援指南。
3. **车型差异**：仅 generic light BEV。不得由 BEV 标签推定直流电压等级、电池类型/化学体系、BMS 管脚、HVIL 位置/数量、充电接口、接触器数量、预充形式、隔离监测频率、冷却方案或失效响应。Honda IMA / i-DCD / e:HEV 是不同混动架构，不直接套入此 BEV DAG；缅甸 Probox/Fit 车架身份及故障率均 UNKNOWN。
4. **专业知识缺口**：需要原厂 VIN/销售地区/年款/硬件软件版本、原始 DTC 定义、控制状态机、故障保护动作、事故应急指南、授权维修技能、合法实车历史收据，才可能从本通用模型进入车型诊断差量。供应商 TI 参考设计绝非任何 OEM 实装电路。
5. **DAG 后继**：已批 [PLAN](../../../PLAN.md) 的下一节点 REP-HV 只有在 FAIL-HV 已真实交付且无权威纠错/STALE 时才可按 #61 独占 Claim 进行**非可执行**安全鉴别知识生成；本文件不是 REP-HV，也不启动新任务/发布职业资格。
