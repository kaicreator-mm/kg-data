## 1. 先分清实际机械与电能架构

| 家族与原厂证实范围 | 正常主要动力路径 | 真正有意义的失效归因边界 | 不能混入的另一家族假设 |
|---|---|---|---|
| **IMA + CVT**：2010 日本 Fit Hybrid 一类 | 发动机提供机械动力，单电机按条件助力/回收，适用 CVT 将动力传向车轮 | 发动机输出、IMA 助力/回收许可、PCU/电池与实际 CVT 传力可能分别成为限制 | 不能假设有 i-DCD 的 7DCT、独立发电机或 e:HEV 的三模式双电机串联系统 |
| **i-DCD + 7DCT**：2013 日本 Fit Hybrid 一类 | 发动机与传动内集成的**单电机**，按受控离合接合/脱开实现 EV、Hybrid、Engine Drive 和条件再生 | 发动机机械输入、离合/DCT/换挡执行、同一电机/电池、控制软件与模式许可相互耦合 | 不能把 7DCT 当金属带 CVT，也不能解释成“双电机独立发电＋牵引” |
| **e:HEV 双电机**：2020 日本 Fit e:HEV 家族 | EV：电池→牵引电机；Hybrid：发动机→发电电机→电能→牵引电机；适用 Engine Drive：发动机经直连离合向车轮传力 | 牵引机、发电机、PCU/电池、发动机、机械直连离合和功率/模式许可应按真实模式分别分析 | 官方“Electric CVT”不是默认有传统皮带/链条/夹紧油压的机械 CVT；也不是 i-DCD 7DCT |

本节分别由 [Honda 2010 Fit/IMA 发布](https://global.honda/en/newsroom/news/2010/4101008eng-fit.html)、[Honda 2012 i-DCD 公告](https://global.honda/en/newsroom/news/2012/4121113aeng.html)、[Honda 2013 Fit Hybrid 发布](https://global.honda/en/newsroom/news/2013/4130719aeng.html)、[Honda 2020 Fit e:HEV 发布](https://global.honda/en/newsroom/news/2020/4200213eng-fit.html) 和 [Honda e:HEV 双电机机理](https://global.honda/en/tech/two_motor_hybrid_system_honda_eHEV/) 支持其**产品家族存在及正常功能**。这些材料不证明以下失效假设实际发生，也不证明缅甸车辆已经装配相应系统。

## 2. 不把驾驶请求、控制允许和实际轮端力矩混为一谈

研究级因果分解：

`驾驶/制动请求 → 控制器判定与模式选择 → 发动机/电机可用能力及储能许可 → 离合/齿轮/电气传力实际状态 → 轮端可用扭矩 → 车辆动态与仪表观察`。

- **请求层**：驾驶者要求加速、维持车速或减速；请求本身不证明发动机、电机或制动执行。
- **许可层**：SOC、温度、电池充放电允许、控制器通信/自检、发动机和传动保护可能改变或否决请求；“动力被限制”不必然等于硬件损坏。
- **产生层**：发动机能否输出实际机械力矩、电机/逆变器能否输出实际电磁力矩、发电机能否提供电能，随架构和工况不同。
- **传递层**：IMA 的 CVT、i-DCD 的离合和 7DCT、e:HEV 的电驱或直连离合是三类不同的传力条件；无轮端输出未必是发动机没有输出。
- **观测层**：仪表模式、转速、声音、可感加速度与轮端力矩是不同量；缺少 OEM 数据时不把任何一种观测解释成唯一根因。

三个基本反例：①电池 SOC 较高仍可能因温度或保护**不允许**输出/接收目标功率；②发动机转速升高而车速无同步上升，在 e:HEV **Hybrid Drive** 的发电路径上可属正常，不证明“CVT 打滑”；③某一运行模式未进入，可能是输入条件不满足、正常节能策略、控制故障或实际部件故障，不能直接宣布“离合器损坏”。

## 3. IMA + CVT：发动机主机械路径、单电机辅助和回收的候选失效

Honda 2010 日本 Fit Hybrid 产品资料确认该时期 **1.3L i-VTEC + IMA + CVT** 的配置。以下 IMA 假设只针对这类功能架构；未获得 VIN/ECU/维修手册前，不能判定特定车辆是否具有对应电池代际、离合元件、动力限值、启停策略或检测信号。

| 假设 ID | 条件/候选原因 → 机制 → 可能影响 | 竞争解释、可证伪的观察方向（非维修操作） |
|---|---|---|
| HEV-IMA-01 | 牵引储能可用功率下降、热限制或 PCU 许可不足 → 电机助力减少 → 发动机承担更多加速负荷 | 发动机本身输出不足、CVT 传力限制、上坡/满载都可能造成同样加速感；“助力减弱”不能直接判电池失效 |
| HEV-IMA-02 | 适用的电机/逆变或相关控制信号异常 → 预期助力命令与实际输出不一致 | 混动辅助可能本来在当前 SOC、温度、车速/负荷条件下不被请求；是否真异常须有车型级命令/许可证据 |
| HEV-IMA-03 | 发动机燃烧/起动能力或控制许可异常 → 机械输入不足或启动状态不符 → 牵引能力受限 | 某些合法停机/自动启停并非“无法启动”；不能以不听见发动机声音判断起动机或 IMA 电机损坏 |
| HEV-IMA-04 | CVT 机械传力、变比执行或其液压/润滑状态受限 → 发动机/电机输出与轮端牵引不一致 | 电池助力缺失、轮胎附着差、驱动请求不同也可造成类似感受；传统 CVT 假设只能在确有该 CVT 硬件时成立 |
| HEV-IMA-05 | 减速时电池接收能力不足或回收未获许可 → 电机再生减小 → 回收能量变化 | SOC 高/环境温度/稳定性或制动协调状态也会合法限制回收；不意味着摩擦制动“坏了” |
| HEV-IMA-06 | 冷却、低压供电或通信许可异常 → IMA 功率/功能可被保护性限制 | 同一限功率症状也可能来自发动机、CVT 或电池老化；不能直接给“更换 IPU/电池”结论 |

**不可套用**：IMA 的“发动机机械主路＋单电机辅助”不能用 e:HEV 的“发动机发电机→牵引电机”双机路径定位；IMA-CVT 与普通单一燃油车 CVT 也未必有相同控制权限和维修参数。

## 4. i-DCD + 7DCT：离合接合、模式转换和软件/硬件竞争解释

Honda 2012 技术公告与 2013 Fit Hybrid 发布确认：i-DCD 的驱动单元由 **7 速双离合变速器和单个内置电机**组成；Honda 2012 公告说明适用 EV 条件下离合脱开发动机，适用混动/发动机模式下离合接合，并可能在减速时通过脱开发动机增大回收机会。参见 [Honda i-DCD 技术资料](https://global.honda/en/tech/hybrid_system_SPORT_HYBRID_i-DCD/) 和 [Honda R&D 7DCT 论文](https://global.honda/en/technical-review/papers/10002116/)。

| 假设 ID | 条件/候选原因 → 机制 → 可能影响 | 竞争解释与范围反例 |
|---|---|---|
| HEV-IDCD-01 | 发动机接合/脱开请求与实际离合接合能力不一致 → 预期 EV/Hybrid/Engine 路径无法按要求转移力矩 | 可能是正常不满足模式条件、低电池许可、执行器/机械离合状态或控制软件；**不能**从单次切换迟疑直接确诊离合损坏 |
| HEV-IDCD-02 | 7DCT 选挡/接合控制、状态反馈或控制软件不一致 → 已请求的齿轮路径未正确形成 → 起步延迟/无驱动等候选现象 | 电机供能不足、发动机不输出、驻车/制动/其他控制许可同样可能阻止牵引；不是金属带 CVT 夹持问题 |
| HEV-IDCD-03 | 单台内置电机或功率电子可用能力下降 → EV Drive 受限，Hybrid Drive 的助力与再生能力改变 | 车辆允许发动机单独机械驱动时可能仍有牵引；模式不出现也可能是 SOC/温度/充电状态正常限制 |
| HEV-IDCD-04 | 发动机起动/燃烧能力、传动机械接合或其许可限制 → 适用混动与发动机驱动模式无法按预期建立 | 若控制器合法选择 EV Drive，发动机短时未起动可属正常；不可把所有模式下的停机归为起动故障 |
| HEV-IDCD-05 | DCT 温度、润滑或离合热负荷受限 → 控制器可能保护性限制换挡与输出 | 大负载、低速频繁变速、控制保守策略和真实机械故障可竞争；无具体 OEM 阈值不得作过热判定 |
| HEV-IDCD-06 | 电池接收能力、单电机再生及离合断开许可变化 → 回收减弱且制动能量分配改变 | 滑路/ABS/ESC、SOC、温度与摩擦制动策略是独立竞争变量；不能把“回收弱”定为制动液路故障 |
| HEV-IDCD-07 | 控制器软件/校准缺陷 → 错误选挡、离合控制或状态判定 → 起步延迟/无法起步的某些限定实例 | 2014 日本历史召回证明某类**控制软件问题确实曾出现**；不证明所有 i-DCD 有相同缺陷，也不支持以此替代对机械、供电和允许条件的区分 |

**已发生的、但严格限定的出版方证据**：Honda [2014-02-10 日本 Fit Hybrid 与 Vezel Hybrid 召回公告](https://global.honda/en/newsroom/news/2014/c140210eng.html) 明确将**日本指定生产期及受影响车辆**的 7DCT 控制软件问题与起步延迟/无法移动关联，还提及其他时期不同原因的相关召回。这是“软件原因与机械症状不可混同”的一个真实历史反例；不是当前缅甸在用车辆的故障统计、VIN 召回资格、零件缺陷定论或刷写指令。**无需、也不得**在本稿给出升级软件、离合校准、液压测试或拆卸步骤。

**模式反例**：i-DCD EV 下发动机不经机械路径提供扭矩不等于发动机故障；i-DCD Hybrid 的单电机助力不是 e:HEV 的独立发电机驱动牵引电机。减速回收是另一种能量流条件，不是与 EV/Hybrid/Engine Drive 平行的“第四牵引模式”。

## 5. e:HEV 双电机：电能主路径、发电与机械直连的独立失效类

Honda 2020 日本 Fit e:HEV 与官方双电机说明确认牵引电机、发电电机、PCU、电池、发动机以及适用的高速机械直连模式。它没有由名称“Electric CVT”自动产生传统钢带/链条机械 CVT 的夹持油压/带轮失效链。

| 假设 ID | 条件/候选原因 → 机制 → 可能影响 | 竞争解释与正常反例 |
|---|---|---|
| HEV-EHEV-01 | EV Drive 中电池放电许可、PCU 或牵引电机能力不足 → 可用电驱扭矩下降 | 高 SOC 不代表功率一定可用；驱动请求、速度限制、轮胎附着和温度保护都需分离 |
| HEV-EHEV-02 | Hybrid Drive 中发动机机械输出、**独立发电电机**或发电功率控制受限 → 牵引电机可用电源路径下降 → 有条件的驱动力限制 | 发动机转速与车速不固定同步可属正常发电路径；不能由高转速认定皮带式 CVT 打滑 |
| HEV-EHEV-03 | PCU 变换或供电/通信状态异常 → 牵引电机实际扭矩与目标不符 | 电池限功率、发电功率限制、热管理和踏板/整车控制同样可能减少目标扭矩 |
| HEV-EHEV-04 | Engine Drive 机械直连离合未满足接合许可/能力 → 机械直连模式无法按预期形成 | 低速或效率不适合时不使用 Engine Drive 可能完全正常；不能借用 i-DCD 7DCT 换挡故障模型 |
| HEV-EHEV-05 | 发电机/发动机调速与牵引请求之间的控制协调偏差 → 转速/加速度响应感知不一致 | 模式策略可主动改变发动机转速追求效率；单靠声浪不能确定扭矩误差或控制故障 |
| HEV-EHEV-06 | 牵引电机再生与电池接收、整车制动许可不一致 → 可回收功率下降 | 过高 SOC、低温、附着稳定性限制下回收降低可能正常；不得据此认定摩擦制动失效 |
| HEV-EHEV-07 | 电池或电驱/功率电子热保护 → 充放电/牵引能力被限制，模式策略可能改变 | 环境、空调/电池热管理需求及真实冷却条件可竞争；不等于冷却泵必坏 |
| HEV-EHEV-08 | 低压供电/控制器通信异常 → 模式授权、READY/发动机启动请求无法成立 | 这与电池包储能能力、传动离合损伤不同；没有车型级安全状态和 DTC 不能定位具体控制器 |

**否定错误迁移**：e:HEV Hybrid Drive 的发动机可以用于发电而不直接以固定机械传动比驱动车轮；Engine Drive 适用时才存在直接机械路径。e:HEV 不应套用 i-DCD 的奇偶挡离合控制或 IMA-CVT 的机械带轮滑移。详见 [Honda e:HEV 技术说明](https://global.honda/en/tech/two_motor_hybrid_system_honda_eHEV/) 与 [Honda 2020 Fit 原厂发布](https://global.honda/en/newsroom/news/2020/4200213eng-fit.html)。

## 6. 跨架构共同原因：电池、温度、许可、起动与制动之间的竞争

以下横向耦合只表示研究级**可能机制**，不意味着三种混动都具有同样电池化学体系、传感器、车架布置、起动元件或制动液路。

| 维度 | 条件与结果的候选因果链 | 正常反例 / 独立竞争假说 |
|---|---|---|
| SOC 与可用功率 | BMS/能量管理依据实际可用储能及保护限制电池输出/输入 → 助力、纯电或再生可用性变化 | SOC 高可能禁止大量再生，SOC 低可能限制助力；SOC 显示不等于电池健康证明 |
| 电池温度/热管理 | 温度或冷却/加热能力影响电池可接受功率 → 控制器保护限制扭矩、发电或回收 | 环境温度变化本身可引起合法限制；仅见“限功率”不能确认泵、冷却液或电池部件故障 |
| 发动机起动 | 发动机请求、燃烧条件、起动相关电机/机械链和控制许可可能互相限制 | 发动机暂时未启动可能是合法 EV/启停模式；“不启动”还可能与低压供电、其他许可相关 |
| 低压与控制器通信 | 12V 供电、唤醒、网关/数据真实性影响高层系统准备与模式许可 | 低压/通信故障与牵引电池或机械传动故障不是同一结论 |
| 模式转换 | 实际状态/允许条件与驾驶需求不一致可能导致驾驶感知落差 | 合法模式选择（温度、SOC、效率）会改变何时发动机参与；非预期感觉不自动等于故障 |
| 驱动需求与附着 | 轮端实际可传牵引受道路摩擦、驱动控制与动力系统共同限制 | 动力系统输出正常也可能因轮胎低附着无法获得预期加速度 |
| 再生与摩擦制动 | 车轮机械能经适用电机回收；电池许可和整车制动协调决定可回收范围 | 不能从能量回收弱推出摩擦制动安全、ABS/ESC 合格或需要特定制动操作；保持安全 STOP |

现有同仓跨系统链接：[FUN-HEV-FAMILY](./function.md)、[STR-HEV-FAMILY](./structure.md)、[FUN-HV](../high-voltage/function.md)、[FUN-BRK](../../braking/function.md)、[FUN-THERMAL](../../thermal/function.md)。它们是交叉阅读材料，**不是本 R9 节点的新增硬 DAG 前置**。

## 7. 假设区分表：观察本身永远不能直接跳到维修结论

| 观察（仅概念示例） | IMA 可能解释 | i-DCD 可能解释 | e:HEV 可能解释 | 跨家族非唯一因素 |
|---|---|---|---|---|
| 驾驶员请求加速但实际牵引不足 | 发动机、辅助电机、CVT 输出或功率许可 | DCT/离合接合、单电机、发动机、软件状态 | 牵引/发电电机、PCU、直连模式、发动机 | 附着、SOC、温度、低压、通信、保护 |
| 起步迟滞、无法建立牵引 | CVT/发动机主路与助力限制 | 7DCT 控制/接合状态；有历史限定软件召回案例 | EV 电驱许可/牵引机/PCU 或其它控制 | 不证明某个离合坏，也不证明当前车属于召回范围 |
| 发动机转速与速度不同步 | CVT 变比本可变 | DCT 挡位/离合及模式转换可改变关联 | Hybrid Drive 发电模式本来可不直接锁定车速 | 驾驶策略、测量延迟、机械传动与控制 |
| 回收强弱变化 | 单电机及储能接收 | 7DCT/同一电机与发动机脱开条件 | 牵引电机、电池接收与协调 | 制动/稳定性要求、SOC、温度 |
| 模式状态不如预期 | 无需强行期待 e:HEV 三模式 | EV/Hybrid/Engine 条件及 7DCT 真实状态 | EV/Hybrid/Engine 以及发电/直连许可 | 确认机型/软件版次前，“模式消失”不一定为错误 |
| 热后动力受限 | 电池/辅助电机/ICE/CVT 热状态 | 电池/单电机/7DCT/发动机热保护 | 电池/PCU/牵引机/发电机/ICE 热保护 | 真实温度与许可阈值、散热器/泵状态未知 |

**研究假设的最低证伪结构**：若要将某一解释提高可信度，至少需要能证明该车实际安装了所称架构、处于该动力模式，并区分请求/允许/实际三层的独立材料；只有一个症状、泛化 DTC 或网上故障案例不构成此种证明。真实安全受控的检测、历史维修记录及 OEM 定义须由有资质人员根据适用手册核实，本文章**不**提供具体实施步骤。
