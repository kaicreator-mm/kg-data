# 车身电气、照明、门锁与乘员约束系统：结构组成及安全边界（STR-BODY-SAFETY）

> Task: `STR-BODY-SAFETY` · MAIN: [parts-system #61](https://github.com/kaicreator-mm/parts-system/issues/61) · Stage: `MARKDOWN_ONLY_GENERATION`。  
> **资格**：`MODEL_GENERATED_UNVERIFIED`，仅为通用轻型乘用车结构研究；不同年代和市场车款差异显著。无任何指定缅甸 VIN/底盘年款的 OEM 零件位置、SRS 标定/配置、接线、引爆回路、气囊拆装或安全作业许可。本文件**不提供**断电、检测、短接/模拟气囊模块、拆卸、修复、编程或主动触发约束装置的实操步骤。

## 1. 车身相关系统不是一个“万能 BCM”

通用概念结构：

```text
车身与乘员保护相关系统（结构树示意，非任何车款实装图）
├─ [A] 车身结构与乘员舱：框架/门框/侧围/顶梁/地板/玻璃/碰撞吸能路径
│  └─ 铰链、锁止件、密封、防水排水与车门线束连接
├─ [B] 车身电气/舒适：12 V 或其它低压供电/保险/网络
│  ├─ BCM 或分布式门控/照明/雨刮/玻璃/车门锁模块（按架构）
│  ├─ 开关、继电器/半导体驱动、执行电机、局部传感器与反馈
│  └─ 驱动者 HMI/仪表告警、网关与共享通信接口
├─ [C] 外部/内部照明：前照灯、转向/制动/位置灯、室内照明
│  └─ 灯源/驱动/散热、开关控制、线路、灯具和故障监测（按设计）
├─ [D] 进入与锁止：门锁执行、门开关、钥匙/遥控/防盗接口（按设计）
├─ [E] SRS 被动乘员保护：座椅安全带/卷收器/带扣/预紧器
│  ├─ 碰撞/加速度/压力传感器（按设计）
│  ├─ 气囊控制器和约束执行单元（按装车配置）
│  ├─ 前部/侧部/帘式等不同气囊模块（非每车都有）
│  └─ 乘员识别/座椅位置/带扣状态（可选）
└─ [F] 相关但独立：ABS/ESC、ADAS 主动控制、低压网络/网关、HV
```

**边界**：车门开关、车身 BCM、约束控制器和发动机 ECU 不应被视为一块硬件。不同年份汽车可能以继电器与简易控制器为主，也可能使用高度集中的区域控制器/中央网关；本篇仅刻画“可能组成、接口与职责”。

## 2. 车身电气、低压电源和控制模块

| 对象 | 结构角色 | 常见配置差异及 UNKNOWN |
|---|---|---|
| 车身控制模块 BCM | 协调门锁、室内照明、转向灯、雨刮或其他车身负载的部分功能 | 各车可分成多个门模块/灯模块/网关，不保证所有负载受同一 BCM 控制 |
| 输入和状态采集 | 门开关、锁舌状态、照明控制、雨量传感器、开关按键等 | 传感器类型、输入极性、诊断支持依 OEM 网络及年款；没有某传感器不自动是故障 |
| 电源配电 | 低压蓄电池、熔断器、继电器、电子电源开关、接地、线束与插头 | 共享供电故障可能影响多个子系统；保险/引脚位置不通用 |
| 负载驱动 | 窗升电机、门锁执行器、雨刮电机、喇叭/灯驱动等（按装备） | 不同车可用机械、继电器、电机或电子驱动，不推断同一种电压/电流/占空比 |
| 网络与网关 | CAN/LIN/其他总线（按架构）承载状态、请求与故障消息 | 网关是通信转发/边界设备，不代表能把所有传感信号当独立物理观测 |
| HMI/仪表 | 向驾驶员报告开门、照明状态、SRS 警告等 | 警告显示不等于故障最终原因；不同仪表/网络架构可能只显示汇总码 |

与已生成 [STR-LOWV 低压结构](../electrical-low-voltage/structure.md) 的供电和车内通信概念保持**共享引用而非抄写**；车身控制只是同一车辆电气网络上的一个或多个消费者。

Continental 的 [Control Units](https://www.continental-automotive.com/en/components/control-units.html) 产品资料显示存在车身控制、网关、照明和电动闭合控制等不同模块。这是供应商产品与架构的有限证据，不能据此断定 Myanmar Probox/Fit 采用其中任何型号。

## 3. 车门、玻璃、车身机构与电气接口

- **门铰链/门锁/锁扣**属于保持车门闭合、允许开闭的机械结构；门锁电机/执行器和状态开关是机电连接，不能把车门“锁定命令已发送”等同机械锁舌确实到位。
- **车窗系统**可能有手摇/电动、玻璃导轨、升降机构、驱动电机、开关与控制模块；带防夹控制的车型可能有额外位置/电流/速度判断，而老车可能没有相同保护逻辑。
- **防水/排水与柔性线束**连接车门和车身；雨水、温度、门铰链反复运动等是潜在应力来源，但本文不宣称某车型必然有某一失效模式。
- **中央门锁/无钥匙**可由本地锁止机构、遥控模块、BCM 与防盗/发动机授权系统协作；“遥控不响应”可能属于钥匙、电源、接收、控制或机械锁，并非一个固定零件。

这些是后续 `FUN-BODY-SAFETY`（目前未获新 DAG 准入）可以研究的正常功能；本 `STR` 不代替功能或失效链。

## 4. 照明系统：灯源和控制策略并非一一对应

| 照明用途 | 候选硬件或接口 | 不得泛化的假设 |
|---|---|---|
| 近光、远光 | 卤素/HID/LED 等灯具、供电/驱动、开关/控制器（按车型） | 所有车都是 LED 或有自动调平、自适应灯 |
| 转向与危险警示 | 方向开关/控制模块、闪烁控制、灯具与反馈 | 所有继电器式旧车和现代 BCM 都有相同失效侦测 |
| 制动灯与倒车灯 | 相关状态输入、照明回路和输出灯具 | 制动踏板开关状态不等于四轮真实制动力；倒车挡请求不保证灯已亮 |
| 日行/位置/牌照灯 | 独立或共享灯具/模块，取决于市场/年款 | 任一缅甸二手车辆必有规定的日行灯模块 |
| 车内照明 | 车门开闭、用户控制、延时/调光等 | 打开车门灯不亮一定是 BCM 故障 |

照明控制可能与低压供电、门锁、仪表和网关通信相关；但头灯的光型、法规许可、灯具适配与改装合规性完全依相应车型/市场原始法规与认证，本文不提供更换或改装参数。[Continental lighting control units](https://www.continental-automotive.com/en/components/lighting/control-units-for-lighting-systems/Front-Light-Control-Units.html) 仅作可选技术供应实例。

## 5. SRS 与安全带：机械约束、传感、决策和执行必须分开

### 5.1 安全带是完整的被动防护结构，不是“气囊的辅助开关”

安全带可包含织带、带扣、卷收器、锁止机构、锚点、导向/高度调节（适用时）、负载限制器和预紧器（适用时）。某些卷收器能根据车辆加速度或织带拉出速度触发机械锁止；预紧器在相应设计中参与碰撞约束。**“安全带已扣”并不说明预紧器一定存在或在碰撞中工作**。

Autoliv 官方 [Seatbelts](https://www.autoliv.com/seatbelt) 介绍卷收锁止、预紧和不同带扣架构；NHTSA [Seat belts](https://www.nhtsa.gov/vehicle-safety/seat-belts) 明确安全带和气囊共同组成乘员保护。两份资料不确认任何特定老款 Probox/Fit 安装配置。

### 5.2 SRS 是独立的安全关键控制链

可能出现的概念链：

```text
碰撞事件/车体加速度或压力变化
  → 适用的碰撞传感器/输入
  → SRS 约束控制器对事件类型、严重度与配置进行判别
  → 条件符合时协调安全带预紧、气囊等相应约束机构
  → 安全气囊/织带与车身吸能结构共同对乘员作用
```

**这是结构与工作对象图，不是接线图、控制触发逻辑、诊断阈值或实验步骤。** 多数现代 SRS 结构可包含：气囊控制器、中央/周边加速度或压力传感器、前/侧/帘式气囊模块、坐姿/占座检测与带扣传感、约束执行通道、故障显示及通信接口；然而老车配备气囊的数量/位置、传感器、乘员分类功能与 SRS ECU 都可能不同。

Bosch 官方 [Occupant protection system](https://www.bosch-mobility.com/en/solutions/passive-safety/occupant-protection/) 和 [Airbag control unit](https://www.bosch-mobility.com/en/solutions/control-units/airbag-control-unit/) 可支持“周边传感器 + ECU 决策 + 可选约束执行单元”的结构。厂商产品资料**不能**推出所有车型具备相同传感器/触发回路，不能把某厂商安全测试数值用于真实车辆。

### 5.3 气囊不触发，并不必然证明系统失效

NHTSA 官方 [Vehicle Air Bags](https://www.nhtsa.gov/vehicle-safety/air-bags) 说明气囊是否展开受碰撞方向、严重度、传感位置和系统策略等条件影响；某些场景中安全带已足以提供必要保护。不可从“该事故没有展开”单独推论“某个气囊传感器坏”；反之也不能把已展开当作系统其他部件全部健康的证据。

**危险边界**：约束系统的点火/气体发生器与预紧器可能存在意外动作风险；即使电源关闭，具体装车系统也可能有储能或安全要求。没有 OEM 车型级维修手册和合格人员，不提供引爆回路测量、万用表检测、接插件处理、替换模块、事故后复位或程序刷写。本文也不提供任何用户能模仿的触发测试。

## 6. 被动安全、主动安全、ADAS 的区别

- **被动安全**：安全带、车体碰撞结构、气囊、预紧器等在碰撞过程中保护乘员；不负责日常保持路面附着或自动制动车轮。
- **主动安全**：ABS/ESC 等以行驶稳定/制动控制为目标，其结构和正常功能在 [STR-BRK](../braking/structure.md) 与 [FUN-BRK](../braking/function.md) 中单独建模。其刹车灯接口和低压通信不等于 SRS ECU。
- **ADAS**：外部感知/辅助控制可能调用制动、动力和转向，是否装配及权限取决于年款/配置。个别预碰撞约束可在有证据的车型中与 SRS 协调，但不应把所有气囊都归入 ADAS。
- **电驱高压**：BEV 高压绝缘/碰撞断电保护是一类不同的安全系统；可能和碰撞信号有接口，但本文件不提供高压隔离工序或电池拆卸内容。

## 7. 研究型失效与误判索引（不冒充已生成 FAIL/REP）

| 可见症状或信息 | 相互竞争的候选来源 | 一项信息无法证明的结论 |
|---|---|---|
| 多个车身灯/锁同时异常 | 共同低压供电、接地/保险、BCM、通信、局部线束或多个独立负载 | “两个灯不亮=必须更换 BCM” |
| 门锁遥控无响应 | 遥控输入、电源、接收器、门控制、执行器、机械锁止 | “钥匙能发射=车门执行器必坏” |
| 开门/车窗状态不可靠 | 开关/传感、机械位置、线束、电机、电源或模块 | “ECU 显示请求=玻璃真实运动已完成” |
| SRS 警告存在 | 控制器自检/传感/通信/配置等候选（须 OEM） | “有报警=立即更换气囊”，或“无报警=SRS 在事故中一定展开” |
| 事故后无气囊展开 | 可能本来不满足设计展开条件，也可能存在缺陷，依碰撞和系统记录 | “没展开=SRS 坏”或“没展开=完全安全” |
| 车辆电气故障连带被动安全异常 | 低压供电/网络/系统自检、独立故障同时发生 | “所有 DTC 都是同一个线束问题” |

对于 SRS 及约束安全，研究结束条件首先是**禁止猜测、明确专业移交与不可操作边界**。不以危险实操换取所谓“故障验证深度”。

## 10. 下一轮节点与真正完成边界

- **已完成（仅 STR 本体）**：车身与低压、门锁/车窗、灯光、乘员约束/气囊控制的结构，适用性分界、SRS 安全风险与知识复用接口。
- **未来 `FUN-BODY-SAFETY`**（候选，不在已审 PLAN 单独准入）：低压供电→BCM 状态机→车灯/门锁执行的正常功能；安全带机械约束与 SRS 的条件化事件响应，不给引爆与维修。
- **未来 `FAIL-BODY-SAFETY`**（候选）：公共供电、车身线束、门控与照明多故障，SRS 报警与真实碰撞条件的竞争解释；需独立审核新增 DAG。
- **未来 `REP-BODY-SAFETY`**（候选）：证据优先级与危险移交判断，不提供 SRS 实操、零件替换或事故后车辆复用许可。
