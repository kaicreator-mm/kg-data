## 1. 先标记危险停用条件，不能用“诊断还没确定”推迟安全处置

制动能力**明显下降、失去制动或难以控制减速**、踏板明显失去有效阻力或行程异常加长、疑似制动液泄漏、制动时明显失稳/严重跑偏、持续不释放造成局部过热/焦味，或与异常制动感同时出现的严重主制动警告，均应视为**潜在严重安全风险**。应停止正常使用车辆，在安全地点停放，并联系合格专业维修及合适的救援/运输。不能靠一次成功减速、再生制动仍能拖慢车辆、只有 ABS 灯而无其他灯等，推定车辆安全可继续行驶。

**严格禁止**将本文变成任何道路试刹、诱发 ABS/ESC、再次制动过热试验、制动放气/拆装、液压加压和泄漏探查、执行器通电、手动解除驻车、软件复位/刷写、HV 带电处置的步骤。安全现场/交通应急依车辆手册及当地专业救援处理；本文不指导危险驾驶动作。

| 危险级别 | 典型已报告症状 | 必须拒绝的推断 | 诊断/维修知识的正确终点 |
|---|---|---|---|
| **S0：基础制动有效性可疑** | 明显制动不足、异常下沉/无阻力踏板、可疑制动液泄漏、红色主制动异常且伴能力变化、严重偏航 | “双回路还有一个好的”“低速可以开去修”“有再生制动所以无碍” | **停止使用；专业救援/运输和具资质的车辆专用检测**；原因保持 UNKNOWN |
| **S1：持续拖滞/热与稳定风险** | 非预期轮端阻力、焦味/局部高热、明显单侧拖滞/左右不均 | “冷却就恢复”“一定是卡钳”“只需继续驾驶观察” | **停止使用并专业检查**；区分机械释放、驻车、液压残压、轴承和轮胎等竞争因素 |
| **S2：电子控制功能不明确** | ABS、ESC、电子助力/制动系统警告、降级提示但没有可靠完整症状资料 | “ABS 灯=全部刹车消失”或“只有 ABS 灯=保证普通刹车安全” | 依车型警告语义、组合、实际症状由专业人员评估；同时出现 S0/S1 证据立即采用更严格边界 |
| **S3：非急性线索需专业确认** | 历史轻微异响、震动或踏板手感改变，缺乏现场/车辆适用资料 | “没报码=没问题”或“有声音=摩擦片必须更换” | 保留记录与竞争假说，专业人员核对；本文仍不授予 SAFE_TO_DRIVE |

**限界**：本表是风险识别、停止正常使用和专业移交的原则，不是应急驾驶指令，更非对具体车辆制动后备性能的认证。红灯可对应驻车或系统故障，须按 OEM 定义；但严重症状优先于颜色推断。

## 2. 物理与控制链：不是一个“制动系统故障”就能确定的原因

需要分辨的五层：

1. **驾驶者制动请求、助力与液压/电液能力**：踏板、主缸、真空或电动助力/线控请求和回路传力；驾驶输入不等于各轮实际压力。
2. **轮端摩擦力矩和释放**：卡钳/轮缸、摩擦片或蹄、盘鼓、驻车机构、热状态；踏板手感不代表摩擦力一定足够。
3. **轮胎-路面附着**：即使轮端力矩达到要求，湿滑、轮胎状态、载荷/道路条件仍可能限制纵向力，转弯时侧向力需求还会分享附着。
4. **ABS/ESC 轮速与姿态反馈、液压调制**：正常防锁制动压力释放/再施加不等于液压漏失；ESC 可能逐轮制动并协调驱动扭矩，不能把警报直接定位为阀或传感器损坏。
5. **选配再生制动**：HEV/BEV 回收能量依赖电池、SOC、温度、电机/逆变器和控制许可；摩擦后备和踏板解耦依具体车型，不自动存在或自动合格。

### 2.1 至少三条竞争的“刹不住”因果链

- **A：轮端制动力矩不足**。液压漏失、助力受限、摩擦面异常、制动液/执行环节失效等可能导致请求未实现。
- **B：轮端制动力矩存在，但轮胎与路面的力传递达到附着极限**。湿滑、轮胎和载荷是另一因果链；ABS 的防抱死调压不会凭空增加抓地。
- **C：控制或再生协调造成制动力响应差异**。有对应配置时，ABS/ESC 调制、再生许可变化、电子助力或线控后备与前两条链交互。

**反例**：在低附着路面制动距离变长并触发正常 ABS，不足以证明主缸故障；反过来，有真实液压泄漏却全部归因于“雨天路滑”会掩盖严重危险。这两条同时可能成立，不能用单次主诉作唯一诊断。

## 3. 与 FAIL-BRK 十二种失效机理的一一对应：证据选择、竞争原因、误修风险

所有行都只是**研究级候选**，证据指历史可靠记录和合格专业验证应提供的类型，绝不代表执行指令。

| 上游 ID / 功能失败 | 同症状的主要竞争原因 | 真正可区分的来源证据维度 | 常见错误推断与专业风险 |
|---|---|---|---|
| **BRK-F01 液压传递不足** | 液压外漏、主缸内部旁通、回路空气/其他可压缩性、助力或适用电液执行问题 | VIN 对应回路、既有警告/液位与泄漏来源记录、专业验证的压力传递与系统结构结论 | “软踏板=主缸坏”不成立；漏液和明显踏板异常必须先停用 |
| **BRK-F02 助力不足** | 真空源/管路/助力器 vs 电子助力供电/控制器/传动执行；实际架构有别 | 车型真实助力类型、控制/供电异常历史、专业来源对助力状态的判定 | “踏板硬=摩擦片耗尽”；不能给装有电子助力的车套真空管路诊断 |
| **BRK-F03 摩擦接触/材料能力不足** | 摩擦材料异常磨耗、污染、盘鼓表面/接触问题、轮端执行不足；低附着也可产生减速度不足 | OEM 轮端结构、专业摩擦部件报告、热/工况历史，是否已排除附着限制 | “异响=必须换片”或“换片就能修复湿滑抓地不足”均不成立 |
| **BRK-F04 摩擦热衰退** | 高热负载造成材料摩擦特性下降，与 BRK-F05 介质气化不同，且可共存 | 事故前热负荷时序、专业摩擦表面记录及真实车辆允许条件 | “热后制动差=制动液一定沸腾”；不得借重复热路试区分 |
| **BRK-F05 制动液/介质状态** | 介质污染、可压缩性变化、密封/兼容、热环境与液压执行状况 | OEM 指定介质版次及专业原始材料/状态记录 | “踏板软=随便补某种刹车油”；未经 OEM 不能提供液种、换液/放气方法 |
| **BRK-F06 拖滞/无法充分释放** | 卡钳/鼓式机构、驻车机构、残余液压、控制执行、轴承等 | 已有热/负荷/制动请求时序、专业确认的部件位置与因果来源 | “热轮=卡钳卡死”；轴承与轮胎也会热；不得触碰发热部件或继续行驶试验 |
| **BRK-F07 左右/轴间不对称** | 摩擦/液压左右差、轮胎/路面载荷、悬架/定位/转向和 ESC 介入 | 与制动请求相符的偏航记录、轮胎/路况、车型控制架构和专业确认 | “制动跑偏=单侧刹车片问题”；严重不稳应停用，而非道路复测 |
| **BRK-F08 ABS 轮速信号** | 轮速传感器、编码目标轮、线路/供电、通信、轮胎有效半径/状态 | OEM DTC 含义、原始时间戳/冻结帧与轮速通道、实际配置 | “ABS 灯=刹车完全失效”或“无其他灯=安全可驾驶”均无依据 |
| **BRK-F09 ABS 调制/执行** | 轮速与滑移状态、液压阀/泵、执行命令/回路问题；正常 ABS 也可能产生踏板脉动 | 有效防抱死工况、可信控制命令与物理反馈，OEM 通道定义 | “踏板脉动=ABS 总成必坏”；控制目标并不等于各轮实测压力 |
| **BRK-F10 轮胎/路面抓地极限** | 湿滑、砂砾、水膜、轮胎状态、法向载荷/转弯侧向需求 | 可信环境与轮胎来源、既有车辆动态/滑移记录，不生成新的危险道路测试 | “制动距离长=液压不足”；ABS 不能无限增加附着力，也不保证任何表面都最短停车 |
| **BRK-F11 ESC/牵引控制干预** | 轮速、转向角、横摆估计、制动执行、轮胎附着与电控供电 | 是否真实配备 ESC、既有控制与车身状态记录、官方警告语义 | “ESC 灯=ABS 阀故障”；有些车无 ESC，不能跨车型类推 |
| **BRK-F12 HEV/BEV 再生协调** | 电池 SOC/温度/充电许可、驱动电机、摩擦制动融合或线控制动 | VIN/动力架构、OEM 再生/摩擦协调定义及历史控制状态 | “回收弱=液压坏”；“回收仍有=基础摩擦制动不需要”均危险且无依据 |

### 3.1 同一现象的关键反例

- **制动距离增长**：可能由轮端摩擦力矩不足，也可能是轮胎附着不足；不允许把 ABS 正常调压当“阀漏压”。
- **踏板变硬**：可能是助力或电子制动响应变化，不唯一指摩擦材料；**踏板明显下沉/无阻力**可提示更严重的液压/执行风险，先停用。
- **热后刹不住**：材料 fade 与制动介质汽化并非同一个物理过程，二者能同时发生。
- **ABS 黄色故障灯**：未必是液压制动全部失效；但只剩所谓“普通制动”也不能凭通用资料断言实际后备充分。
- **再生减弱**：电池接收许可变化可能符合正常保护；摩擦制动出现真实故障则不能由再生减速代替。
- **局部轮端热/异响**：卡钳拖滞、轴承、轮胎与驻车机构都可能竞争，不建议以手触/再次起步来“定位”。

## 4. 非操作性的诊断证据分层

| 级别 | 证据对象 | 能证明 / 不能证明 |
|---|---|---|
| **E0 主诉** | 车主描述、感觉、仪表印象、时间/天气/道路历史 | 只产生风险和候选，不能判断部件已坏或可继续使用 |
| **E1 可追溯已有事实** | VIN、制造/区域版本、原始故障码/冻结帧、维护记录、已存在的故障时序 | 可以收窄工况与配置；DTC 本身并不证明具体阀、传感器或摩擦件故障 |
| **E2 对应 OEM 权威资料** | 指定底盘/年份/软件的制动功能图、警告定义、后备策略、适用维修手册 | 才能限定该车实际功能/组件与适用规则；并不自动确认实车原因 |
| **E3 合格专业检修结论** | 按车辆适用 OEM 标准形成的可溯源检测/维修判定、部件/系统验证 | 才可将候选提升为维修结论；本 Markdown 不提供其操作方法 |
| **E4 车辆修复后独立验证** | 专业签署、与车型和修复范围对应的实际安全验收记录 | 才可能成为修复完成证据；本文不能代签“能上路” |

**证据冲突处理**：若 E0 抱怨软踏板但 E1/E2 缺失，原因保持 UNKNOWN，不能认定“没报警就没危险”。若存在 S0/S1，仍先停用。现有记录中无法核实 VIN/装备的情况，不得声称车辆具有 ESC、集成线控制动、再生功能或任何统一的安全后备。

## 5. 专业检修交接：最小事实包与拒绝的操作建议

建议知识记录的字段是：车型/VIN（若合法取得）、地区与制造年份、制动架构及已知装备、主诉与发生时间、S0–S3 风险分类、是否存在可信漏液/踏板/热/偏航证据、ABS/ESC/电子助力/再生配置和警告组合、故障码原始来源、竞争的 BRK-F01..F12 假说、证据层级、缺失项目、合格维修人结论和后续安全验证状态。

这些是**记录字段**，不是让普通用户执行现场试验或维修的操作步骤。未经特定 OEM 技术资料，不得生成制动液规格、系统压力、摩擦片最小厚度、卡钳紧固力矩、放气顺序、执行器动作、轮速信号针脚、ABS 编码、混动制动融合校准和高压隔离程序。

“停用/专业交接”是安全研究级建议；实际转运与安全处置须由当地适用的专业救援与车辆规定决定。禁止凭非认证生成知识作车辆道路通行许可。
