## 1. 先界定“制动系统”的几个不同边界

车辆减速链不等于一个“刹车总成”。同一辆车上至少要分开识别：

1. **行车制动（service braking）**：驾驶员或车辆控制系统要求减速时，提供并分配车轮制动力；常用摩擦副为盘式或鼓式。常见轻型车采用液压传力，也有不同程度的电液或线控集成方案。
2. **驻车制动（parking braking）**：保持静止车轮/车辆防止意外移动的机构与控制路径；可为机械驻车拉索、盘内鼓式驻车机构或电动驻车制动器 EPB，不能因为共用后轮卡钳就误认为与行车液压回路相同。
3. **防抱死 ABS / 电子制动力分配 EBD**：利用轮速等信息和液压/其它制动执行器调节车轮制动，减少不受控锁死的风险；EBD 的实现、软件集成和法规边界因车型而异。
4. **电子稳定控制 ESC（亦见 ESP 等供应商名称）与牵引力控制 TCS**：将制动执行能力用于车辆横摆/稳定与牵引控制；ESC 通常需要车辆运动与驾驶意图传感信息，并可协同动力系统，而不仅是“更高级的 ABS”。
5. **纯电车驱动电机再生减速**：电机/逆变器产生电磁减速扭矩并按条件回收能量；与轮端摩擦制动在减速需求层可混合，但**不等同于**液压摩擦回路，也不能无条件取代它。

**边界原则**：驾驶员脚踏/车辆制动请求、液压/电动执行、轮端摩擦副、车身动态控制以及电驱再生是五个不同层面。功能可一体化，物理执行拓扑未必相同。[S01][S02][S03][S04]

## 2. 结构覆盖骨架：从整车到部件

以下为研究级候选结构索引，表示“可能包含/可能交互”，而不是任意车型都具备的物理清单。

| 层级 | 典型总成/部件 | 作用与关键接口 | 适用限定 |
|---|---|---|---|
| 驾驶员/自动请求输入 | 制动踏板、推杆或踏板位移/力传感器、踏板支架、制动灯开关/信号 | 将驾驶员意图送到机械/液压或电子控制链；制动请求还可能来自辅助驾驶 | 线控架构不必保留贯通踏板到执行器的刚性机械力链 |
| 助力/压力生成 | 真空助力器、真空源/相关阀和管路；电动助力器；电液压力发生器及电机 | 放大或生成轮端所需压力/制动指令；与低压供电、发动机或电驱平台有关 | 真空、电机辅助、集成单元、冗余单元不可混为一种固定排列 |
| 制动主缸与储液 | 串列双回路主缸、制动液储液罐、液位信号及密封件 | 为液压分路建立/维持压力传递条件；回路拓扑依车型而定 | 某些 one-box 方案集成这些元件；不能断言每辆车都有可独立辨识的外置主缸 |
| 液压分配/管线 | 硬制动管、柔性制动软管、接头、分路、车辆级压力调节组件 | 在车身与运动轮端之间传递液压能，适应悬架/转向相对运动 | 前后分路、对角分路、冗余/隔离路径并非统一固定接管图 |
| ABS/ESC 调压 | 电子控制器 ECU、轮速传感器、液压控制单元 HCU/调压阀块、阀、泵及相关腔室/压力传感器（按型式） | 依据控制需要改变特定轮端压力，连接通信/电源/传感器 | 并非全部阀、泵、压力传感器在每种 ABS/ESC 产品中都独立存在或外露 |
| 盘式轮端摩擦副 | 制动盘、制动片、卡钳/支架、活塞、导向/密封与防尘部件 | 液压或其它执行力使摩擦材料作用于旋转盘，制动力经轮毂/轮胎传路面 | 浮动/固定卡钳、单/多活塞、盘尺寸/材质随车型与轴位不同 |
| 鼓式轮端摩擦副 | 制动鼓、制动蹄、轮缸或其它执行机构、支承/回位/调整机构 | 蹄片与鼓内表面摩擦，结构与力学反馈不同于卡钳—制动盘 | 可出现在部分车辆后轮或专门驻车机构；不是所有 BEV 都无鼓刹 |
| 驻车执行 | 机械拉索/杠杆、盘内鼓、卡钳电机 EPB、控制器/线束 | 驻车保持路径及其状态信息；可能与后轮摩擦总成物理共用 | 驻车电驱、机械保持与液压行车制动需分别追踪 |
| 车身动态传感 | 轮速、方向盘转角、横摆角速度、横向/纵向加速度、制动请求/压力信号（依架构） | 帮助 ABS/ESC 估计轮胎滑移、车辆方向和实际运动 | 并非所有传感器都专属于 ESC；封装/信号融合/网络归属不统一 |
| 再生制动接口（BEV） | 电驱电机、逆变器、动力电池/BMS、电驱控制器、制动协调控制、轮端摩擦执行 | 在允许条件下协调电磁制动与摩擦制动，承担要求的总减速 | 前/后/多电机、驱动轴/再生可用轴、能量回收限制、踏板逻辑均需车型资料 |

## 3. 三条彼此关联但不可混淆的结构路径

### 3.1 传统“踏板—助力—主缸—调压—轮端”液压路径

~~~text
驾驶员制动踏板
    │ 机械输入
    ▼
[真空助力器/另一型助力器] ── 可与真空源、供电系统关联
    │
    ▼
[串列主缸 + 储液罐] ── 两条液压分路（具体分路未知）
    │
    ▼
[ABS/ESC 液压调压模块] <── ECU、轮速/车身动态传感输入
    │
    ├── 制动硬管/软管 ── 轮端盘式卡钳（摩擦片 + 制动盘）
    └── 制动硬管/软管 ── 轮端鼓式轮缸（蹄片 + 制动鼓）
~~~

这只是一个**传统模块化拓扑示意**，不能据此推出真实车辆的 ABS 阀路、回路数量对应的车轮分组、容错工作方式或软管接头安排。助力器不是所有系统产生液压压力的唯一来源；调压模块也不等于主缸。串列双回路设计的工程目的与分路细节须区分，“双回路存在”不意味着单故障时仍保持相同制动性能。[S01][S03][S05]

### 3.2 集成电液制动：one-box 与 two-box 只是封装/功能组织的范畴

- **模块化 two-box**：如某些独立电动助力器加 ESC 模块方案，助力/建压与车轮压力调制位于不同总成。
- **集成 one-box**：如 Bosch integrated power brake、AUMOVIO MK C2 类产品，在一个总成内集成主缸/助力/ESC 的若干职责，电机经机械机构推动液压活塞建压。具体踏板解耦与失效后备路径不能按“one-box”这一名称推断。
- **踏板解耦与踏板感觉模拟**：某些集成电液系统可根据踏板传感信息计算制动请求，把踏板与工作液压路径在正常模式下解耦，并通过踏板感觉部件反馈操作感。此描述**不适用于所有电动助力或电控制动系统**。
- **纯线控/更高度解耦**：Bosch 展示的 brake-by-wire 方案以电信号替代踏板到制动执行路径的机械连接，并使用独立制动执行通道；其冗余是**该产品设计属性**，不可外推为所有线控制动都具有相同双冗余或后备机制。[S01][S02][S03][S04]

**分类规则**：是否有真空源、是否通过制动液传力、是否保留踏板机械/液压后备、助力与调压是否一体化、轮端是否为电机械执行器，需作为相互独立的描述维度。不要把“电动助力”“电液线控”“干式轮端 EMB”当作同义词。

### 3.3 轮端执行：盘、鼓与驻车不构成一一映射

- **盘式**：轮端转动体是制动盘；卡钳对摩擦片施加载荷。浮动卡钳利用滑动机构与单侧或一侧配置的活塞形成夹紧，固定卡钳可在盘两侧配置活塞；这是常见拓扑，不规定某车型实物结构。
- **鼓式**：轮缸/执行器将制动蹄推向鼓内表面；蹄片回位、调整装置和自增力趋势与盘式不同。鼓刹既可能承担行车制动，也可能作为盘内独立驻车鼓。
- **驻车**：EPB 可采用卡钳电机或其它机构，操作输入与低压控制/电源相连；“有 EPB”不证明存在四轮电机械行车制动，也不证明驻车保持仅依赖车载电源持续供能。
- **机械终端**：摩擦制动力需经轮毂—轮胎—路面建立纵向作用；因此制动执行能力与可用路面附着不等价。轮胎规格/状况与悬架载荷转移是接口，不属于制动液路的内部部件。[S05][S06]

## 4. ABS / EBD / ESC 的硬件共享与控制职责

| 功能 | 主要关注量/请求 | 候选输入 | 候选输出/执行通道 | 不能据此推断 |
|---|---|---|---|---|
| ABS 防抱死 | 减速中车轮滑移/锁死趋势 | 轮速，估计车速及按架构其他信号 | 控制单个或分组轮端液压压力；某些方案也协调电机扭矩 | ABS 不创造额外路面摩擦；不保证任意路况制动距离都缩短 |
| EBD 制动力分配 | 轴间/轮间制动需求与工况 | 轮速、负载相关估计及其它信号 | 对现有调压/制动执行结构分配需求 | 不等于每辆车均有独立“EBD 硬件盒” |
| ESC 稳定控制 | 驾驶意图与实际横摆/侧向运动偏差 | 转角、横摆、加速度、轮速、制动/动力状态等 | 选择性轮端制动、动力扭矩协同 | ESC 不能代替转向、轮胎附着或全部高级辅助驾驶功能 |
| TCS 牵引控制 | 驱动轮过度滑移趋势 | 轮速、动力输出/扭矩请求 | 驱动轮制动与发动机/电机扭矩协调 | 与 ABS 共用传感/执行元件不表示二者触发条件相同 |

**结构性关系**：轮速传感器通常服务多个控制功能；ABS/ESC ECU 可与 HCU 集成为一个总成，阀/泵/压力传感和电子板封装各异；ESC 还会通过车内通信与发动机 ECU、电驱逆变器、转向相关系统交换状态或扭矩请求。传感器缺失、通信不可用和执行器降级会影响相应功能，但**具体故障灯、失效保护与仍保留何种制动能力由 OEM 版本决定，本文不提供可执行推断**。[S01][S06][S07]

**关键区分**：ABS 是车轮滑移控制目标；ESC 是车辆横向/横摆稳定目标；同一套 HCU 或控制器可能承担二者。没有 ABS 硬件的车型、只有部分 ESC 功能的实现或专用车类不能照搬本轻型乘用车示意。

## 5. ICE 与 BEV 的共用结构、不同接口及再生制动协同

| 对比点 | ARCH-ICE-GAS-LIGHT（本轮汽油车概念） | ARCH-BEV-LIGHT（本轮纯电车概念） |
|---|---|---|
| 制动末端 | 常见盘式/鼓式摩擦副；可含 EPB | 仍可配置盘式/鼓式摩擦副和驻车机构；再生与之互补 |
| 助力能源 | 常见真空助力，与发动机进气真空或独立真空源相关；也可电动助力 | 无法假定有发动机进气真空；常见电动/电液建压与低压供电关联 |
| 主工作路径 | 常见踏板/助力/主缸/液压调压/轮端 | 传统液压、电液集成及线控方案均可能出现；不由 BEV 身份唯一决定 |
| 能量去向 | 摩擦制动主要转为热；本切片不考虑 ICE 混动再生 | 电机允许时可通过逆变器回收部分动能，摩擦副承担剩余/不可回收制动 |
| 控制信息 | ABS/ESC 与动力系统、转向、车内网络互联 | 在此基础上需要电驱/电池允许回收扭矩与制动协调信息 |
| 关键依赖 | 液压完整性、传感、助力源、供电及轮胎附着 | 除上述外，还涉及电驱扭矩能力、电池接收能力、工作状态和软件协调 |
| 必须声明的 UNKNOWN | 主缸/分路接法、轮端制动型式、具体后备机制 | 再生轴位、回收优先级、踏板解耦、驾驶模式、低速与故障衔接模式 |

**BEV 结构交互：**

~~~text
驾驶员踏板或车辆减速请求
           │
           ▼
  [减速需求/制动协调逻辑]
      │             │
      │             ├──> [摩擦制动请求/电液建压/ABS-ESC调压] ──> 轮端摩擦
      ▼             │
[电驱扭矩请求]      │
      │             │
[逆变器 + 电机]     │
      │             │
[驱动轴/车轮减速] <─┘
      │
      └── 电能回送（条件允许）──> [动力电池/BMS与能量接受限制]

轮速/转角/横摆/加速度/压力/电驱状态 ──> 控制反馈（连接关系因车型不同）
~~~

这个图表示**需求与能量路径的逻辑关系**，不是电源/线束原理图，更不是再生扭矩总能自由分配到四个车轮的证明：再生作用通常受可实施的电驱轴/驱动结构约束。可回收能力可能随车速、轮胎附着、电池温度、SOC、功率/故障状态变化；摩擦制动、ABS/ESC 和再生需按已认证车辆策略协调，不能从“BEV”推断固定的回收比例、刹车踏板手感或失效行为。[S03][S04][S08]

**法规作用限定**：美国 FMVSS No. 135 对其适用的轻型车、ABS 与被认定属于行车制动系统的再生制动协调等有特定定义与要求。这是**区域适用法规参考**，不能直接作为全球车型构造证明，也不能把一款制动方案的产品介绍替代车型认证报告。[S08]

## 6. 跨系统连接表：为什么不能只画一棵制动零件树

| 制动节点 | 外部节点 | 关系类型 | 专业理解价值及范围 |
|---|---|---|---|
| 助力/建压总成 | ICE 进气/真空源、低压供电 | 能源依赖 | 真空助力与电子助力的能源路径不同；并非全车都含真空泵 |
| 轮端制动盘/鼓/卡钳 | 车轮/轮毂、悬架、转向节 | 机械装配与载荷路径 | 制动力最终通过轮胎—路面，安装、支撑、热传递和载荷影响不可割裂 |
| 制动软管 | 悬架与转向运动 | 柔性机械/液压接口 | 车身到轮端的相对运动需要按结构安排柔性接口 |
| 轮速传感器 | 轮毂/轴承或其它测速目标 | 运动感知 | 可能通过车内网络供多个控制功能，不能只归属于 ABS |
| ESC 控制器 | 方向盘转角、IMU、底盘网络 | 驾驶意图与实际运动反馈 | 横摆稳定控制不同于单轮 ABS 调压 |
| ESC / ABS | 动力系统 ECU、电驱控制器 | 扭矩请求/限扭协同 | 驱动力与制动扭矩相互制约；BEV 还涉及再生请求调制 |
| BEV 制动协调 | 电机/逆变器、BMS、动力电池 | 扭矩与能量接受条件 | 回收不是摩擦制动的替代物，受电池与电驱状态约束 |
| EPB | 后轮摩擦机构/低压供电/驻车控制 | 驻车保持/状态控制 | 共用卡钳不等于共用所有液压执行或紧急备用策略 |
| ABS/ESC | 仪表、DTC、诊断通信 | 状态与诊断信息 | 一个报警或故障码不是某个零件失效的唯一证据 |

结构树用于回答“某对象属于哪个系统”；上表回答“哪些跨系统数据、能量、机械关系不能丢”。在同一实际车辆中，这些接口的实体归属/网络协议/OEM 部件号必须按车型版次追踪，暂不编造。

## 7. 结构变型与反例：避免把一种方案错写成“通用”

1. **反例：BEV 全靠再生制动，不需要摩擦制动。** 不成立。电机再生受工况和可用驱动轴限制，摩擦制动结构仍需明确；具体法规属于适用地区车辆类别范畴。[S03][S08]
2. **反例：有 ABS 必然有单独 ABS 控制盒、独立 ESC 盒和独立泵体。** 不成立。硬件和软件功能可以集成在同一模块，且集成程度随产品变化。[S01][S04]
3. **反例：所有车辆均为真空助力+普通主缸的机械直通。** 不成立。存在无真空电液集成、解耦/线控及冗余设计等明显变型。[S02][S03]
4. **反例：电动助力器就是没有液压油的干式电机械轮刹。** 不成立。电动动力源可以仍通过液压轮刹执行；真正在轮端电机械施力属于另一个维度。[S02][S03]
5. **反例：四轮盘刹、前盘后鼓或 EPB 属于同一个必选配置。** 不成立。轮端型式、轴位、驻车实现与服务制动分路是独立配置维度。[S05]
6. **反例：ESP/ESC 就是 ABS 触发更早。** 不成立。稳定控制需要考虑车辆横摆与驾驶意图，可能选择性制动车轮、协调动力扭矩。[S06][S07]
7. **反例：ABS/ESC 工作意味着不可能打滑，任何路面距离都变短。** 不成立。控制不创造附着能力，轮胎/路面条件仍限定运动结果。
8. **反例：双制动分路等于任一失效后还能保持原制动性能。** 不成立。具体冗余能力、失效告警及降级表现需对应车型法规/认证与维修资料。
9. **反例：同属 BEV，任何前后轴都能分摊电机再生。** 不成立。受电驱配置和车轮/电机机械联系约束；制动协调层逻辑不等于所有轴都有再生执行器。

这些反例用于检验结构模型和适用边界，不是特定车辆故障诊断结论。
