## 1. 如何从“刹不住/制动警告”分出真正不同的失效类型

制动是 **驾驶者/控制器制动请求 → 可用助力 → 液压/机电执行 → 摩擦力矩或再生力矩 → 轮胎/路面可用纵向力 → 车身减速度和稳定性** 的跨系统结果。

一条链有多个不同可能限制点。必须分开：
- **制动力矩生成不足**：主缸、助力、液压、轮端摩擦等可能使请求无法转为足够轮端力矩。
- **车轮产生力矩却无法把力传给路面**：湿滑/低附着、轮胎与接地条件限制，ABS 的压力调节也不能创造附着。
- **正常制动过程中的反馈调节**：ABS 可能暂时降低压力防止锁死；踏板反馈或噪声不是 ABS 损坏的充分证据。
- **不应存在的拖滞和不对称力矩**：在不应制动时仍存在摩擦阻力、热负荷或左右不均。
- **电子监测/通信/指令异常**：灯、DTC、轮速信号、ECU 目标值与真实液压/轮胎状态不是同一个量。
- **HEV/BEV 额外能量路径**：再生力矩可受电池、逆变器、轮胎附着及车辆策略约束；不能用电机回收直接代替全部摩擦制动。

本篇按根因→物理过程→现象→竞争反例编排，不以一次制动故障案例代替结构和功能知识。

## 2. 十二类失效链（候选机理，不是车辆已确诊）

| ID、失效对象 | 可能成立的条件/候选根因 | 物理作用及可能表现 | 同症状竞争解释与证伪边界 |
|---|---|---|---|
| `BRK-F01` 液压压力传递降低 | 相关回路泄漏、主缸内部旁通、系统内部空气/可压缩性或其他液压缺陷 | 踏板请求难以按设计转成轮端夹紧力矩，可能出现行程变化/制动不足；具体后备依架构 | 软踏板不唯一定位主缸，助力/机械/液压/控制条件亦可能影响手感；不同车型不能用统一液压路径推断 |
| `BRK-F02` 助力能力不足 | 真空源/管路/助力器异常，或适用电子助力的低压供电、执行单元/许可问题 | 实现同等液压需求所需驾驶输入或手感可能变化，减速度能力依实际机械后备 | 踏板变硬≠摩擦片一定磨损；电子助力、发动机启停架构未核实则不可判定 |
| `BRK-F03` 摩擦材料/接触失效 | 摩擦片或鼓蹄异常磨损、污染、非正常接触、盘鼓状态不合适 | 给定有效夹紧力下实际摩擦力矩变小或不稳定，可有制动效能下降、振动、噪声 | 响声不是直接证明摩擦片磨尽；若轮胎附着先达到极限，增加摩擦力矩也未必缩短停车距离 |
| `BRK-F04` 热衰退（fade） | 反复制动/高热负荷使摩擦材料、盘鼓工作温度超出相应工况性能范围 | 摩擦系数下降或热行为改变，可能出现制动效能衰减/异味 | 与 F05 液压气化不同；两者可共存，不可由一个“热后制动软”事件唯一归因 |
| `BRK-F05` 制动介质热/状态异常 | 介质含水/气化、外来污染、与系统规范不匹配（只描述条件） | 流体可压缩性或系统材料兼容性影响压力传递/反馈，可能出现行程和制动响应异常 | 无 OEM 制动液规范、状态证据不能断言“已沸腾”或指定更换工序 |
| `BRK-F06` 拖滞、无法充分释放 | 卡钳滑移/活塞或鼓式机构释放受阻、驻车机构、残余液压或电子驱动异常 | 无相应制动请求时仍有轮端阻力、温升、偏磨或能耗增加 | 热轮端也可能受轮毂轴承、胎压和道路条件影响；不能单凭温升锁定卡钳 |
| `BRK-F07` 左右或轴间制动不对称 | 一侧摩擦/液压/机械差异、轮胎附着与负荷变化、控制通道异常 | 左右轮所能传递的纵向力不同，可能偏航、跑偏或稳定性改变 | 跑偏不能自动归因于制动器；路拱、悬架定位、轮胎差异、转向系统亦有竞争解释 |
| `BRK-F08` ABS 轮速与信号链 | 轮速传感/目标轮、线束、供电、通信或估计误差 | 轮速信息缺失/不可信时 ABS 控制可受限，可能报码、警告或错误滑移判定 | ABS 警告不等于全部轮端摩擦制动消失；也不代表故障后备一定足以安全行驶 |
| `BRK-F09` ABS/ESC 调制与执行 | 液压调制单元的阀/泵/压力控制、电子指令/供电/反馈问题（按装备） | 升压、保压、降压与期望不符，可能影响滑移/方向稳定，产生控制异常 | 指令压力与真实轮缸压力不是同一测量；车辆 ABS/ESC 通道、失效后备和 DTC 定义必须 OEM 确认 |
| `BRK-F10` 道路/轮胎附着上限 | 湿滑、砂砾、水膜、轮胎状态/载荷/路面不均 | 制动力矩已足够而接地纵向力受到限制，停车距离或方向响应仍可能不符合驾驶者期望 | 延长的停车距离未必由液压不足造成；ABS 的主要作用是防锁与稳定，不保证所有路面都更短 |
| `BRK-F11` ESC/牵引与其它控制干预 | 不可信的转向角、横摆/轮速等输入，协调扭矩/单轮制动请求问题（按配置） | 控制器可能抑制/施加个别轮制动力或请求动力变化，使车辆表现出非预期干预/警告 | 方向异常不应一律判 ESC；车辆可根本没有 ESC，或问题来自轮胎附着/悬架/转向 |
| `BRK-F12` 可选再生制动/协调 | HEV/BEV 电机回收受电池充电许可、SOC/温度、逆变器/轮速、制动协同控制条件限制 | 可用再生力矩改变，摩擦制动补偿与踏板感觉/减速协调取决于车型架构 | 不能将再生减弱等同于液压制动完全失效；也不可认为所有 HEV/BEV 都有相同混合制动策略 |

**共同限定**：这些是假说类别，没有维修车队的暴露车数和真实工单分母，`PROBABILITY=UNKNOWN`；一些车型没有电子助力、ESC、再生或特定轮速传感配置，则对应分支需经可信的 `HAS_COMPONENT` 证据才能启用。

## 3. 同一“刹不住”主诉，至少有三条相反的因果路径

```text
[主诉：制动距离/响应不符合期望]
   ├─ H-A：驾驶制动请求未转成充分轮端制动力矩
   │   ├─ 助力输入/建压/压力保持
   │   ├─ 摩擦片-盘鼓接触及温度条件
   │   └─ 相关车辆控制与后备路径（依架构）
   ├─ H-B：轮端力矩正常，但轮胎地面可用纵向力受限制
   │   ├─ 湿滑/低附着/轮胎状态/载荷
   │   └─ ABS 控制限滑与路面关系
   └─ H-C：信号/控制/人为主诉口径或数据映射不一致
       ├─ 请求值与实测值、警告与实体条件差别
       └─ 不同车速/温度/工况及客观证据缺失
```

**反例 A**：在低附着路面，即便踏板、主缸、卡钳、摩擦材料都具备功能，路面可用摩擦仍可能决定减速度；将该现象全部归为“摩擦片坏”会误修。

**反例 B**：轮速异常或 ABS 灯亮，不能直接推定整个制动管路没有压力；同时也不能因为“还能踩出减速感”就宣布系统安全，应按对应 OEM 故障条件与专业评估处理。

**反例 C**：电子助力车型的踏板感觉可能通过控制模拟、容错逻辑与实际轮端液压脱耦；传统真空助力/非线控模型不能直接套用该构型。

## 4. 过热、拖滞、偏磨与制动力不足之间的可逆和不可逆区别

摩擦制动将动能转化为热，正常热量产生不等于“存在拖滞”。异常拖滞的核心是**不应存在的持续摩擦阻力**，可使轮端发热、能耗/磨损增加。高温可能与摩擦系数热衰退、制动液状态、盘/鼓热变形等并存，但不能从单次温度或气味推出唯一根因。

| 观察条件 | 可能符合 | 不可直接成立 |
|---|---|---|
| 长时间下坡后制动感觉变化 | 摩擦材料热响应、介质热状态、负载与道路条件 | 一定是液压里有空气；或一定是正常衰退、可继续用车 |
| 单侧轮端温升较高 | 机械拖滞、驻车/卡钳释放问题、轴承或道路/负荷差异 | 必然卡钳坏、唯一换件就是卡钳 |
| 踩下去“软”、行程变长 | 液压可压缩性、回路泄漏、主缸或其他与踏板机械有关的过程 | 可根据触感单独确定故障点、允许现场任意制动排气操作 |
| 偏磨或制动跑偏 | 接触不均、局部机械或液压差、轮胎/定位与荷载差异 | ABS 一定错误，或“左右压力相同所以跑偏不可能由制动引起” |

详细诊断与误修鉴别属于已审原 DAG 的后继 `REP-BRK`，此处只建失效/竞争原因知识。

## 5. ABS、ESC 的故障与正常控制需分别建模

**ABS 正常控制**：轮速传感与控制器估计车轮滑移趋势，在必要时通过液压单元适当降低/保持/恢复相应制动压力。Bosch 原始 [Antilock braking system](https://www.bosch-mobility.com/en/solutions/braking-systems/antilock-braking-system/) 表明 ABS 涉及轮速感知、ECU 与调压阀/回油泵。**在正常 ABS 干预时**出现压力调制并不是液压泄漏的直接证据。

**ABS 异常**：感知链、控制许可、供电或液压执行出现不一致时，车轮滑移控制可能不满足目标；但具体功能降级依车辆硬件、软件策略和标准要求，不可凭通用文档许诺“退化后仍能安全上路”。NHTSA 的 [Light Vehicle ABS Research Program](https://www.nhtsa.gov/sites/nhtsa.gov/files/absperformancefinalreport.pdf) 说明 ABS 的重要目标是保持制动稳定与操纵，不是对每种路面保证最短停车距离。本文仅借其公开结论，不复制原测试数据作为车型结果。

**ESC 正常/异常**：ESC 可能用轮速、转角、横摆与侧向动态，选择性制动车轮及请求动力干预；`ESP` 原理不能由一盏警告灯映射为某传感器损坏。Bosch 原始 [Electronic stability program](https://www.bosch-mobility.com/en/solutions/braking-systems/electronic-stability-program/) 显示其与 ABS/牵引功能的功能区分。未装 ESC 的老款或配置不明车辆应为 `NOT_APPLICABLE`（有车型证明不装）或 `UNKNOWN`（尚无证据），绝非默认配置。

**电子助力/线控制动**：Bosch [Brake-by-wire](https://www.bosch-mobility.com/en/solutions/braking-systems/brake-by-wire/) 展示一种含电子致动与后备建压的供应商方案，存在这种架构不意味着所有 HEV/BEV 或缅甸 Probox/Fit 有同一系统，更不能反推所有故障后备、机械连接方式及制动分配一致。

## 6. 混动/纯电的再生制动：区分三种能量限制

```text
车辆动能
  ├─ 摩擦制动 → 轮端摩擦热（液压/机电执行与路面附着受限）
  ├─ 电机负转矩（若允许）→ 逆变器/DC母线 → 电池受控充电
  └─ 其它行驶阻力
```

再生力矩可能受到：
1. **电池接收能力**：SOC、温度、故障状态、可接受充电功率；
2. **电机/逆变器与控制许可**：电机转速/驱动构型、功率电子状态、驱动系统限值；
3. **轮胎/制动协调**：附着、ABS/ESC 的稳定控制、摩擦制动与回收分配策略。

同一“能量回收变弱”可由这些条件产生，不能自动判动力电池失效。再生力矩可用性下降时，车辆如何补足摩擦力矩、踏板感是否改变、驻车与机械后备如何实现，属于**不同车型的实际控制策略**，没有对应 OEM 不能保证安全接管行为；也不能把某厂家“协调制动”的营销功能当所有车型的事实。传统汽油 Probox 不可无车型证据设想强再生制动；Honda Fit 的 IMA、i-DCD、e:HEV 也不可共用单一再生-摩擦映射。

## 7. 故障证据、竞争解释和不确定性：为 REP-BRK 提供输入

| 研究假说 | 有鉴别价值的证据**类型**（不是建议实际操作） | 反证或强制 UNKNOWN |
|---|---|---|
| `H-HYD` 压力传递不足 | 对应架构的实体回路/压力信息、异常工况与机械状态证据 | 只有控制器建压指令而没有实体状态；无适用 OEM 回路 |
| `H-FRIC` 摩擦副异常 | 材料/接触、磨损、温度与载荷的可信资料 | 轮胎附着先受限、根本没有该车型摩擦副结构证明 |
| `H-DRAG` 轮端持续拖滞 | 不应制动时的力矩/热表现及与机械、轴承/轮胎竞争来源的区分 | 单次热感、没有客观对照、同轴其它热源存在 |
| `H-ABS` 轮速/调制系统异常 | 轮速实际测量与 ECU 信号语义、可信执行反馈、架构故障状态 | “灯亮”但未验证传感器/液压路径；无对应车型 DTC 定义 |
| `H-TIRE` 附着不足 | 胎路状态、路面、载荷/速度/温度及车辆状态的可信证据 | 没有实际轮胎-路面条件，不能靠主观滑移断言液压健康 |
| `H-REGEN` 回收/融合变化 | 适用 BEV/HEV 具体电驱/电池许可、制动请求和摩擦补偿状态 | 该车不具再生架构，或无充电/电机运行资格证据 |

必须保留**多根因并存**（如热衰退与液压介质问题、轮胎失附与 ABS 输入异常）。DTC、指令压力和可见灯不能替代高风险实体判定。参考已生成 [跨系统诊断方法 DISC-METHOD](../common/diagnostic-methods.md)，其自身独审仍 PENDING，不可当成已验证专业诊断规程。

## 8. 缅甸车系、危险条件与适配边界

- Probox/Succeed 和 Fit/Jazz 均可能存在代际与地区差异。没有 `market+year+chassis+brake_architecture+ABS_ESC_variant+hydraulic_hardware+powertrain` 的车型原始资料，`HAS_ESC`、`ABS_CHANNEL_MAP`、`BRAKE_FLUID`、`REGEN_BRAKE_BLEND`、`SAFE_FALLBACK`、`PART_FITMENT`、`REPAIR_SPEC` 全部 `UNKNOWN`。
- **真实制动力异常、车辆跑偏或制动报警属于安全关键问题**。研究文字不能授权继续驾驶、跑测试路段、排气放液、拆解轮端、处理高压系统；必须由适格维修人员按准确车型资料进行风险评估和专业处理。
- `SEVERITY` 不等于 `FREQUENCY`。本稿可以标记风险可能很高，却完全没有可靠故障率样本，`FAILURE_RATE=UNKNOWN`。
- 不将 Bosch 或 NHTSA 的供应商/美国研究资料升级为缅甸实际车型认证、故障发生统计或 OEM 保修认定。
