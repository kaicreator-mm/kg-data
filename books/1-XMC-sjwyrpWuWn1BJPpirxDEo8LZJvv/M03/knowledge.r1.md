## 生成的知识记录

### M03-K001　液力耦合器的两轮能量传递

**核心命题：** 液力耦合器通常由输入侧泵轮和输出侧涡轮构成；泵轮驱动液体循环，流体动量变化向涡轮传递转矩。

**原理与解释：** 发动机机械功经泵轮变成流体运动能量，再由涡轮恢复为轴功；损失表现为流体摩擦与发热。

**条件与限制：** 必须明确泵轮/涡轮是两个不同的旋转部件；效率不是恒等于1。

**反例 / 错误推断：** 不能因为两轮转速接近，就推断没有任何能量损失。

**目录主题定位：** 课题一 液力耦合器

**知识关系：** RELATED → M03-K004, RELATED → M03-K006


### M03-K002　液力耦合器与液力变矩器的结构差异

**核心命题：** 典型液力变矩器除泵轮和涡轮外还设导轮，导轮通过改变回流方向参与转矩反力；单纯液力耦合器不具备相同的增矩机构。

**原理与解释：** 导轮对工作液体角动量的调节改变了泵轮与涡轮之间的转矩平衡关系。

**条件与限制：** 仅针对常见汽车液力变矩器结构；不能仅凭总成外观判断内部构型。

**反例 / 错误推断：** 不可认为所有有液体传动的设备都必然能够在低速时增矩。

**目录主题定位：** 课题二 液力变矩器

**知识关系：** RELATED → M03-K003, RELATED → M03-K005


### M03-K003　导轮产生反力的作用机制

**核心命题：** 导轮在反力阶段改变涡轮回流液体的方向，使泵轮入口流动条件发生变化，从而在一定工况下增加涡轮输出转矩。

**原理与解释：** 流体角动量改变对应叶轮/导轮的转矩；导轮反力经其支承传递到壳体。

**条件与限制：** 依赖导轮单向离合器处于锁止反力状态以及具体流场；不应外推到每一转速比。

**反例 / 错误推断：** 导轮存在并不意味着所有工况下涡轮转矩始终大于泵轮转矩。

**目录主题定位：** 课题三 综合式液力变矩器

**知识关系：** REQUIRES_CONDITION → M03-K005, RELATED → M03-K007


### M03-K004　角动量方程用于理解叶轮转矩

**核心命题：** 在适当控制体和符号约定下，旋转流体机械的轴转矩与质量流量及进出口切向角动量通量差有关。

**原理与解释：** 简化稳态表达：T≈ṁ(r₂Vθ₂−r₁Vθ₁)；实际流场复杂时需考虑多个进出口、非定常项和损失。

**条件与限制：** 稳态平均、控制体定义明确、流量与速度取一致方向；不是某型号变矩器的试验曲线。

**反例 / 错误推断：** 不能把该近似式直接当作任何型号液力变矩器的精确扭矩标定值。

**目录主题定位：** 课题二 液力变矩器

**知识关系：** EXPLAINS → M03-K003, RELATED → M03-K011


### M03-K005　导轮单向离合器的反力与超越状态

**核心命题：** 典型综合式液力变矩器的导轮通过单向离合器，在需要承受特定方向液流反力时锁止，在回流反力方向转变时允许超越旋转。

**原理与解释：** 这种状态转换减少高速耦合区导轮持续阻碍流动造成的损失。

**条件与限制：** 锁止/超越取决于真实反力矩方向及单向离合器机构，不存在通用于所有型号的固定车速阈值。

**反例 / 错误推断：** 不能仅根据车速高低就绝对断言导轮正在锁止或自由旋转。

**目录主题定位：** 三、 单向离合器的结构与原理

**知识关系：** CONDITIONS → M03-K003, RELATED → M03-K007


### M03-K006　速度比及其测量边界

**核心命题：** 液力变矩器常用涡轮转速与泵轮转速之比表征工作点：k=n_t/n_p。

**原理与解释：** 速度比仅描述两轴转速比例，需结合转矩比和效率才能讨论能量传递性能。

**条件与限制：** 要求n_p≠0，转速均在同一基准和方向约定下测量；负向或反拖工况另行定义。

**反例 / 错误推断：** k 接近 1 不等于锁止离合器已经机械结合。

**目录主题定位：** 四、 液力变矩器的工作特性

**知识关系：** RELATED → M03-K007, DISTINGUISH_FROM → M03-K008


### M03-K007　变矩器转矩比的含义

**核心命题：** 在输入和输出转矩方向及测量边界一致时，变矩器转矩比可定义为τ=T_t/T_p。

**原理与解释：** τ 随工况变化，典型低速比反力阶段可能大于1；并非任何状态下固定不变。

**条件与限制：** T_p≠0且符号定义、测量工况、内部附属功耗边界明确；具体曲线必须依型号数据核验。

**反例 / 错误推断：** 不能把某一型号失速转矩比复制到全部自动变速器。

**目录主题定位：** 四、 液力变矩器的工作特性

**知识关系：** RELATED → M03-K006, RELATED → M03-K011


### M03-K008　锁止离合器与液力滑差的区别

**核心命题：** 锁止离合器通过受控摩擦联接使输入和输出轴更直接地传递机械功；未锁止时液力传动存在随工况变化的速度差。

**原理与解释：** 锁止降低持续液力滑差损失，但也涉及扭转振动隔离、摩擦热和换挡品质的取舍。

**条件与限制：** 部分系统允许可控微滑差，不能用简单“开/关”概括全部锁止策略。

**反例 / 错误推断：** 传动转速差接近零不能单独证明锁止摩擦片完好。

**目录主题定位：** 课题四 带锁止离合器的综合式液力变矩器

**知识关系：** CONTROLS → M03-K009, RELATED → M03-K014


### M03-K009　锁止控制与工况约束

**核心命题：** 电子控制的锁止策略可能依赖车速、负荷、温度、挡位、振动和制动请求等变量，并在允许区域内改变结合压力或目标滑差。

**原理与解释：** 控制器通常需要兼顾经济性、NVH、传动链负荷和摩擦元件保护。

**条件与限制：** 具体锁止启用条件及电磁阀逻辑属于车型标定，不得从目录推导成维修阈值。

**反例 / 错误推断：** 不能声称“达到某个固定车速后所有汽车均会锁止”。

**目录主题定位：** 三、 锁止离合器的作用条件

### M03-K010　失速状态下的转速边界

**核心命题：** 典型变矩器失速试验所称失速点是涡轮转速接近零而泵轮仍由发动机驱动的工况，反映低速比区的流体反力状态。

**原理与解释：** 此时液力传动产生较高热负荷；实际测试必须受 OEM 测试时长、温度和安全条件约束。

**条件与限制：** 只表达概念，不提供可直接执行的失速试验操作；特定车型试验程序需权威核验。

**反例 / 错误推断：** 车辆无法移动不等于其液力变矩器处于规范的试验失速状态。

**目录主题定位：** 二、 液力变矩器的工作原理

**知识关系：** USES → M03-K006, SAFETY_CONSTRAINT → M03-K015


### M03-K011　转矩比与传动效率并非同一指标

**核心命题：** 若转矩与转速定义一致、忽略测量边界以外的功率，效率可表示为η≈(T_t ω_t)/(T_p ω_p)=τk。

**原理与解释：** 转矩比大于1并不意味着输出功率大于输入功率；转速比与液力损失共同决定效率。

**条件与限制：** 稳态、正向功率流且分母非零；具体辅助泵和机械损失必须定义是否计入系统边界。

**反例 / 错误推断：** 不能因低速时增矩就推断变矩器是“增能”装置。

**目录主题定位：** 四、 液力变矩器的工作特性

**知识关系：** RELATED → M03-K004, USES → M03-K006, USES → M03-K007


### M03-K012　液力传动热损失与ATF冷却关联

**核心命题：** 未锁止液力传动的输入功率与输出功率之差主要转化为热和其他损失，并通过ATF、壳体与冷却系统排散。

**原理与解释：** 持续高滑差、冷却能力不足或流量异常会提升热负荷，但实际温升还受驾驶循环、油路及环境影响。

**条件与限制：** ATF类型、温度限值及冷却路径必须与具体变速器型号绑定。

**反例 / 错误推断：** 高ATF温度不能单凭现象唯一归因于液力变矩器打滑。

**目录主题定位：** 四、 液力变矩器的工作特性

**知识关系：** RELATED → M03-K011, POSSIBLE_CAUSE → M03-K016


### M03-K013　内部叶轮与外部传动耦合关系

**核心命题：** 泵轮通常连接输入驱动侧，涡轮输出至变速器输入轴，导轮通过反力机构和固定支承路径参与工作；锁止元件提供旁路机械传递路径。

**原理与解释：** 输入输出连接关系是分析无前进挡、异响与控制失效的系统边界起点。

**条件与限制：** 不同车型和集成结构可能有不同部件命名、支承结构或起动机/电机布置。

**反例 / 错误推断：** 不能将某一种发动机横置AT总成的连接图直接用于所有混动驱动系统。

**目录主题定位：** 二、 液力变矩器的结构

### M03-K014　锁止抖动诊断必须建立候选原因集

**核心命题：** 锁止区域的抖动可能与摩擦系数变化、控制压力波动、扭转减振器问题、发动机失火等原因相关；应先复现实测条件再区分。

**原理与解释：** 比较目标与实际滑差、发动机燃烧稳定性、ATF状态以及异常出现的锁止控制区间可帮助提出可证伪假设。

**条件与限制：** 所列原因是候选，并非对特定车的确诊；需要 OEM 诊断数据与适用安全条件。

**反例 / 错误推断：** 不能仅因特定车速发生抖动，就直接更换液力变矩器总成。

### M03-K016　油液充气与冷却异常作为交叉系统候选

**核心命题：** 液力传动异常可以与油泵吸油、油液充气、过滤器受阻或冷却回路异常交叉关联，不能仅局限在变矩器内部零件。

**原理与解释：** 区分冷车/热车、负荷变化、压力与温度记录有助于检查跨系统假设。

**条件与限制：** 具体压力、温度和流量合格值按变速器型号确定；若仅有现象必须保持不确定性。

**反例 / 错误推断：** 出现油液泡沫不一定证明导轮单向离合器损坏。

### M03-K017　单向离合器失效的两种不同模式

**核心命题：** 导轮单向离合器若丧失承受反力的能力，低速增矩特性可能恶化；若卡滞不能超越，高速工作区的损耗与热负荷可能异常。

**原理与解释：** 两种故障模式对工况依赖不同，诊断应综合动力表现、油温与其他证据。

**条件与限制：** 必须结合具体单向离合器构型及适用诊断程序；不能单凭加速无力或过热确诊。

**反例 / 错误推断：** “加速无力”同时也可能来自发动机、供油、离合器等多种系统。

**目录主题定位：** 三、 单向离合器的结构与原理

**知识关系：** FAILURE_OF → M03-K005, POSSIBLE_CAUSE → M03-K012


### M03-K018　锁止滑差指标的计算条件

**核心命题：** 在明确输入、输出转速的正向定义后，可用Δn=n_p−n_t描述变矩器瞬时转速差；正向驱动时也可定义s=(n_p−n_t)/n_p。

**原理与解释：** 目标滑差与实际滑差的偏差可作为控制诊断中的辅助信号，但传感器滤波与稳态/瞬态必须分开。

**条件与限制：** n_p≠0，必要时考虑符号约定；纯负滑差/反拖及混动工况需另行定义。

**反例 / 错误推断：** Δn 很小不等价于摩擦片没有磨损，也不能据此确认锁止压力正确。

**目录主题定位：** 二、 锁止离合器的操作

**知识关系：** USES → M03-K006, RELATED → M03-K008, RELATED → M03-K014


### M03-K019　液力元件效率与NVH的工程折中

**核心命题：** 锁止可降低流体滑差热损失，但削弱部分液力隔振效果；控制策略通常在效率与扭振舒适性之间折中。

**原理与解释：** 不同传动系的惯量、发动机激励和减振装置影响适宜的锁止运行区域。

**条件与限制：** 这是一般工程原理，不表示图书提供某一车型的控制标定。

**反例 / 错误推断：** 不能据此推断所有车型“越早锁止越好”。

**目录主题定位：** 三、 锁止离合器的作用条件
